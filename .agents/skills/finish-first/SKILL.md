# Finish one useful result

- Select one concrete user-visible defect or capability gap.
- Define done in observable terms and keep the scope narrow.
- Do not broaden into optional redesign while the selected defect remains open.
- If blocked, record the blocker and move to the next independent task.
- Leave the repository in a resumable state with tests, commit, and a concise status.
