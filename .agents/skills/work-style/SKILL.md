# Work style

- Inspect before editing; reproduce before fixing when possible.
- Make one logical change at a time and test it.
- Read the diff after editing.
- Never report tests, CI, merges, or releases that were not observed in the current work.
- Be concise in chat; put durable technical detail in repository files.
- Preserve the user's exact scope and terminology.
