# CharacterDesigner（chatdraw）

チャットで頼むと AI が絵を描き、その絵に人が描き足せるデスクトップの描画アプリです。ラフを描いて渡すと、線の形に沿って AI が仕上げます。

![左にデッサンの道具、中央にキャンバス、右に AI の欄と履歴とレイヤーが並ぶ画面](../docs/images/chatdraw-main.jpg)

## 主な機能

- AI で描く: 右の AI の欄に描きたい絵を書いて「描く」を押します。日本語の頼みは、言葉の模型が絵の模型の分かる言葉に直します
- ラフから描く: キャンバスに線を描き、「ラフから」を選んで描くと、線の形に沿って描きます
- 描いている様子: 描いている途中の絵がキャンバスに出ます。工程と残り時間は右の履歴の欄に出ます
- 作画: レイヤー、ブラシ 6 種と筆圧、移動・選択・ぼかし・塗りつぶし・グラデーション・直線・四角・楕円・スポイトなど 14 の道具
- 絵の模型: 好みに合わせて選べます。動作を確かめた模型だけを出し、「AI」メニューでいつでも切り替えられます。「おまかせ」は頼みに合う模型を AI が選びます
- 模型の管理: 「AI」メニューの「模型の管理」で、手元の模型の一覧・削除・推奨の模型の取得・更新ができます
- 欄の配置: 欄は畳む・別ウィンドウにする・隠すができ、「ウィンドウ」メニューの「並びを初めの形に戻す」で初めの配置に戻せます

## 動作環境

- Windows 10 / 11（64 ビット）
- ディスク: 絵の模型 1 つにつき 約 2〜7GB、言葉の模型 約 1.3GB、描く部品 約 0.2〜2.5GB（NVIDIA の GPU がある機械は大きい方）
- GPU は無くても動きます（CPU で 1 枚 約 4〜10 分）
- Python などは要りません。アプリは利用者の Python や環境変数の設定を読みません

## 入れ方（短く）

1. `CharacterDesigner-Setup.exe` を開き、案内に沿って入れます（管理者の権限を求められます）
2. デスクトップかスタートメニューの CharacterDesigner を開きます
3. 初めての起動で絵の模型を選び、「取って使う」を押します

手元の模型（`.safetensors` か diffusers のフォルダー）を使うときは、「設定」の「模型の管理」の「手で置く模型の置き場を開く」か「ファイルを選んで使う…」を使います。詳しくは手順書の 3 章にあります。

## 置き場

| 置き場（既定） | 入っている物 |
|---|---|
| `C:\Program Files\CharacterDesigner` | アプリ本体 |
| `C:\ProgramData\CharacterDesigner` | 描く部品、記録（`chatdraw.log`、`setup.log`）、模型の置き場の設定（`places.json`） |
| `C:\LLM\huggingface`、`C:\LLM\gguf` | 取った模型（自作アプリで共有） |
| `C:\LLM\manual` | 手で置いた模型 |
| ピクチャ\CharacterDesigner | 描いた絵 |

模型の置き場は「設定」の「保存」で変えられます（次の起動から）。

## 設定

「設定」メニューの「設定…」で、模型、描く工程の数、頼みの効き、ラフに沿う強さ、保存先、模型の置き場、知らせ、カーソルを変えます。キーの割り当ては「キーの設定…」で変えます。

| 環境変数 | 用途 | 必須 |
|---|---|---|
| `CD_HOME` | 部品と記録の置き場を移す（開発用） | 任意 |
| `LLM_HOME` | 模型の置き場を移す（開発用。設定で選んだ置き場があれば、そちらが先） | 任意 |

## ディレクトリ構成

| 場所 | 役割 |
|---|---|
| `app.py` | ウィンドウ、メニュー、欄の配置 |
| `canvas.py`、`brush.py`、`colorpanel.py`、`icons.py` | 作画 |
| `engine.py` | 絵の模型と言葉の模型で描く |
| `models.py`、`catalog.json` | 模型の一覧と、確かめた結果 |
| `setup.py`、`manager.py`、`choose.py` | 初回の設定、模型の管理、おまかせの選び方 |
| `paths.py`、`migrate.py` | 置き場と、前の版からの移行 |
| `activity.py` | 工程・進み・履歴の欄（緊急停止、最後に進んだ時刻、裏の処理） |
| `tabdock.py` | AI の欄のタブの並べ替え・欄の外へ出す・並びの保存 |
| `finishers.py` | 仕上げの道具（綺麗にする・描き直して整える・拡大・質感・空気感・清書）。tools/gen の retouch・inking・atmosphere・materials を囲みの中だけに掛ける |
| `shortcuts.py` | 右クリックのショートカット。加工と登録した指示を、★・よく使う順・処理の種類ごとに並べる |
| `charadesign.py` | キャラクターデザインのメニュー（設定資料集・三面図・表情差分）。tools/gen/bible.py の資料の形を使う |
| `fit.py`、`keys.py` | 窓を画面に収める、キーの割り当て |
| `help/`、`helpview.py` | 手順書と操作方法、アプリの中で読む窓 |
| `verify_models.py` | 絵の模型を動かして確かめる（Actions の model-verify で流す） |
| `tests/` | 試験 |
