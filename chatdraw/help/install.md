# 手順書: 入れる・模型を用意する・困ったとき

## 1. 入れる

1. [Releases](https://github.com/Maguro-JP/CharacterDesigner/releases/latest) から `CharacterDesigner-Setup.exe` を取ります
2. 開いて、案内に沿って入れます。管理者の権限を求められます
3. デスクトップかスタートメニューの「CharacterDesigner」を開きます

Python などをほかに入れる必要はありません。アプリは、利用者の Python や環境変数の設定を読まずに起動します。

## 2. 初めての起動で模型を取る

初めての起動では「使う AI を選んでください」の窓が出ます。

1. 絵の模型を選びます。迷ったら「おすすめ」の印が付いた物を選びます
2. 「取って使う」を押します。描く部品（約 0.2〜2.5GB）と、選んだ模型（約 7GB）を取ります
3. 取っている間は、進みの帯と今している事が窓に出ます。回線によっては数十分かかります
4. 終わると「はじめる」の画面になります

ほかの模型を取りたいときは、「推奨だけ表示」を外します。まだ確かめていない模型には「まだ確かめていない」の印が付きます。

あとから模型を足す・替えるときは、「設定」メニューの「模型の管理（入れ替え・更新）…」を開きます。

## 3. 模型を手で置く

回線を使わずに、手元にある模型を使えます。

### 絵の模型

使える形は次の 2 つです。

- `.safetensors` のファイル 1 つ（SDXL 系か SD1.5 系）
- diffusers の形のフォルダー（中に `model_index.json` がある物）

置き方:

1. 「設定」メニューの「模型の管理（入れ替え・更新）…」を開きます
2. 「手で置く模型の置き場を開く」を押します。置き場（既定は `C:\LLM\manual`）が開きます
3. そこへファイルかフォルダーを置き、模型の管理の窓を開き直します
4. 一覧の「手で置いた模型」の「使う」を押します

置き場へ動かさずに使うときは、「ファイルを選んで使う…」で `.safetensors` を選びます。ファイルはそのままの場所から読みます。

世代は、フォルダーなら `model_index.json` の部品の名前から、ファイルなら中の重みの名前から見分けます。1 つのファイルで読めるのは SDXL・SD1.5・FLUX.1 です。見分けられないときは、使う前に理由を出します。

1 つのファイル（.safetensors）の模型は、初めて読むときに、組み立ての設定（数 MB）を Hugging Face から取ることがあります。ラフから描くときは、世代に合うラフの部品を初回に取ります（約 0.15〜0.3GB）。回線がまったく使えない機械では、ラフから描くことと参考画像は使えません。

### 言葉の模型

日本語の頼みを、絵の模型が分かる言葉に直す模型です。`.gguf` のファイルを `C:\LLM\gguf` か `C:\LLM\manual` に置くと、「設定」の「言葉の模型」の一覧に出ます。

### 置き場を変える

「設定」の「保存」の「模型の置き場」で、模型の置き場を選べます。変えると、次に起動したときから新しい置き場を使います。前の置き場の模型は動かさないので、要る物は自分で移します。

| 置き場（既定） | 入っている物 |
|---|---|
| `C:\LLM\huggingface` | 取った絵の模型と部品 |
| `C:\LLM\gguf` | 取った言葉の模型 |
| `C:\LLM\manual` | 手で置いた模型 |
| `C:\ProgramData\CharacterDesigner` | 描く部品、設定の一部、記録（`chatdraw.log`、`setup.log`） |
| ピクチャ\CharacterDesigner | 描いた絵 |

## 4. 更新する

- 「ヘルプ」メニューの「更新を確かめる」で、新しい版があれば取って入れます
- 新しい `CharacterDesigner-Setup.exe` をそのまま入れても更新できます。描いた絵・模型・設定は残ります

## 5. 消す

Windows の「設定」の「アプリ」から CharacterDesigner をアンインストールします。

- アプリ本体、ショートカット、取った更新、自動保存の控えを消します
- 描く部品（ProgramData）は、消すかどうかを聞きます
- 模型（`C:\LLM`）と描いた絵は消しません。模型はほかの自作アプリと共有していることがあるためです。要らなければ自分で消します

## 6. 困ったとき

| 起きたこと | すること |
|---|---|
| 模型が取れない | 窓に出た理由を読みます。詳しい記録は `C:\ProgramData\CharacterDesigner\setup.log` にあります。回線を確かめ、模型の管理から取り直します |
| 進みが動かない | 進みの欄の文で、今している事を見ます。初めて模型を読むときは数分かかります |
| 欄が見つからない・隠れた | Tab を押します（欄を出す・隠すが入れ替わります）。直らなければ「設定」の「並びを初めの形に戻す」を押します |
| ウィンドウが画面からはみ出す | 自動で画面の中に戻します。戻らなければ「並びを初めの形に戻す」を押します |
| キーが効かない | 「設定」の「キーの設定…」で割り当てを見ます。「すべて既定に戻す」で初めの割り当てに戻せます |
| 落ちた・おかしい | `C:\ProgramData\CharacterDesigner\chatdraw.log` に記録があります。「ヘルプ」の「記録の置き場を開く」で開けます |
