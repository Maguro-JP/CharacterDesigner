- [x] 職業を増やす: 剣士、神官（女性）、狩人、踊子（女性）、盗賊、商人（子供）、学者、薬師。体格の枠（子供、男性、大柄男性、女性）

- [x] 体格の枠ごとの頭の大きさ（変更不要と判断。男性の頭身 3.17 は範囲内。要るときは `transforms` で直せる）

- [x] 待機2コマ（呼吸。`frames` と `breathe`）
- [x] 歩き4コマ（剣士、神官、狩人）

- [x] 右向き（左右反転ではなく、光の向きを保って描き直す）
