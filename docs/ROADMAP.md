# 道のり

## 1. HD-2D のドット絵（今ここ）

- [x] 作風の決まり `styles/hd2d.json`、描画と検品の道具、手打ちの戦士の試作（3版）
- [ ] 部品で組む描画器: 頭・胴・腕・脚・装備を、形（楕円、多角形、曲線）と素材で定義する
- [ ] 光: 左上からの光で素材ごとに陰影を付ける（地・影・最暗・光、金属は鋭いハイライト）
- [ ] 縮小: 高解像度から 18x32 前後へ。減色（素材ごとのパレット）、素材ごとの輪郭、孤立ドットの掃除
- [ ] 同じ戦士を新方式で描き、手打ちの v3 と並べて良くなったかを見る
- [ ] 職業を増やす: 剣士、狩人、神官、学者、踊子、商人、盗賊、薬師。体格の枠（子供、男性、大柄男性、女性）
- [ ] 向きと動き: 左向きの 3/4 を基本に、待機2コマ、歩き
