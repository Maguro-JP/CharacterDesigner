# 道のり

## 優先順位（2026-10-03 見直し）

目的は、Claude に「○○なキャラクターを作って」と頼めば、綺麗なキャラクターデザインが出て、
そこから画風を変えた派生（3D、アニメ風2D、リアル風、ドット絵）に繋げられること。

1. ベース: 文章 → 綺麗なキャラクターデザインの絵（画像生成。`tools/gen/design.py draw`）
2. 同じ人物を保つ: 正面・横・後ろ、表情、ポーズを同じ人物のまま描き分ける
3. 派生: リアル風（`restyle --style real`）、ドット絵（`pixel`）、3D（Blender。人物の比率と服を絵に合わせる）
   - ドット絵の作風: 等身を保つ少ない色の見下ろしアクション（`pixel --preset survivor`、使える水準）と、箱庭ドット（頭を大きくする変換が要る）
4. 作風に寄せる: 派生のドット絵を、手本の全コマの分布（`tools/learn.py`）に近づける。箱庭ドットの頭身への変換

5. 亜人の設定資料の道具（`tools/gen/demi.py`）を、手元で動くアプリにする。計画は `docs/app/PLAN.md`（長期開発で進める）

## 0. ローカルアプリ（長期開発、2026-10-05 から）

`docs/app/PLAN.md` の M1〜M5 を上から順に進める。M5（Claude から使えるようにする）はアプリが完成してから。

## 0.5 描き分けを広げる（2026-10-10 利用者の指示）

アプリ（0.）の次に進める。`tools/gen/traits.json` に分類として足し、1つずつ描いて目で見て、効いた言葉・効かない言葉を
`docs/knowledge/traits.md` に表で残す。各分類の済の条件: 5種類以上が、目で見て頼んだとおりに描き分けられ、崩れが無い。

1. [x] 髪型（ロング、ショート、ボブ、ポニーテール、ツインテール、お団子、編み込み、ウェーブ、アホ毛）: 9種中8種が言葉だけで描き分けられた（アホ毛は出ない）。`docs/knowledge/traits.md`
2. [x] 影の付け方（アニメ塗り2段、ブラシ塗り、厚塗り、セル影なし、逆光のリムライト）: 立体を計算して光を当てる `imgproc.py shade` で、2段・3段・なめらか・縁の光・逆光の5つと光の向きを出し分けられる。描く言葉での塗りの作風（ブラシ塗り、厚塗り）はまだ
3. [x] 服（制服、和服、ドレス、鎧、作業着、パーカー、軍服、魔法使いのローブ）: 8種すべてが言葉だけで描き分けられた。華やかな服は背景が暗い舞台に寄る。`docs/knowledge/traits.md`
4. [ ] 武器（剣、刀、槍、弓、杖、銃、大鎌、盾）。持ち方（手に握っている、背中に負う）が崩れないこと
5. [ ] 装備（鞄、ベルトの小物、ゴーグル、ヘッドホン、手袋、ブーツ）
6. [ ] エフェクト（炎、氷、雷、魔法陣、光の粒、風）
7. [ ] 乗り物（バイク、馬、ほうき、機械の脚、小型の飛行機）。乗っている姿勢が崩れないこと
8. [ ] ペット（肩の小動物、足元の犬猫、浮かぶ使い魔）
9. [ ] 動物（人と並べない単体の動物の設定資料: 犬、猫、狐、狼、鳥、竜）
10. [ ] ディテール（アクセサリー、刺繍、傷、そばかす、ピアス、タトゥー）
11. [ ] デフォルメ（2頭身、3頭身、SD のちびキャラ。同じ人物のまま頭身だけ変える）

## 0.6 画像処理の道具（2026-10-10 利用者の指示）

`tools/gen/imgproc.py` にまとめる。済の条件: 描いた絵の上で動き、結果を目で見て崩れが無い。記録は `docs/knowledge/imgproc.md`。

- [x] セグメンテーション（セマンティック、インスタンス）、イメージマッティング、背景除去、切り抜きとクリッピングパス、クロマキー、ロトスコーピング（GIF とコマのフォルダ）
- [ ] 動画のロトスコーピング（mp4。ffmpeg が要る）
- [x] インペインティング（範囲を描き直す。`edit.py` にあるものを呼べるようにする）とアウトペインティング（絵の外を描き足す）: `imgproc.py inpaint / outpaint`。丸窓を描き足せ、描き足しの横縞も消えた。描き足しの左の境目にうっすら筋が残る。`docs/knowledge/imgproc.md`
- [ ] 超解像（拡大して細部を足す）
- [ ] 線画の抽出（塗り絵や清書の下地）と、線画への着色
- [ ] 色の置き換え・色調補正・色合わせ（`layers.py` の色寄せを単体で呼べるように）
- [ ] 姿勢推定（骨格の点を取る。ポーズを付けて描くとき、骨格で崩れを数える）
- [ ] 奥行き推定（`layers.py` の Depth Anything を単体で）と、法線から光を当て直すリライティング
- [ ] 顔の検出と、顔だけ拡大して描き直す修正（崩れた顔を直す）
- [ ] ノイズ除去、ぼかし除去
