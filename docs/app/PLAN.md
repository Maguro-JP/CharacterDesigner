# キャラクターデザインのローカルアプリ（計画）

手元の PC で動かし、画面から「狐娘」「サキュバス」のように頼むと、設定資料（多方向の1枚）を描いて検品し、
通ったものを並べて見せるアプリ。Claude に頼まなくても同じことができ、完成したら Claude からも呼べるようにする。

長期開発（long-dev → auto-dev）がこの計画を上から順に進める。終わった項目には [x] を付け、決めたことは
`docs/knowledge/decisions.md` に書く。

## 前提

- 中身は今の道具をそのまま使う。描く・検品するのは `tools/gen/demi.py`、3D の下絵は `tools/engine/viewer/vrm-base.html`
- 公開しない。自分の PC だけで使う（12-1 の「公開せず内側だけで使う」→ Vite + React + TypeScript）
- 描く処理は Python なので、間に Python のサーバー（FastAPI）を置く
- GPU があれば使い、無ければ CPU で動く（CPU では1枚 約3分、初回の読み込み 約10分）
- 置き場所は `app/`（`app/server` が Python、`app/web` が画面）

## 段階

### M1. サーバー（描く仕事を受けて返す）
- [x] `app/server`: FastAPI。仕事（描く依頼）を受け、順番に1つずつ処理する（同時に2つ描くとメモリが足りない）
- [x] 仕事の状態（待ち・下絵・描画中・検品・完了・失敗）と、何回目の試行かを返す
- [x] モデルは1度だけ読み、仕事の間で使い回す（読み込みに約10分かかるため）
- [x] 種の一覧（`casts/demi3d.json`）の読み書き
- 完了条件: `curl` で依頼を出し、`sheet.png` と検品の結果（`report.json`）が返る。テストで確かめる
- 済（2026-10-06 JST）: 偽の描画で流れの試験 9件（`PYTHONPATH=.cache/app/lib python3 -m pytest app/server/tests`）。
  本物で猫娘を3回まで描く依頼を curl で出し、3回目で通った `sheet.png` が返った（1回 約180秒、2件目はモデルの読み込み無し）
- 起動: `PYTHONPATH=.cache/app/lib:.cache/gen/lib python3 -m uvicorn app.server.main:app --port 8000`
  （部品は `python3 -m pip install --target .cache/app/lib -r app/server/requirements.txt`）

### M2. 画面
- [x] `app/web`: Vite + React + TypeScript + Tailwind
  - 済（2026-10-06 JST）: 1枚の画面で、種を選ぶ・描く・進み具合（状態、何回目、経過）・最後の回の検品・通った絵を見る、まで。
    偽の描き手のサーバーにつなぎ、ブラウザーで猫娘を頼んで、2回目で通った絵が出るまでを通した（画面のエラー 0、375px 幅で横のはみ出し 0）
  - 起動: `cd app/web && npm install && npm run dev`（http://127.0.0.1:5173、/api は 8000 番のサーバーへ渡す。`CD_API` で変えられる）
- [x] 種を選ぶ・新しく足す（部品の形と色、描く言葉、打ち消し）
  - 済（2026-10-06 JST）: 種の欄（耳・尾・翼・角の形と色、3D の部品の組、体の決まり、描く言葉、髪と目、打ち消し、下絵の髪の色、背景、強さ）。
    選択肢はサーバーの `/api/parts` が描く道具の定義から返す。部品を選ぶと体の決まり（獣の耳・尾・翼）も自動で入る。
    ブラウザーで、空のまま保存して理由3件が出る → 狼娘を足す → 一覧に出る → 狐娘の強さだけ直して他の値が残る → 狼娘で描く、を通した
- [x] 3D の素体の確認（`vrm-base.html` を埋め込み、部品の付け根を見る）
  - 済（2026-10-06 JST）: 種の欄の「3D の下絵を見る」で、描くときと同じ下絵（`demi.underlay`）を4方向で撮って並べ、検品で数える部品の型も横に出す。
    1回 約24秒。同じ下絵になる設定（部品・色・髪の色・背景）は撮り直さず、言葉だけ変えたときは 0.4 秒で出る。
    ブラウザーを埋め込んで回して見る形にはしなかった（描くときと違う見え方になりうる。描くときの下絵そのものを見る方が確か）
  - 直したこと: 悪魔の尾・角・蝙蝠の翼の膜は色を選んでも変わらなかった（主な色の印が無かった）。既定の色の下絵は直す前と画素が全く同じ
- [ ] 仕事の進み具合（何分経ったか、何回目か）
- [x] 結果の一覧: 描いた絵、検品の図（部品ごとの ○×）、落ちた理由。通ったものを `library/samples` に保存する
  - 済（2026-10-06 JST）: 回ごとに描いた絵・検品の図・落ちた理由（「斜め前の尾」のように向きと部品の日本語名）を開いて見られる。
    通った絵は「見本に保存」で `library/samples/demi3d-<種>.png` に置く。既にある見本は「置き換える」を選んだときだけ上書きする。
    本物で描いた猫娘の回ごとの絵を偽のサーバーから返し、ブラウザーで表示（画像 4 枚とも読めた）・保存・断り・置き換えを通した
- 完了条件: 画面だけで、新しい種を足して描き、通った絵を保存まで通せる
- 済（2026-10-06 JST）: 4項目すべて済。偽の描き手で、足す・下絵を見る・描く・結果を見る・保存を画面だけで通した。本物の描画は `demi.py` で1種ずつ確かめた

## やらないこと（今は）

- 外への公開、ログイン、複数人での利用
- 有料の GPU サービスへの接続（手元の GPU か CPU で動かす）
- 3D の作り込み（3D は下絵に要る部品を足すだけ）
