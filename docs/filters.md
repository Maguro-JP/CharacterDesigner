# 描く内容の制限とフィルター

このツールは、描く内容を最初から規制しない。描きたくないものは、使う人が自分のフィルターで止める。
設定で外せない制限は、下の「固定の制限」の1つだけ。

## 利用者のフィルター

`config/filters.json` に書く。書き方の見本は `config/filters.example.json`。

```json
{
 "filters": [
  {"name": "グロテスク", "enabled": true,
   "words": ["グロ", "流血", "gore", "blood"],
   "negative": "gore, blood"}
 ]
}
```

- `enabled`: `true` のフィルターだけが働く。既定ではどれも `false`
- `words`: 止める言葉。どの言語で書いてもよく、1つの一覧に並べる。頼みごとか描く言葉にこの言葉が出たら、描かずに理由を返す
- `negative`: フィルターを入れている間、描かせない言葉にいつも足す言葉
- 新しいフィルターは、名前を付けて足せる。用意してある型は「グロテスク」「性的な表現」「暴力」「ホラー」で、どれも切ってある
- `config/filters.json` は個人の設定なので git には入れない。ファイルが無いか壊れているときは、全部切った状態で動く

英数字だけの言葉は語の単位で比べる（`bra` を入れても `braid` は止めない）。それ以外の言葉は文字列として探す。

## 固定の制限

子どもを性的に描くことだけは、設定では外せない。止めるのは次の2つ。

- 子どもを性的に描くことを指す言葉（例: loli、shota）
- 子どもを表す言葉と、性的な言葉が同じ頼みごとに並んだとき

子どものキャラクターを描くこと、大人の性的な表現や露出は、この制限では止めない。

## 確かめていないこと

- 言葉で見る仕組みなので、言い換えや綴りの崩しは拾えない
- 画像生成の模型は、頼んだ以上に体を強調した絵に寄せることがある。出来た絵の中身までは、この仕組みでは見ていない
