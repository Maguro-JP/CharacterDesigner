# 描く内容の制限とフィルター

このツールは、描く内容を最初から規制しない。描きたくないものは、使う人が自分のフィルターで止める。
設定で外せない制限は、下の「固定の制限」の1つだけ。

## 利用者のフィルター

アプリの画面の「フィルター」の板で、入れ切り・止める言葉の追加・新しいフィルターの追加をして保存できる。外せない制限の説明もそこに出る。
保存先は `config/filters.json` で、手で書いてもよい。書き方の見本は `config/filters.example.json`。

```json
{
 "filters": [
  {"name": "グロテスク", "enabled": true,
   "words": ["グロ", "流血", "gore", "blood"],
   "negative": "gore, blood"}
 ]
}
```

- `enabled`: `true` のフィルターだけが働く。既定ではどれも `false`
- `words`: 止める言葉。どの言語で書いてもよく、1つの一覧に並べる。頼みごとか描く言葉にこの言葉が出たら、描かずに理由を返す
- `negative`: フィルターを入れている間、描かせない言葉にいつも足す言葉
- 新しいフィルターは、名前を付けて足せる。用意してある型は「グロテスク」「性的な表現」「暴力」「ホラー」で、どれも切ってある
- `config/filters.json` は個人の設定なので git には入れない。ファイルが無いか壊れているときは、全部切った状態で動く

英数字だけの言葉は語の単位で比べる（`bra` を入れても `braid` は止めない）。それ以外の言葉は文字列として探す。

## 固定の制限

子どもを性的に描くことだけは、設定では外せない。止めるのは次の2つ。

- 子どもを性的に描くことを指す言葉（例: loli、shota）
- 子どもを表す言葉と、性的な言葉が同じ頼みごとに並んだとき

子どものキャラクターを描くこと、大人の性的な表現や露出は、この制限では止めない。

子どもを表す言葉のある頼みごとでは、出来た絵の肌の割合も見る。肌が多く出た絵は見せずに、服を着せて描き直す
（模型が頼みごとと関係なく肌を見せる絵に寄せることがあるため）。大人の絵には掛けない。

判定は `tools/gen/filters.py` の1か所で行う。自由に描く（`tools/gen/free_text.py`）とスタジオは、そこを呼ぶだけ。

## 宗教・文化への配慮

宗教・文化の上で見る人を傷つけやすい描写（差別の象徴、預言者の姿、宗教の装いの性的な描写、着物の左前など）は、止めずに知らせる。
頼みごとを描く言葉に直したときの知らせ（notes）と、描いた絵の検品の `cultural` に出る。軍服や寺の場面では、頼まれていない印を打ち消しに足す。
止めたいときは、フィルター「宗教・文化への配慮」を入れる（差別の象徴と、宗教・文化の配慮の段の頼みごとを止める）。
決まりは `styles/cultural.json`、考え方と出典は [docs/knowledge/cultural-sensitivity.md](knowledge/cultural-sensitivity.md)。

## 確かめていないこと

- 言葉で見る仕組みなので、言い換えや綴りの崩しは拾えない（宗教・文化の配慮も同じ）
- 画像生成の模型は、頼んだ以上に体を強調した絵に寄せることがある。出来た絵の中身までは、この仕組みでは見ていない
