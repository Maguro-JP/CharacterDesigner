# ペイントソフトの引き継ぎ（CharacterDesigner から AtelIer へ）

書いた日: 2026-11-21（日本時間）。CharacterDesigner の main は 0.5.38（4a9e809f）、最新の Release は v0.5.38。

## 領域の分け方

| 領域 | 担当 | 中身 |
|---|---|---|
| ペイントソフト（人が使い、AI も使う・AI に使わせる道具） | AtelIer | `chatdraw/` の全部。描く・直す・加工・検品・模型の管理・チャット・工程に分けた描き方・タイムラプス・配布（Setup.exe） |
| 検品（作画監督） | AtelIer が開発。CharacterDesigner は連携して使う | `chatdraw/handcheck.py`、`sanity.py`、`requestcheck.py`、`qcmanual.py`、`qcparts.py`、`mirrorcheck.py`、`tools/gen/facecheck.py`、`qcbench.py`、`qcsynth.py`、`tagger.py`、`measure.py`、`normlearn.py` |
| キャラクターデザインの道具と拡張機能 | CharacterDesigner | `tools/gen/design.py`、`bible.py`、`people.py`、`demi.py`、`layers.py`、`bible/`、`casts/`、`characters/`、`styles/`、`designs/`、`tools/engine/`（3D・VRM）、`chatdraw/charadesign.py`・`charafile.py`・`to3d.py` に当たる機能 |

`chatdraw/charadesign.py`、`charafile.py`、`to3d.py`、`sheetlayout` は、今はペイントソフトの中にあるキャラデザの機能。どちらに置くかは 2 つの担当で決める（未決）。

## ユーザーの指摘のうち、まだ直っていない・確かめていない物

- 精度優先: 工程の絵が人の描く過程に見えない（最初から完成の絵、線画が色の絵の色違い、清書で汚れる、工程 2 から先で絵が変わる）。作り直しは humanpaint のブランチにあるが、本物の模型の工程ごとの絵を見せていない
- 精度優先: AI モードより遅い（種 11 で 520 秒に対して 6,892 秒）。最後の絵に崩れ（靴下の上下の色の割れ、手の指）が残る
- 加工と修正: 「綺麗にする」が効かない、リアル系の画風が絵を壊す。原因の 1 つ（VAE の型の食い違い）は直したが、前と後の絵で確かめていない
- 模型の一覧: 0.5.33 の剪定で新しい模型を取れなくなった。直しは modelscore のブランチ
- 絵の質: 0.5.24 で模型カードの質のタグと打ち消しの言葉を外してから下がった（`docs/knowledge/quality-regression-2026-11.md`）。「頼んでいない言葉を足さない」の決まりがあるので戻していない。模型ごとに入り切りできる設定として戻すかは、ユーザーの判断待ち
- 検品: 手の誤報 76%、指の数の言い切り 0%、口・顔の歪み・頼んだ物が描かれていないは 0%（`docs/knowledge/accuracy.md`）。Actions の機械で人の数の部品（rtdetr）が読めない
- 一時停止からの再開と、工程ごとに確かめる窓は、本物の模型とアプリの画面で確かめていない
- 0.5.31 以降の Setup.exe を Windows に入れて起動する確かめは、していない
- 本物の言葉の模型とマイクでのチャット・音声入力は、動かしていない
- 筆で描く（AI が筆を動かす）、枚数の欄、赤ペンなど、ユーザーの頼みの一覧は `docs/reports/user-requests.md` と `docs/reports/requests-20261113.md`

## 確かめ方の台

| 物 | 場所 |
|---|---|
| マージ前の試験 | `bash .claude/hooks/test.sh </dev/null`。`.cache` に PySide6（`.cache/simple/lib`）と描く部品（`.cache/gen/lib`）が要る。通った束は `.cache/testsh-done` に覚える |
| 本物の模型で描く比べ | Actions の `phase-bench.yml`（1 回で描く形と工程の形）、`draw-one.yml`、`finish-verify.yml`（全部の加工と修正）、`model-verify.yml`（模型の点）、`qcbench.yml`（検品の精度）、`adhere-bench.yml`（頼んだ通りか） |
| Windows の起動 | `chatdraw-e2e.yml`（入れる・起動・1 枚描く・右クリック・工程の描き方） |
| Release | main の `VERSION` を変えると `chatdraw-setup.yml` が Setup.exe を組んで Release を作る |
| 画面の無い所で描く | `tests/test_headless.py`（描く処理が PySide6 を読まない） |

Actions の機械には 2 種類ある。bf16 を速く計算できる CPU では 20 歩が約 3 分、できない CPU では 1 歩 86 秒（0.5.35 で float32 に替える前は 1 歩 2,200 秒）。秒数を比べるときは、記録の CPU の行を見る。
