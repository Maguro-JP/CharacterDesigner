# 3D の素体（MakeHuman → GLB → ブラウザ）

スマホのブラウザで回して見られる 3D の人体を作る手順と、詰まったところの記録。
道具は MakeHuman（Blender 用部品 MPFB、基本素材は CC0）と Blender（bpy）。表示は three.js。

## 手順

```sh
sh tools/engine/setup.sh   # 初回だけ。.cache/engine に bpy と MPFB を取る
PYTHONPATH=.cache/engine/bpy python3 tools/engine/model3d.py out.glb --tex 512 --head 1.12 --face anime --arms 70 \
  --outfits "casual=female_casualsuit01,shoes02;sport=female_sportsuit01,shoes05;dress=female_elegantsuit01,shoes03;tunic=female_casualsuit02,shoes06"
base64 -w0 out.glb > outfits-glb.txt   # 公開ページは .glb を置けないので、文字にして添える
```

表示のページは `tools/engine/viewer/toon.html`。`outfits-glb.txt` を同じ場所に置いて開く。
1体の書き出しは CPU で約 15 秒、4組で 5.7MB（文字にして 7.6MB）。

## 見た目の方針

- 写実の顔は見せない。利用者に「気持ち悪い」と言われた。最初の頃の、頭身を縮めて塗り分けた絵の方が日本受けした
- 形は道具の数字で寄せる（`--head` で頭を大きく、`--face anime` で目を大きく・鼻と口とあごを小さく）
- 塗りは表示の側で行う。陰を2段に丸める塗り（MeshToonMaterial）と、裏面を膨らませて暗く塗る輪郭線
- 肌は画像を使わず一色にする（写実の肌の画像は顔のしわや唇を描いてしまう）
- 目は表示の側で、瞳を大きく暗く、ハイライト付きに描いた画像に差し替える

## 着せ替え

MakeHuman は服ごとに、服の下に隠れる体の点を消す設定（MASK、名前は `Delete.<服>`）を体に付ける。
全部の服を付けたまま書き出すと、どの服を着せても、ほかの服の分まで体に穴が開く。
`--outfits` は組ごとに体を複製し、その組の服の MASK だけを残す。形の名前は `body__<組>`、`<服>__<組>`。
表示の側は名前の `__` の後ろで組を見分け、選んだ組だけを表示する。

## 詰まったところ

| 見えた崩れ | 原因 | 直し方 |
|---|---|---|
| 唇の外に歯、胸の前に背中の髪が透ける | 体・服の素材の Alpha に線がつながり、半透明（BLEND）で書き出された | 透けてはいけない素材は Alpha の線を外して 1 にする |
| 目が白目だけ | 目の膜の透けまで外した | 目と服は Alpha の手前に丸め（ROUND）を挟み、切り抜き（MASK）で書き出す |
| すねに靴の色の欠け | 靴の形が足首より上まであり、細いジーンズを内側から突き抜けた | 姿勢を焼き込んでから、裾より 2cm 上の靴の点を消す |
| 長袖が腕を下ろしても A の字のまま | 骨を服より後に付けたので、服に骨の重みが入らなかった（半袖は肩の近くなので目立たなかった） | 骨を服より先に付ける |
| 描き直した目の画像で白目だけ | 目の表面の膜は、目の画像の右下の丸 (0.935, 0.933) を使い、元は透明だった | 描き直した画像でも、その丸を透明に抜く |
| 目を大きくしたら怒った顔 | 目の高さを上げて眉との間が詰まった | 眉は eyebrows-angle-up（内側を上げる）。angle-down は余計に怒った顔になった |
| 肌が白く飛ぶ | 色の指定が sRGB のまま、線形の計算に渡っていた | `new THREE.Color(hex).convertSRGBToLinear()` |
| 表示の読み込みで止まる | 形をたどる途中で輪郭線の形を足し、足した形もたどって無限に続いた | 先に形の一覧を取ってから足す |

試して外したもの: 服の画像の台紙をにじませる処理（靴の突き抜けの原因と見誤った）。

## 公開ページの制約

- `.glb` は置けない（配れる種類に無い）。base64 の文字（`.txt`）にして添え、ページで読み込んでバイトに戻す
- 外部のスクリプトは jsdelivr などの決まった場所からだけ。three.js は 0.147.0 の `examples/js`（モジュールでない版）を使う
- 確認は Playwright と Chromium で撮る（`--use-gl=swiftshader`、`--no-proxy-server`、`python3 -m http.server`）

## まだ出来ていないこと

- 顔はまだアニメの水準ではない（顔の幅が広く平ら、髪は写実の画像）
- 腕を下ろしても肘が外に張る
- 亜人の耳・尾・角を 3D で足す

## マネキン（体型の描き分け）

`tools/engine/mannequin.py` は、MakeHuman の体を白いつや消し一色のマネキンにして、体型を正面・横・背面から描く。
目・眉・髪・肌の画像は付けない（眼球だけ体と同じ色で付ける。無いと眼窩が空洞に見えた）。

```sh
PYTHONPATH=.cache/engine/bpy python3 tools/engine/mannequin.py out/ [--gender 0.0] [--only slim,standard]
```

5体型（細身・標準・曲線的・肉付きが良い・筋肉質）で約 50 秒。体型の数字は `BODIES` に持つ。

| 詰まったところ | 原因 | 直し方 |
|---|---|---|
| 白が飛んで形が見えない | 色と光が明るすぎた | 色 0.62、主光 2.2。背景は透明で描き、一覧図で明るい灰色に載せる |
| 元の形をならしても凹凸が戻る | 体型は形の差分と骨で後から上乗せされる | 姿勢と体型を形に焼き込んでから、その形の上でならす |
| 股の前がならせない | 点の区分 genitals は体の側では0点（補助の形にだけ入っている） | 体の中心線で一番低い点（股）の少し上から半径 7cm をならす |
| 胸を MakeHuman の上限より大きくできない | cupsize と firmness は 1.0 が上限で、超えると形が崩れて平らになった | 焼き込んだ形の上で、胸の先の内側 6cm・少し上を中心に半径 17cm を膨らませる（breast_scale）。縁まで滑らかに弱め、鎖骨と下側は弱める |
| 膨らませると胸の下に段・平らな切れ | 内側を一律に膨らませて縁で急に止めた／下側を急に止めた | 弱め方を距離に沿って滑らかにし、下側も 8cm かけて弱める。1.3 倍までが自然 |
| 胸全体が平らになった | 乳首の凸をならす範囲を広げすぎた（5段・120回） | ならしは 3段・80回のまま、膨らませる前にならす |

## アニメ調の 3D 素体（VRM、2026-10-05）

アニメの比率で作られた素体として、VRM（アニメ調の人型 3D の標準形式）の公式サンプル
`VRM1_Constraint_Twist_Sample.vrm`（pixiv の three-vrm リポジトリ）を使う。メタデータの許諾は
改変・再配布可、法人の商用可、表記不要（`https://vrm.dev/licenses/1.0/`）。重いのでリポジトリには入れない。

- 表示: `tools/engine/viewer/vrm-pose.html`。three.js 0.147 と three-vrm 1.0.6（UMD 版。three-vrm 1.0.7 以降は three 0.151 以上が要り、0.148 以降は UMD の読み込み部品が無い）
- 塗りは VRM の MToon（陰2段と輪郭線）のまま
- ポーズは人型の骨ごとの回転（度）で持つ。VRM 1.0 の模型は +Z を向き、左腕は +X 側。腕を下ろすには左腕の Z を負、右腕の Z を正に回す（逆にすると万歳になった）
- 光は横の向き・高さ・主の光・回り込みの4つと、昼・夕方・夜・逆光。白い服は主の光 100% と回り込み 60% で白く飛んだので、既定を 70% と 35% にした
- 片膝立ちと構えは骨の回転だけでは崩れた（脚が上がる、腕が X 字）ので外した
- まだ出来ないこと: 体型を理想のベースに合わせる（サンプルの体のまま）、髪型・服の差し替え

## 専用ベースの 3D 素体（VRoid のサンプル、2026-10-05）

体のラインに水着や服を重ねる素体として、VRoid Studio の公式サンプル `HairSample_Female.vrm`（VRM 0.x、CC0、
性的な用途の可否も Allow）を使う。上の VRM 1.0 のサンプルは、服の下の胴が削られていて（VRoid が隠れる面を消す）水着を着せられなかった。
入手は `https://github.com/madjin/vrm-samples` の `vroid/beta/`。許諾は VRoid の公式ヘルプ（サンプル模型の利用条件）による。重いのでリポジトリには入れない。

- 表示: `tools/engine/viewer/vrm-base.html`。模型は `tools/engine/vrm_repack.py <in.vrm> <out.vrm> 1024` で画像を 1024px に縮め（8.5MB）、base64 の文字にして `base-vrm.txt` として横に置く（公開ページは .glb を配れないため）
- 体型: 胸は揺れ用の骨 `J_Sec_*_Bust1` を大きくする（肌の 408 点が結び付いている。点を動かすと貼り付けた塊に見えた）。ウエストと腰は骨の重みで点を動かす。脚と頭は骨の伸び縮み
- 水着: 肌の材質に塗る（シェーダーで、ポーズ前の体の位置から縁の線を引く）。肌から三角形を切り出して重ねる作り方は、縁が網目でギザギザになり、背面で割れた。塗る方式なら体型を変えても突き抜けない
- 普段着（サンプルのワンピース）は水着の上に重ねる。肌の絵には下だけ下着が描かれているので、水着は常に塗っておく
- 髪の猫耳は隠す（人の耳と合わせて耳が4つになる）。耳の内側の桃色（HAIR_02）が付く骨だけに付いた髪の部品を隠す

つまずいたこと:

| 症状 | 原因 | 直し方 |
|---|---|---|
| 肌と髪と顔が真っ黒 | VRoid の書き出しは、1つの模型の部分（Bodybaked と Bodybaked_1 など）が位置と法線の配列を共有している。部分ごとに `computeVertexNormals()` を呼ぶと、そのたびに共有の配列が 0 に戻り、最後の部分以外の法線が 0 のまま残った | 共有する組ごとに全部の三角形を集めて1回で計算する。同じ位置の点はまとめ、継ぎ目に光の割れ目を出さない |
| 胸の布が背中に出た。腰を広げるとお腹が出た | 骨の位置を `bindMatrixInverse` で模型の座標に直していた。three.js はこれを毎フレーム今の向きから作り直すので、VRM 0.x を前に向ける 180° 回転が混ざり、前後が逆になった | 元の `bindMatrix` の逆行列を使う。この素体は −z が前 |
| 腕組み・腰に手・歩きの膝が崩れた | VRM 0.x の回転の向きを Y と Z で反転していた。縦の軸まわりに 180° 回しているので、逆になるのは X と Z | X と Z を反転し、Y はそのまま |
| 腕組みで腕が背中へ回る、顔の前へ上がる | オイラー角（XYZ）では X が最後に効くので、上腕の X は腕のひねりではなく前後の振りになる | 前腕の向き（胸の下を水平に内へ）から肘の回転を逆算した |
| 陰の境目が背中やお尻の横で角張る | 陰2段の境を切り立てていた | 境目だけ少しぼかす（32 段の表で、0.44〜0.58 の間をなめらかにつなぐ） |
| 下の水着の上端に灰色の帯 | 肌の絵に描かれた下着のゴムがはみ出していた | 水着の上端をゴムより上に上げた |

### 亜人の部品と、下絵の道具（2026-10-05）

3D はここで一区切りにする。以後は亜人の下絵に要る部品だけを足す。

- 部品は「人・猫（獣耳と尾）・悪魔（角と翼と尾）」で切り替える。部品は骨の子にするので、ポーズを変えても付け根が動かない
  - 尾は尾骶骨（腰の骨より 2.2cm 上の背中の表面）、翼は肩甲骨（胸の付け根の高さで中心から左右 5.5cm の背中の表面）、角は額の上、獣耳は頭頂の左右
  - 背中の表面の位置は肌の点から取る（その高さで最も背中側の点）
  - 獣耳のときは人の耳（顔の模型の高さ 1.43〜1.51、横幅 0.085 より外の点）を頭の側面まで引っ込める
  - 尾があるときは、水着の後ろの上端を尾の付け根の下に下げる（尾が布から生えないように）
- 外から撮る入口 `window.tool`（kind・body・pose・view・mask）。mask は肌を緑、尾を赤、翼を桃、頭の部品を黄、それ以外を黒の単色で描く
- 撮影は `tools/engine/vrm_shoot.mjs`（Playwright、CPU の描画）。`tools/gen/demi.py` が手元に配って呼ぶ
- 画面なしのブラウザで撮るとき、舞台だけ透明にしてもページの地の色が写り込み、人物の範囲を画面全体と見誤った。html と body も透明にする

## 部品の色（2026-10-06）

- 部品の色を種ごとに変えられるのは、素材を `mainMat` で作った所だけ（`setParts` が `userData.main` の付いた素材だけ塗り替える）
- 悪魔の尾・角・蝙蝠の翼の膜は `toonMat` で作っていて、色を選んでも変わらなかった。`mainMat` に替えた。既定の色の下絵は画素が全く同じ
- 部品を足すときは、主な色の面を `mainMat`、内側や骨のような添え色を `toonMat` で作る
