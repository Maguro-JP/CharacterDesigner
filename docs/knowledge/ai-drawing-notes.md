# AI に描かせて分かったこと

画像生成の AI に良い絵を描かせるために、試したことと結果を積み重ねる帳面。
1件ごとに「こう描かせると、こうなった」「この処理をすると、ここが良くなった」を書く。
どれも、この道具・この模型・手元の CPU で試した結果で、別の模型では違うかもしれない。詳しい数字と図は各行の出典の記録にある。

## 線画

| 描かせ方・処理 | 結果 | 記録 |
|---|---|---|
| 塗った絵から、明暗の差で線を取り出す（XDoG） | 影の境目や髪の陰影まで線に拾い、二重・途切れが出る | lineart.md |
| 塗った絵を、線画として描き直させる（強さ 0.55〜0.88） | 弱いと塗りが残り、強いと別の塗った絵になる | lineart.md |
| 最初から線画として描かせる | 線が閉じ、目・瞳・手まで線で描かれる。灰色の陰影が乗る | lineart.md |
| 明るさのしきい値で白黒にする | 薄く細い線（目・瞳）が消え、顔の影が黒い塊になる | lineart.md |
| 線の細さで線と影を見分ける（black top-hat） | 細い線は残り、広い影は消える。見る幅が線より狭いと太い線の中が抜ける | lineart.md |
| 描く言葉が長い | 77 語を超えた後ろが切れる | lineart.md |

## 色

| 描かせ方・処理 | 結果 | 記録 |
|---|---|---|
| 線画を下敷きに色を描かせる（強さ 0.6、0.75） | 線は残るが、白い地が勝って色がほとんど乗らない | lineart.md |
| 線で閉じた面ごとに、参考の絵の色を1色塗る | 線は崩れず、はみ出さない。参考と位置がずれると、顔に髪の色が乗る | lineart.md |
| 参考を線画と別に色付きで描かせ、部位分けで面と色を対応させる | 色がしっかり乗る（赤い籠手、手袋、帯、道具袋）。部位分けが線画と参考で食い違う所（マント、作業着、左右の靴）は色が外れる | lineart.md |
| 部位分けの食い違いを、仲間の部位（服どうし、左右どうし）で対応させる。数画素だけの部位は無いと数える | 技師の作業着が橙に、騎士のマントが赤と黒になった。部位分けが同じ部位に入れたもの（作業着の胸当てとシャツ）は分けられない | lineart.md |
| AI の線画は顔と髪のあいだの線が閉じないことがある。線で閉じた面だけで塗る | 顔と髪が1つの面になり、顔が髪の色になる。髪・顔・肌の境目でだけ面を分けると直った。服の境目まで分けると、布の上で境目が揺れてマントがまだらになった | lineart.md |
| 参考の絵で隠れた部位（スカートの下の脚）は色の取り先が無い | 白いまま残ってスカートに白い斑点ができた。隣の面の色で埋めると消えた。部位分けの小さな切れ端を別の面にすると、襟巻きに肌色の点が乗った。小さい切れ端は面の多い方にまとめると消えた | lineart.md |
| 参考の絵の形が線画と大きく違う（剣士の参考は襟巻きが大きくなびく） | 部位の中の位置の対応がずれ、襟巻きの赤が髪に乗り、顔が暗い灰色になった。形が近い騎士・技師・魔女では外れが少ない | lineart.md |
| 色の参考を描かせると、構図によって部位分けが崩れる（なびく襟巻きを顔と取る） | 崩れた参考で色を置くと顔が赤や灰色になる。顔の色が肌に見えるかで参考を確かめ、落ちたら別の回の参考に替えると顔が肌色になった | lineart.md |
| 白い布を、明るさが真ん中の画素の色で塗る | 陰影の分だけ暗い灰色になる（剣士の袴） | lineart.md |
| 面の色を明るい側（明るさの順で 7 割の位置）の画素から取る | 剣士の袴が明るくなり、魔女の帯に紫が乗った。8.5 割まで上げると騎士の鎧が桃色がかり、肌が白く抜けた | lineart.md |
| 色を赤・緑・青で別々に真ん中を取る | 白と橙が混ざる所で、どちらでもない灰色になる。実際にある画素から選ぶと起きない | lineart.md |
| 塗った絵を部位分けで下塗りし、計算した影を置く | 元の絵の形と光が消え、汚くなる（使うのをやめた） | painting-workflow.md |
| 鉛筆のラフを下敷きに色を描かせる（強さ 0.8） | 白黒のまま返る。0.93 にすると構えを残して色が乗る | app/PLAN.md |

## 同じキャラクターを描き続ける（設定資料集、`tools/gen/bible.py`）

| 描かせ方・処理 | 結果 | 記録 |
|---|---|---|
| 毎回、思いつきの言葉で頼む | 描くたびに顔・髪・服の細部・色が変わる（AI はキャラクターを覚えない） | — |
| 変えない見た目・いつもの服・持ち物を保存し、毎回先頭に組み立てて渡す | 城門の雪の夜、大広間で座る、と場面と姿勢を変えても、茶色の短い髪・赤い襟巻き・銀の鎧・ランタンの同じ騎士に見えた（`library/samples/bible-knight-scenes.jpg`） | app/PLAN.md M15 |
| さらに色の手本を IP-Adapter（0.6）で読ませる | 保存した言葉だけの時と、似せる効き目に大きな差は見えなかった。大広間では手本に無い短い裾で太ももが出た。描かせない言葉をキャラクターごとに残す | app/PLAN.md M15 |
| 背景だけを描かせる（`no humans, scenery` と場所・世界の言葉、人物を描かせない言葉） | 人物の無い城門と大広間が描けた。保存した世界の言葉をそのまま使える | app/PLAN.md M15 |
| 持ち物を服の後ろに置き、持ち方と大きさを添えて描く（技師の大スパナ、2枚） | 検品担当が2枚とも戻した。1枚目はスパナが手に無く腰袋の小さなスパナ、背景が倉庫のよう、シャツが長袖。2枚目はスパナが柱に隠れて切れ、肩に担いでいない。腰袋から別の工具が覗く。どちらも旗が無い | app/PLAN.md M15 |
| 持ち物を見た目のすぐ後に移し、持ち物と場所ごとの描かせないもの（腰袋の小さなスパナ、樽や木箱）を足す | 検品担当が2枚とも戻した。1枚目はスパナが肩から胸元までの長さで、首の横に当てているだけ。2枚目はスパナが無く小さな円盤を持ち、手が3本、胸当てが消えた。2枚とも旗が無い。樽と木箱は消えた。文章で書いた持ち方（right hand gripping ..., resting on his shoulder）と大きさは効かなかった | app/PLAN.md M15 |
| 模型が覚えている決まった言い方（huge weapon, weapon over shoulder, oversized object）に替え、場所の言葉の先頭に banner を置く | 検品担当が2枚とも戻した。1枚目はスパナが無く、肩の筒状の棒と地面まで届く刃物が描かれ、手が1つ多い（「武器」と書いたので武器が出た）。2枚目はスパナ1本で大きさも近く旗も出たが、右手は柄を握らず垂れ、柄は宙で終わり、左の拳は柄の前に浮く。肩に担いでいない | app/PLAN.md M15 |
| 人形（MakeHuman）に IK で柄を握らせ、右肩に担がせた下絵から描き換える（強さ 0.75 と 0.85、各2枚） | 検品担当が4枚とも戻した。ただし右手が柄を握り柄が右肩に載る形は4枚中3枚で出た（言葉だけでは6枚とも出なかった）。戻した理由は頭の形で、箱を組んだ口は刃・槍・ハンマーとして描かれ、1本の両端が刃とスパナになった絵もあった。腰の道具袋とズボンの色も設定から外れた | tools/engine/pose_prop.py |
| 下絵の頭を U 字に開いた口にし、言葉に open-end wrench・U-shaped jaw、描かせないものに刃・槍・斧・袋を足す（強さ 0.8 と 0.85、各2枚） | 検品担当が4枚とも戻したが、刃・槍・ハンマーは消え、服は4枚とも設定どおりになった。2枚は柄の反対にも口が出て両口スパナになり、1枚は柄が肩に届かず胸元で終わった。0.85 の1枚は手・柄・肩・頭がそろい、腰の後ろの灰色の物だけが残った | tools/engine/pose_prop.py |
| 左腕を下ろし左手を空にする言葉を足す（強さ 0.85、4枚） | 検品担当が4枚とも戻した。4枚とも腰や太ももに袋が出て、左手はペンチや柄を握った。原因は服の欄の tool belt で、持ち物の欄で描かせないとした pouch とぶつかっていた。服の欄から外した。後から範囲を描き直す方法では、同じ物がまた描かれた。灰色の画素を白にすると輪郭線まで消えた | bible/characters/mechanic.json |
| 3通りの言葉で、持ち物の持ち方（右手で握って肩に担ぐ）を描かせる | 6枚すべてで持ち方が描けなかった。物の大きさ・数・背景は言葉で寄せられたが、手と物のつながりは言葉だけでは決めきれない | app/PLAN.md M15 |
