# 人体の比率（キャラクターの土台）

服や鎧を描く前に、中の人間を骨格の比率から組む。形を「それらしく」描くと、顔が前後にも上下にも長くなり、髪が頭より大きな作り物になった。
数字は美術解剖学で一般に使う目安。単位 H は頭の高さ（頭頂から顎まで）。

## 写実の大人（7.5 頭身）

縦の目印（頭頂を 0 として下へ）:

| 目印 | 位置 |
|---|---|
| 顎 | 1 H |
| 肩の上 | 1.33 H |
| 乳首・脇の下 | 2 H |
| 臍・肘 | 3 H |
| 股・手首 | 4 H（身長のほぼ半分） |
| 膝 | 5.5〜5.75 H |
| 足首 | 7.25 H |
| 足の裏 | 7.5 H |

横幅（正面）:

| | 男性 | 女性 |
|---|---|---|
| 肩幅 | 約 2 H | 約 1.6〜1.75 H |
| 腰幅（骨盤の最も広い所） | 約 1.4〜1.5 H | 約 1.6〜1.75 H（肩幅と同じか広い） |
| 胴のくびれ | 肩幅の約 0.65 | 肩幅の約 0.55 |

- 腕を下ろすと、肘は臍、手首は股の高さに来る。手の長さは顔の長さ（顎から生え際）と同じくらい
- 首の太さは頭の幅の約半分。肩の線は首の付け根からなだらかに下がる

## 頭

- 頭の幅は高さの約 2/3（正面）。横から見た奥行きは高さとほぼ同じ
- 頭は「頭蓋骨の球」と「その前下に付く顔（顎）」でできている。顔は頭蓋骨の球から前へ少ししか出ない
- 目は頭の高さの半分。鼻の下は目と顎の中間。耳は眉から鼻の下までの高さで、頭の中心より後ろ
- 髪は頭蓋骨の上に数センチの厚みで乗るだけ。短髪なら頭の輪郭はほぼ頭蓋骨の輪郭と同じ
- 3/4 の向き（左向き）では、頭蓋骨の球の左下に顔が付き、耳は球の中心の右に見える
- 箱庭ドット の手本（頭 11 行）の縦の割り振り: 髪4行・額2行・眉1行・目1行・目の下3行。目は頭の上から 0.64〜0.7。髪を額まで下ろして額を消すと、髪が顔より大きく見える

## 子供（4〜5 歳で約 5 頭身）

- 頭が大きく、股は身長の半分より下、脚が短い。肩幅は約 1.3 H、首は細く短い

## デフォルメへの落とし方

- 頭の大きさを保ったまま、顎から下を縮める。胴（顎から股）より脚（股から足の裏）を強く縮める
- 箱庭ドットの手本では大人 2.8 頭身前後、胴 1.25 H・脚 0.55 H ほど（`docs/knowledge/tech.md`）
- 縮めても目印の順番と、肘＝臍・手首＝股の関係は崩さない。関節の位置がずれると人間に見えなくなる
