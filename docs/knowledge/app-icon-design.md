# アプリのアイコンを AI に描かせる

アイコンの頼みは chatdraw/logo.py の icon_prompt、検品は icon_check、描き直しは draw_icon。

## 公式の手引きの要点

- 1 つの比喩（象徴）で、アプリの中身を表す。2 つまで、1 つならなおよい。飾りで主役を薄めない（Microsoft の Windows のアプリのアイコンの手引き）
- 文字を入れない。名前はアイコンの横に OS が出す（Microsoft、Apple の Human Interface Guidelines）
- 形は少なく、角も少なく。太すぎ・細すぎを避け、小さな大きさでも読める輪郭にする。細部は一番手前の層だけ（Microsoft）
- 色だけで意味を伝えない。グラデーション・透けの重ね・色の加減は最小にする（Microsoft）
- 写真を使わない。地は全面に塗り、角の丸めは OS に任せる。一番小さな大きさで確かめる（Apple。2026-11-01 の取得で本文が読めず、要点は公開されている版の言い換え）
- 正面から平らに描く。奥行きは立体の道具のときだけ（Microsoft）

## AI に描かせるとこうなった

- 「symbol inspired by CharacterDesigner」と名前だけを渡すと、絵筆・鉛筆・顔の 3 つを重ねたクリップアートになった。意図（何の道具か）を英語の文で渡す
- 色を「violet, pink and white color scheme」と書くだけでは、地にグラデーションが出た。地の色を「solid plain flat ... background」で 1 色に決め、禁止に gradient と好みに無い色を入れる
- 「rounded square」を頼むと形が縁まで広がり、余白が無くなった。角の丸い四角は描かせない

## 検品の数字（icon_check、256 画素に縮めて測る）

| 項目 | 境 | 意味 |
|---|---|---|
| ground_share | 0.97 以上 | 縁の 8 画素の帯が地の色と同じ割合。下回ればグラデーションか模様 |
| 地の色 | 組の地の色から 90 以内 | |
| off_palette | 0.03 以下 | 組のどの色からも遠い画素の割合 |
| fill | 0.08〜0.6 | 地と違う所の割合 |
| center_off | 0.08 以下 | 形の外枠の中心のずれ |
| margin | 0.06 以上 | 形と縁の間 |
| small_iou | 0.7 以上 | 16 画素に縮めて戻した形と元の形の重なり |
| edge | 0.14 以下 | 明るさの境の画素の割合（細かい描き込み） |

2026-11-01 に戻された 4 枚は、どれも off_palette・fill（0.62〜0.74）・margin で落ちる。
