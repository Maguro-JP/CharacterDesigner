# 描く前の最低限の決まり

頼みごとで特に指定しない限り守る決まりを、描く直前の言葉（打ち消し）に入れて、画像生成の模型が間違えやすい描き方を先に縛る。
決まりそのものは `styles/baseline.json`、掛ける処理は `tools/gen/baseline.py`（`free_text.full_prompt` から呼ばれる）。

## 決まりの形

| 項目 | 意味 |
|---|---|
| person | 人物の絵（1girl、1boy、woman など）に必ず掛ける |
| when | その言葉が頼みごとにあるときに掛ける |
| unless | その言葉があれば掛けない。頼んだことが決まりより先（六本腕・九尾・二刀流・帽子） |
| add | 種族から当然に付く部位（猫娘なら cat ears, cat tail） |
| negative | 描かせない言葉 |
| check | 描いたあとに、その決まりが守られたかを見る検品（`qc.body_parts`、`qc.held_items`、`qc.shoe_pair` など） |

## 分類

- 体: 腕 2 本、脚 2 本、手足の数、指 5 本、頭 1 つ、目 2 つで同じ色、耳 2 つ、尾は 1 本まで、翼は 1 対、角は左右そろう、1 人だけ
- 種族: 獣耳・尾・尖った耳・翼・角・魚や蛇の下半身・馬の下半身。人の部位と重ねない
- 持ち物: 剣・弓・カップ・杖・傘・本は 1 つ
- 身に着ける物: 靴・手袋・耳飾りは左右そろう。頼んでいない帽子と眼鏡は描かない

## 守ること

- 決まりを足すときは、なぜ要るか（why）に、模型が実際に間違えた例を書く
- 掛けた決まりは `baseline.complete` の notes で、外した決まりも理由付きで知らせる（何を勝手に足したかが見えるように）
- 決まりで縛れなかった崩れは、check の検品で拾う。拾えない崩れは `docs/ROADMAP.md` の検品の候補に足す
