# キャラクターファイル（.chara）

1 人分のキャラクターの設定と絵を 1 つのファイルにまとめる形。読み書きは `chatdraw/charafile.py`、アプリの入口は「ファイル」のメニュー（キャラクターを新しく作る・開く・保存・書き出す）と、ライブラリーの「キャラクター」のタブ。

## なぜ 1 つのファイルにするか

設定資料集（`tools/gen/bible.py` の `bible/characters/<id>.json` と、絵のディレクトリ）は道具が読み書きする置き場で、JSON・絵・キャラクターシートの PSD・参考画像の組（`refsets.json`）・LoRA の選び方が別々の場所にあった。人に渡す、別の手元へ移す、前の状態に戻す、のどれも、全部をそろえて運ぶ必要があった。.chara は、その 1 人分を zip 1 つにまとめ、設定資料集とは行き来できるようにする。

## 中身

zip の中に次を置く。

| 名前 | 中身 |
|---|---|
| `manifest.json` | 文字の設定（下の表） |
| `images/<役割>.<拡張子>` | 三面図（`turn-front` など）、表情差分（`expr-smile` など）、色の手本（`color`）など。役割の名前は設定資料集の `images` のキーと同じ |
| `sheet.psd` | キャラクターシート（三面図と表情差分を並べ、絵ごとにレイヤーにした物） |
| `refs/NNN.<拡張子>` | 参考画像の組（学習セット） |
| `thumb.png` | ライブラリーの一覧に出す小さな絵 |

`manifest.json` の欄:

| 欄 | 中身 |
|---|---|
| `format` | `chatdraw.character`。ほかの zip と見分ける |
| `version` | 形の版。今は 2 |
| `id`, `name` | 設定資料集の id と名前 |
| `created`, `updated` | 作った・書いた時刻 |
| `profile` | 見た目（`look`）、いつもの服（`outfit`）、年齢・身長・役割・性格・背景設定、描くときの決まりなど、設定資料集の文字の欄 |
| `eyes` | 目の設計（描く言葉 `tags` と意図 `notes`） |
| `expressions` | 表情の一覧（既定の 8 種に、その人物の固有の表情を重ねた物） |
| `items` | 持ち物（言葉・持ち方・大きさ） |
| `palette` | 色の見本 |
| `images` | 役割 → zip の中の名前 |
| `sheet` | キャラクターシートの PSD の名前（無ければ空） |
| `refset` | 参考画像の組の名前・言葉・zip の中の名前 |
| `loras` | 使う LoRA の参照（ファイルの名前・強さ・系統・きっかけの言葉） |
| `words` | 描く言葉（`prompt`）と禁止ワード（`negative`） |

LoRA の重みは入れない。数百 MB あり、配ってよいかは LoRA ごとに違うため。開いたとき、手元の LoRA の置き場に同じ名前のファイルがあれば使い、無ければ名前を知らせる。

## 版

`version` で形を見分け、読むときは `migrate` で 1 段ずつ今の版に上げてから使う。書くのは今の版だけ。今の版より新しいファイルは、読まずに「アプリを新しくしてから開いてください」と返す。

- 版 1: 設定資料集の JSON をそのまま `character` に入れ、絵の道を zip の中の名前に替えただけの形
- 版 2: 上の表の形。設定資料集の文字の欄を `profile` にまとめ、目・表情・LoRA・描く言葉を別の欄にした

## 設定資料集との行き来

- `from_bible(id)`: 設定資料集の 1 人と、その人のシートの PSD（`<id>-sheet.psd`）と学習セットを .chara の形にする
- `to_bible(ch)`: .chara を設定資料集に書き戻す（同じ id は上書き）。学習セットも戻す

アプリで開くと、まず設定資料集に書き戻し、キャラクターデザインのメニューの「使う人物」にもする。三面図や表情差分を描き足した分は、保存のときに設定資料集から作り直して .chara に入れる。足りない物の判定は `bible.design_status` をそのまま使う（.chara の側に別の判定を持たない）。

## 描くときに入る物

開いたキャラクターは `engine.Studio.character` に入り、描くたびに次を使う。

- 描く言葉の前に、見た目・目の設計・いつもの服・描く言葉を足す（同じ言葉は 1 回だけ）。1 つの模型の道、2 段の道、おまかせの道のどれも通す
- 禁止ワードを、その 1 回だけ描き手の禁止ワードに足す
- 参考画像（学習セットを並べた 1 枚、無ければ三面図の正面か色の手本）を、参考画像を読める模型のときだけ渡す
- 描き手に LoRA を選んでいないときだけ、その人物の LoRA を重ねる

模型に本当に渡した言葉は `chatdraw/sent.py` に残り、頼みの欄のツールチップで見られる。

## キャラデザを作る

キャラクターデザインのメニューの「キャラデザを作る…」は、キャラデザモードの流れを順に通す（`charadesign.make_design`）。

1. 設定を書く（名前・見た目・服・目・年齢・身長・役割・性格・背景設定・禁止ワード）
2. 目と表情を決める
3. 三面図を描く（正面・横・後ろ）
4. 表情差分を描く（三面図の正面の顔の中だけを描き直す。顔の枠は検品から取り、取れないときは頭の位置から囲む）
5. 検品する（1 枚ずつ作画監督に通す。読めなかった絵も崩れとして数える）
6. キャラクターシートに並べる（PSD）
7. キャラクターファイルに保存する

終わるとシートをキャンバスに開き、検品の崩れと、設定資料でまだ足りない物（`design_status` と同じ判定）を知らせる。四面図の左右・ポーズ・髪型差分・詳細の拡大はこの流れではまだ描かないので、足りない物として出る。
