# チャットと描くワード

描くワード（AI の欄の頼みの欄と、描くワードの登録）は、描画の模型への設定。チャットは、言語の模型への指示。
描くワードを文からワードに直すときに言語の模型が入るだけで、チャットに書いた言葉は描くワードではない。
そこで、チャットの文で描くワードの欄を書き換えるのは、チャットで「描くワードを〜に変えて」「描くワードに〜を足して」
「描くワードから〜を消して」「描くワードを空にして」と頼まれたときだけにした（`chatdraw/chatwords.py`）。
そのときは何をどう変えたかをチャットに 1 行で返す。

## 描くワードの欄（`Window.entry`）を書き換えている所

chatpanel.py・chatintent.py・chatplan.py・commands.py は欄に触らない（読むのは app.py）。書き換えはすべて app.py にある。

| 所（app.py の関数） | きっかけ | 前 | 今 |
|---|---|---|---|
| `chat_send` の「〜を描いて」 | チャット | 文の描く内容で欄を置き換えて描いた | この回だけその言葉で描く（`send(once)`）。欄はそのまま |
| `chat_send` の「描いて」だけ | チャット | 言語の模型に回っていた | 今の描くワードで描く |
| `chat_send` の「描くワードを〜」 | チャット | 無かった | 欄を変えて 1 行で返す（`chatwords.parse`） |
| `_plan_draw`（「10 回描いて」などの段取り） | チャット | 欄を置き換えてから描いた | `send(once)`。欄はそのまま |
| `_send_after` の操作の言葉 | 欄・チャット | 操作をしたら欄を空にした | 欄から送ったときだけ空にする |
| `text_instruction`（言葉で指示） | 右クリックの窓 | 欄を置き換えて描いた | `send(once)` |
| `fix_with_text`（登録した指示・言葉で指示の直し） | 右クリック | 欄に書いて、直したあと空にした（描くワードが消えた） | 欄に触らない |
| `offer_prompt` の「AI の欄に入れる」「入れて描く」 | 利用者が押す | 欄に入れる | 変えない（利用者が選んだ操作） |
| `_load_prompts`・`build_chip_menu`（描くワードの登録） | 利用者が押す | 欄に入れる | 変えない |
| `_entry_keys`（↑↓ で履歴） | 利用者のキー | 欄に入れる | 変えない |
| `draw_again`・`_prompt_from`・`redo_from`・`edit_image` | 履歴の絵から戻す | 描いたときの描くワードに戻す | 変えない（絵の設定を戻す操作） |
| `open_favorites` の使う | 作風の登録の窓 | 欄に足す | 変えない |

試験は `chatdraw/tests/test_autosel.py` の `test_chat_draw_keeps_words` と `test_chat_changes_words_only_when_asked`。
