# 宗教・文化への配慮

描いた絵が、特定の宗教・文化の人を知らずに傷つけるのを防ぐための知識。
決まりは `styles/cultural.json`（道具が読む）に1か所だけ持ち、ここには考え方と出典をまとめる。

## 仕組み

| 段 | どこ | 何をする |
|---|---|---|
| 頼みごと | `filters.cultural()` → `free_text.describe` の notes | 当たった決まりを1行ずつ知らせる。止めない |
| 描く言葉 | `filters.negative()` → `cultural_negative()` | 軍服・寺・旧軍などの場面の言葉があると、頼まれていない印（鉤十字、旭日旗など）を打ち消しに足す |
| 描いた絵 | `qc.auto_check` の `cultural` | 絵から読めたタグ（swastika、inverted cross、kimono など）を同じ決まりにかけ、目で確かめる所として返す。崩れ（problems）には数えない |
| 止めたいとき | フィルター「宗教・文化への配慮」 | 入れると hate と caution に当たる頼みごとを止める。既定は切ってある |

止めずに知らせるのを既定にしたのは、創作には悪役・歴史・宗教そのものを描く正当な場面があり、
良し悪しを道具が決めると描けるものが痩せるため。知らずに描いてしまうことだけを防ぐ。

## 3つの段階

- hate（差別の象徴）: 迫害・差別の歴史と結びつき、国によっては法で禁じられる。ナチスの印、白人至上主義の装い、過激派の旗、黒塗り、人種の顔の誇張
- caution（宗教・文化の配慮）: その信仰・文化の人が強く不快に感じる。預言者の姿、宗教の装いや礼拝所の性的な描写、聖典を足元に置く、北米先住民の羽根の冠、卍、旭日旗
- advise（描き方の注意）: 知らずに描くと誤りになる。着物の合わせ、仏像の入れ墨、ビンディ、侮辱の手振り、宗教の食の禁忌、逆さ十字

## 画像生成の模型で起きやすいこと

- 着物・浴衣の合わせを左前（死装束の着方）に描くことが多い。言葉では直しにくいので、描いた絵の襟を目で確かめる（数字で測る検品は `docs/ROADMAP.md` の候補）
- 軍服・将校を頼むと、腕章や襟章に頼んでいない実在の印が出ることがある。場面の言葉から打ち消しを足して防ぐ
- 寺・僧の場面で卍が描かれる。日本では寺の印でも、海外の見る人には鉤十字に見える

## 判断の目安

1. 実在の信仰の対象・聖典・聖地を、性的・嘲りの場面と結びつけない
2. 人種や民族を、顔の誇張や肌の塗りで示さない
3. 他の文化の神聖な装身具は、衣装や流行の小物にしない。使うなら、その文化の出の人物として設定する
4. 実在の国・団体の印は、架空の紋章に置き換える
5. 知らせを受けても描くかは、描く人が決める
