# 設計判断

| 日付 | 決めたこと | 理由 | 触る場所 |
|---|---|---|---|
| 2026-09-29 | 部品で組む描画器は Pillow だけで書く（numpy を足さない） | CLAUDE.md の方針。28x39 で 0.5 秒と十分速い | `tools/build.py` |
| 2026-09-29 | 座標は仕上がりのドット単位（小数可）で書き、内部で 8 倍に描く | 部品を直すときに仕上がりの位置が頭の中で追える。8 倍あれば 1px 幅でも形が残る | `tools/build.py` の `SS` |
| 2026-09-29 | 輪郭は形の外に1ドット足す（選ばなかった案: 外周を塗り替える） | 細い部品が消えないため | `outline()` |
| 2026-09-29 | 部品の境目の線は奥の部品側にだけ引く | 手前を浮かせる。同じ素材どうし・同じ group には引かない | `outline()`、parts の `group` `no_line_behind` |
| 2026-09-29 | 部品組みの戦士は別フォルダ `characters/hd2d-warrior-v4/` に置き、手打ちの v3 は残す | 比較のため。`sprite.json` は `parts.json` からの書き出しで、手で直さない（試験で一致を見る） | `characters/` |
| 2026-09-29 | 1ドットの仕上げは `touchups` に座標と色（`素材:段`）で書く | 形を直しても仕上げの意図が残る。孤立ドットの掃除の対象から外す | `parts.json` の `touchups` |
| 2026-09-29 | 設計判断は `docs/knowledge/decisions.md` に置く（`docs/decisions.md` は作らない） | long-dev の知識の置き場と一本化し、二重に書かない | このファイル |
| 2026-09-29 | 職業は `base` で既存の parts.json を引き継ぎ、部品の名前で差し替える（選ばなかった案: 骨組みの座標から部品を置く） | 骨組みは道のり 3 で要る。今は差し替えで職業を増やせれば足りる | `tools/build.py` の `load_spec` `merge_spec` |
| 2026-09-29 | 色数が上限を超えたら、使用数の少ない段から他の素材と共有する | 20 色の中で素材を増やすため。剣士では金属の輪郭を髪と、上着の暗い段をズボンと共有した | 各 parts.json の `materials` |
