| 日付 | 決めたこと | 理由 | 触る場所 |
|---|---|---|---|
| 2026-09-29 | 部品で組む描画器は Pillow だけで書く（numpy を足さない） | CLAUDE.md の方針。28x39 で 0.5 秒と十分速い | `tools/build.py` |
| 2026-09-29 | 座標は仕上がりのドット単位（小数可）で書き、内部で 8 倍に描く | 部品を直すときに仕上がりの位置が頭の中で追える。8 倍あれば 1px 幅でも形が残る | `tools/build.py` の `SS` |
| 2026-09-29 | 輪郭は形の外に1ドット足す（選ばなかった案: 外周を塗り替える） | 細い部品が消えないため | `outline()` |
| 2026-09-29 | 部品の境目の線は奥の部品側にだけ引く | 手前を浮かせる。同じ素材どうし・同じ group には引かない | `outline()`、parts の `group` `no_line_behind` |
| 2026-09-29 | 部品組みの戦士は別フォルダ `characters/warrior/` に置き、手打ちの v3 は残す | 比較のため。`sprite.json` は `parts.json` からの書き出しで、手で直さない（試験で一致を見る） | `characters/` |
| 2026-09-29 | 1ドットの仕上げは `touchups` に座標と色（`素材:段`）で書く | 形を直しても仕上げの意図が残る。孤立ドットの掃除の対象から外す | `parts.json` の `touchups` |
| 2026-09-29 | 設計判断は `docs/knowledge/decisions.md` に置く（`docs/decisions.md` は作らない） | long-dev の知識の置き場と一本化し、二重に書かない | このファイル |
| 2026-09-29 | 職業は `base` で既存の parts.json を引き継ぎ、部品の名前で差し替える（選ばなかった案: 骨組みの座標から部品を置く） | 骨組みは道のり 3 で要る。今は差し替えで職業を増やせれば足りる | `tools/build.py` の `load_spec` `merge_spec` |
| 2026-09-29 | 色数が上限を超えたら、使用数の少ない段から他の素材と共有する | 20 色の中で素材を増やすため。剣士では金属の輪郭を髪と、上着の暗い段をズボンと共有した | 各 parts.json の `materials` |
| 2026-09-29 | 右向きは絵の反転ではなく、形だけ反転して光は左上のまま描き直す（選ばなかった案: 絵の左右反転） | 同じ場面に左右の向きが並んだとき陰影が食い違わない。部品で組む描き方なら追加の手間がほぼ無い | `tools/build.py` の `_mirror` |
| 2026-09-29 | 子供の枠は、既存の職業を縮めて頭だけ戻す（transforms）。作風の決まりに子供の大きさの範囲を足す（選ばなかった案: 大人の範囲の下限を下げる） | 大人の検品を緩めずに子供を数えられる | `styles/diorama.json` の `canvas.frames`、`tools/check.py` |
| 2026-09-29 | 別の作風は、同じ parts.json から styles/<id>.json の `render` で描き分ける（選ばなかった案: 作風ごとに parts.json を書き直す） | 職業を増やすたびに作風の数だけ書く手間が要らない。作風の差（頭身、大きさ、色数）は変換と決まりに集まる | `styles/*.json` の `render`、`tools/build.py` の `restyle` |
| 2026-09-29 | 16ビット機風の数字は記憶で置き、`unverified: true` を付ける | 参考サイトに届かない。止まるより、確かめられる形で置いて後で数え直す | `styles/retro16.json` |
| 2026-09-29 | 表情集はドット絵の立ち絵では作らず、道のり3の等身の高いイラストで作る（選ばなかった案: 立ち絵のコマごとに目と口の1ドットを差し替える） | 剣士で5表情を試したところ、顔の見える範囲が 7x5 ドット程度で眉は髪に隠れ、笑いの目が×に見えるなど見分けが付かなかった。箱庭ドット でも表情は別の大きな絵で見せる | `docs/ROADMAP.md` の道のり3 |
| 2026-09-30 | 作品名と出典は `docs/references.md` に残してよい。README と PR の説明には出さない。画像は置かない（置き換え: 文書から作品名を全て外す、2026-09-30） | 参考資料として何をどこから読んだかを追えないと、同じ調査を繰り返す。写しや海賊版と見られるのは画像と表向きの説明なので、そこだけ避ける | `docs/references.md`、`CLAUDE.md` |
| 2026-09-30 | 脚の長さは変形の `below` で腰より下だけを縮めて合わせる（選ばなかった案: 部品の座標を職業ごとに描き直す） | 戦士を土台にする職業すべてに一度で効き、上半身と目の直しに触らない | `characters/warrior/parts.json` の `transforms`、`tools/build.py` の `apply_transforms` |
