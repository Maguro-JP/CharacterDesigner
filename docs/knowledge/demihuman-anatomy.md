# 亜人の体の決まり（検品の項目）

利用者のこだわり。亜人の絵は、機械の検品を通ったあと、ここを1枚ずつ目で見る。1つでも外れたら落とす。
描く指示への足し方は `casts/demihuman-cards.json` の anatomy（種ごとに animal_ears / tail / wings）。

## 耳

- 獣耳がある種は、人の耳を描かない（獣耳と人の耳で耳が4つになる絵は落とす）
- 獣耳は頭頂の左右から生える。カチューシャや髪飾り（作り物の耳）は落とす
- エルフ耳を頼んでいない種に、とがった耳を描かない（熊・鼠で出た）
- 耳の形と色は全方向で同じ（犬の立ち耳と垂れ耳、鼠の桃色と黒の食い違いは落とす）

## 尾

- 尾は尾骶骨（お尻の割れ目の上端、腰の真ん中の少し下）から1本生える
- 腰の横、ウエスト、水着の布の上から生えている絵は落とす。宙に浮いて体とつながっていない尾も落とす
- 背面の絵で付け根が見えること。正面の絵では脚の間や横から先が見えるだけでよい
- 九尾は付け根を1か所にまとめ、そこから扇状に広げる

## 翼

- 翼は肩甲骨（背中の上、左右）から生える。腰や腕から生えている絵は落とす
- 背面の絵で付け根が見えること。正面の絵では肩の後ろから翼の上端が見える
- 翼の有無と色は全方向で同じ（悪魔・竜で背面にだけ翼が出た絵は落とす）

## 角

- 角は頭の決まった位置（額の上、こめかみ）から生え、全方向で同じ数・形・色

## 肌

- 肌の色（悪魔の赤、オークの緑、ダークエルフの褐色）は全身で同じ。手や顔だけ違う絵は落とす

## 決まりを指示に足した結果（2026-10-05）

尾・耳・翼の指示（`casts/demihuman-cards.json` の anatomy）を足して、6種を多方向の1枚（正面・斜め・背面）で描いた。
通過は0種。

- 機械の検品で落ちた: 猫・犬・兎（体が画面の端で切れた）
- 目の検品で落ちた:
  - 狐: 斜め後ろだけ尾が無い。背面は尾が水着の布の上から生えた
  - 九尾: 尾が1本だった。背面では付け根が脚の陰に隠れた
  - 狼: 2方向で尾が無い。背面は尾が腰の横の布の上から生えた

言葉の指示だけでは、尾の付け根の位置と、方向ごとの尾の有無が揃わない。画像を作る AI は「尾がある」ことは描けても、「どこから生えるか」を決めていない（推測）。
次は、付け根の位置を絵の外から決める手を試す。3D の素体の腰の骨に尾を付けて各方向を描き、それを下絵にする。

## 3D の下絵から描いた結果（2026-10-05、tools/gen/demi.py）

3D の素体に部品を付けて4方向を撮り、それを下絵に描き直した（img2img、強さ 0.6、1回 約3分）。

- 猫娘: 3回目で通った（`library/samples/demi3d-catgirl.png`）。獣耳は4方向とも頭頂で形と色がそろい、人の耳は無し。尾は背中の中心から出た
  - 1回目と2回目は、斜め前で尾か耳が消えて機械の検品で落ちた
- サキュバス（強さ 0.6）: 翼と角は4方向でそろった。3回とも落ちた
  - 斜め前の人物を後ろ向きに描き直した（翼があると背中を描きたがる）
  - 細い尾（半径 1.2cm）が背面で消えた
  - 尾の先（スペード）が手の横に余分に出た
- 言葉だけで描いた周（6種中0種）と比べ、付け根の位置と方向ごとの部品の有無は揃うようになった。残る失敗は「消える」「余分に出る」「向きが変わる」で、機械の検品で数えられる

検品で分かったこと:
- 尾と角は細いので、型の縁を削ると数える点がほとんど残らない。削らずに数える
- 正面の尾は先が少し見えるだけ（150 点ほど）で、描き直しで消えやすい。決まりでも見えなくてよいので、300 点未満の向きは数えない
- 余分な部品は「人物の外」で数えると、手の上に重なって出た尾の先を見逃した。「下絵で明るかった所に出た暗い点」で数える
- 靴を履いた下絵からは、透明なサンダルが描かれた。下絵は素足で撮る
- サキュバス（2周目）: 悪魔の尾を太く（根元 半径 2cm、先 0.9cm）、スペードを大きくし、強さを 0.5 にした。1回目で通った
  - 角は額の上、翼は肩甲骨、尾は背中の中心から出て、4方向で形と色がそろった
  - 斜め前で人の耳がエルフ耳のようにとがった。頼んでいないので落とし、「pointy ears, elf ears」を打ち消して描き直すと丸い耳になった
  - 見本: `library/samples/demi3d-succubus.png`
