# 工程に分けて描く（構図 → 線画 → 塗り → 仕上げ）

人のイラストもアニメの作画も、1 回で描き上げない。前の工程で決めた物を次の工程で動かさず、工程ごとに見直す物を絞る。
アニメでは工程の間に作画監督の修正が入る（レイアウト → 原画 → 作画監督の修正 → 動画 → 仕上げ → 仕上げ検査）。
出典は `docs/references.md` の「人の描き方の工程」。ラフ・線画・塗りの順に線を処理する道具の段は `drawing-process.md`。

## 工程ごとに決める物・確かめる物・AI への描かせ方

| 人の工程 | 決める物 | 人が確かめる物 | この道具の工程（`chatdraw/phases.py`） | 検品 | 1 回だけの直し |
|---|---|---|---|---|---|
| アタリ・ラフ（レイアウト） | 人数・姿勢・配置・シルエット | 反転・縮小して釣り合い | 構図: 工程の数を半分にして早く描く | requestcheck（人数・体・頼んだ物）、sanity（余分な腕・脚・頭） | 種を変えて構図だけ描き直し、崩れの少ない方を使う |
| 下描き・線画（原画） | 顔・手・指・足の形 | 縮小して線のメリハリ | 線画: 構図の絵から線を抜き、T2I-Adapter で線に沿って描く（Painter.paint の base） | handcheck（手と指の数・形、足、顔） | 崩れた枠の中だけを描き直す（Painter.redraw） |
| 下塗り・影 | 色と、頼んだ物の塗り分け | 塗り残し | 塗り: 頼んだ物と色が描かれているか | requestcheck（描かれていない物、頼んでいない物） | 描かれていない物を前に出し、形を残す弱さ（0.35）で 1 回描き直す |
| 仕上げ（仕上げ検査） | 全体の崩れ | 全体を見直す | 仕上げ | handcheck と sanity の全部 | 手・足・顔の崩れた枠の中だけを 1 回描き直す |

## 決まり

- 工程の数は 4 つで、各工程は「描く → 検品 → 見つけた崩れを 1 回だけ直す → 次へ」。検品が通るまで回さない（0.5.20 で回したら終わらなくなった）
- 直しで崩れが増えたら、直す前の絵を次の工程に渡す
- 渡す言葉は頼みの訳と、手・足・顔の直しの言葉（handcheck.FIX_WORDS）だけ。工程ごとに知らせに出す
- 工程ごとの絵は描いた絵の下に隠したレイヤー（「工程 1: 構図」など）で置き、検品の結果を会話に出す。`.stages/<時刻>-<種>-phases/phases.json` にも残す
- 線に沿って描けない模型・直せない模型では、その工程を描かずに検品だけして次へ進む
