# 人の描き方の順番（ラフ → 線画 → 塗り）

描く模型は、色の付いた完成形を一度に出す。見た目は整うが、漫画やアニメの絵の迫力は出にくい。
人の描き手（天才でない大多数）は順番に描き、各段で決めたことが次の段の土台になる。この道具もその順番で描けるようにする。

| 段 | 人がやること | なぜ | 道具の段（`tools/gen/handdraw.py`） |
|---|---|---|---|
| ラフ | 当たりの線で姿勢・構図・比率を決める | 形の誤りを早く安く直す | `rough`: 鉛筆のラフで描かせる（塗り sketch） |
| 線画 | ラフをなぞって清書する。線は閉じる | 閉じた線の内側を一発で塗れるようにするため | `lines`: 線を抜き、切れ目を繋いで閉じる |
| 線の強弱 | 外側の輪郭と重なりの手前は太く、内側の細部は細く、力の掛かる所（重さ・曲げ・影の側）は太く。見せたくない線は細く隠す | 形の前後と重さを線だけで伝える | `weight`: 人物の外形からの距離と影の側で太さを変える |
| 下塗り | 閉じた領域ごとに平らな色を置く（バケツ塗り） | 色の割り当てを影と分けて決める | `flats`: 領域ごとに色を1つ置く |
| 影 | 光源を1つ決め、影を1段か2段で置く | 立体と光を塗りで足す | `shade`: 既存の `imgproc.py shade` |
| 仕上げ | 線を一番上に重ねる | 線が絵の骨格 | `compose` |

模型の絵はこのどの段も経ていないので、線が閉じていない、線に強弱が無い、色の面が影と混ざっている、のどれかになりやすい。
