# 描画ツール整備計画（人間・AI共通）

更新: 2026-11-19  
対象: CharacterDesigner

## 目的

人間とAIが同じ描画機能を使い、同じ編集データを引き継げる制作環境にする。AIの自由な判断だけに描画品質を委ねず、システムが許可したツール・引数・工程だけを実行する。

「コードが存在する」「画面から使える」「AIから使える」「実画像で品質が確認済み」を別々に扱う。コードやCLIが存在するだけで、利用可能・完成済みとは判定しない。

## 既存資産

### 人間向け描画

- キャンバス: レイヤー、表示・不透明度・ロック、Undo/Redo、拡大・回転・左右反転、グリッド
- ブラシ: ペン、鉛筆、筆、エアブラシ、マーカー、消しゴム。硬さ・流量・間隔・筆圧・粒子
- 図形・編集: ぼかし、スプレー、指先、塗りつぶし、グラデーション、直線、四角、楕円、多角形、正多角形、文字、移動
- 選択: 四角、投げなわ、多角形、自動選択
- 補助: 対称描画、手ぶれ補正、クイックシェイプ、スポイト、赤ペン修正

| 分野 | 既存コード | 統合状況 |

## 不足・統合が必要なツール

### P0: 共通操作基盤

1. **構造化描画操作API**
   - ブラシストローク、消しゴム、図形、塗りつぶし、選択、レイヤー操作を構造化引数で実行する。
   - 人間の画面操作もAI操作も、同じCanvas処理を通す。
   - 座標系、境界、レイヤーロック、Undo単位、失敗時のロールバックを定義する。
2. **ツール契約**
   - 入力スキーマ、前提条件、出力、失敗理由、破壊性、Undo方法、必要モデル・依存部品を定義する。
   - AIには登録済みツールだけを許可し、不正な引数は実行前に拒否する。
   - 実行ID・入力・出力・所要時間・検査結果を記録する。
3. **実行状況の可視化**
   - AIが選んだツール、工程、引数、結果、失敗理由を表示する。
   - 実際の出力と検証が揃った場合だけ成功扱いにする。

### P1: 描画能力の拡張

1. **領域ごとの指示・編集**: 複数領域やレイヤーごとに別の指示を持たせ、指定箇所だけを編集する。
2. **ポーズ・構図制御**: 骨格、ポーズ、奥行き、輪郭、ラフを視覚編集し、同じ制御データをAI生成にも渡す。
3. **顔・手の詳細化**: 既存検出・detailを再評価し、プレビュー、局所描き直し、形状・色・指本数の検査を一工程にする。試験合格まで自動適用しない。
4. **参照画像ワークフロー**: 検索→候補→作者・ライセンス確認→選択→モデル投入を一つの導線にする。参照から指示語を勝手に追加しない。
5. **比較・再現**: 同じ依頼・seed・モデル・設定で候補を並べ、差分と検査結果を比較する。

### P2: 仕上げ・品質向上

- 線画抽出・清書・線幅調整
- 色調補正・ホワイトバランス・色合わせ
- ノイズ除去・ジャギー低減・輪郭補正
- 影・リムライト・反射光・材質表現
- 背景除去・切り抜き・マッティング・動画ロトスコープ
- アニメ／写実に合った超解像

各処理は、元画像との比較・局所破壊検出に合格した結果だけを採用する。

## 実装順

1. 既存ツールを「実装あり／画面あり／AI操作あり／実画像検証済み」に分類する。
2. P0のツール契約と共通操作APIを実装し、既存機能の呼び出しを集約する。
3. ブラシ・図形・レイヤーの基本操作を人間とAIで同じテストケースに通す。
4. 既存の安全な画像処理を共通ツールとして段階的に公開する。
5. 領域編集・ポーズ制御・参照画像・局所詳細化を追加する。
6. P2の仕上げを、実画像の品質試験に合格した順に追加する。

## 品質ゲート

- 単体テストだけで完了にしない。実画像の入出力を保存し、目視比較できる資料を残す。
- 変更禁止領域の画素差は0であること。
- 形状を変える機能は、人物数・主要部位・ポーズ・輪郭などを検査する。
- 仕上げは処理実行だけでなく、目的の品質指標が改善したことを確認する。
- 依存モデルが無い・非対応・検査不能の場合は成功扱いにせず、理由を表示する。
- 学習タグや個人の好みを描画プロンプトへ無断追加しない。学習はまずツール・設定・検査の選択に利用する。

## 主な調査対象

- `chatdraw/chatplan.py`, `chatdraw/commands.py`: チャット操作
- `chatdraw/app.py`: 画面と実行経路
- `tools/gen/edit.py`, `detail.py`, `hands.py`, `poses.py`, `hires.py`, `upscale.py`, `imgproc.py`, `retouch.py`, `inking.py`, `refsearch.py`: 画像処理・描画支援
