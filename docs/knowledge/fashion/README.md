# 流行のファッション資料

最終確認: 2026-10

キャラクターデザインで「今の10代〜20代らしい服」を決めるための資料。系統・季節ごとの服・髪・小物・色を、出典つきで並べる。
対象は 2024〜2026年の日本の流行（10代〜20代、男女）。流行は変わるので、半年以上たったら中身を疑う。

## ファイル

| ファイル | 中身 | 使いどころ |
|---|---|---|
| `genres.md` | 系統ごとの表（特徴、上・下・羽織、髪型、小物、色、季節、性格や立場の手がかり） | キャラクターの性格から服の系統を選ぶ |
| `seasons.md` | 季節ごとの素材・重ね方・品目・色、行事の装い（卒業式の袴、浴衣、成人式の振袖） | 場面の季節に服を合わせる |
| `hair-items.md` | 髪型（男女、長さ、前髪、色の入れ方）と小物（鞄、靴、帽子、アクセサリー、スマホまわり） | 服が決まった後の仕上げ |
| `tags.md` | 画像生成で描かせる英語の言葉（Danbooru 風のタグ）の候補と、誤解されやすい言葉 | 描く言葉を組む |
| `sources.md` | 出典の一覧（48件、記事名・媒体・公開年月・URL） | 根拠を確かめる |
| `zukan/` | 世界の服装の図鑑（古代〜2026年、世界の伝統衣装の 135 項目、出典 450 件）。入口は `zukan/README.md` | 時代物・異国の人物の服を決める |

描く言葉の札は `casts/fashion.json`（1つの装いが1行）、見本の絵は `library/samples/fashion/fashion-*.png`（地雷系、卒業式の袴、ゴープコア、制服のプレッピー系の4枚。札の `sample` に書いた装い）。

## 使い方の流れ

1. キャラクターの性格・立場から、`genres.md` の「手がかり」の欄で系統を選ぶ
2. 場面の季節を `seasons.md` で合わせる（秋冬ならネルシャツやカーディガンを重ねる、など）
3. 髪型と小物を `hair-items.md` から選ぶ
4. `casts/fashion.json` に近い装いがあれば、その `clothes` と `hair` を元に言葉を差し替える。無ければ `tags.md` から組む
5. 描かせる: `PYTHONPATH=.cache/gen/lib python3 tools/gen/people.py card <出力> <名前> --gender female --age teen --hair "<髪>" --clothes "<服>" --views front --zoom none`

## 決まり

- 「未確認」は、信頼できる出典で確かめられなかったもの。推測で流行を作らない
- 色の16進コードは色名の目安で、出典の値ではない
- 札の装い（`casts/fashion.json`）は、出典で確かめた品目に、描くために足りない所（靴、色の組み合わせ）を作例として足したもの。札の全部が流行の事実ではない
- 本文ではブランド名・人名・作品名を使わず、一般名詞にする。ブランド名は出典の記事名の中だけ
- 露出の多い服と性的な見せ方は載せない（出典に挙がっていても外す）。札にその言葉が入ると `tests/test_fashion.py` が落とす
- 実在ブランドの写真や他人の画像は置かない。言葉と数字と出典だけ
