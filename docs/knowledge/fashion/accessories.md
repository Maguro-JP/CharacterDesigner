# アクセサリー・持ち物・服の装飾（設定の密度を上げる部品集）

最終確認: 2026-10

キャラクターデザインで、服が決まった後に「設定の密度」を上げる部品を並べる。流行の品目は `hair-items.md` にあるので、ここでは流行に依らない部品の種類、付く場所、大きさ、描く言葉、崩れやすさを扱う。

- [番号] は末尾の出典。確かめられなかったものは「未確認」。
- 描く言葉は Danbooru 風のタグ [11]。絵の読み手の模型 wd-vit-tagger-v3 の語彙（`.cache/assets/tagger/selected_tags.csv`、10,861語）と 2026-10 に照らし、語彙に無いものに ※ を付けた（`tags.md` と同じ印）。語彙に無いタグは件数が少なく、描く模型が学んでいない見込みが高い [12]。
- 大きさの目安は「頭の高さ（頭頂からあご）を1」とした比。日本の青年の全頭高の平均 234.0mm（男女合わせて 419人）[5] で割った。物の寸法に出典が無いものは「未確認」。
- 性格や立場の手がかりは、持ち物が役割・特技・趣味・好みを分かりやすくする、という設定画の考え方 [1] に沿って並べた案。決まった対応があるわけではない。

## 3. ディテールを足す順番の考え方

出典で確かめた作法:

- 全体のシルエットを決め、顔、髪型、最後に細かい服のデザインを決める。小物はシルエットの釣り合いを見ながら足したり引いたりする [1]。
- 大きい形から小さい形へ進める。シルエット、内側の大きな線、細部の順。見る人も体の比率、服、顔の細部の順で人物を見分ける。全体に細部を入れると、シルエットの内側が一様に見える [3]（記事名と年は未確認）。
- 形を大・中・小に分けて、読みやすく釣り合った絵にする [4]。
- 服の色は 3〜4色、主な色は 3色までにまとめる [1]。複数の人物を並べ、白黒にして明暗の配分が似ていないか見る [2]。

案（作法の出典は無い。このリポジトリでの段取りとして）:

1. 立場を決める大きい物を1つ（鞄、上着、職業の道具）。シルエットが変わる物から
2. 性格を出す中くらいの物を1〜2つ（首まわり、帽子、眼鏡）
3. 小さい物（耳、指、鞄の飾り、ボタンの色、縫い目）は最後。顔の近くか持ち物の近くに集め、何も無い面（休み所）を残す [3]
4. 柄は1着につき1種類。柄を足したら他の面は無地に戻す
5. 足すたびに、設定資料集の持ち物の欄に「数・左右・どの手」を書く。書いていない物が描かれたら崩れとして数えられるようにする

## 4. 画像生成で起きやすい崩れと、検品で見る所

一般に知られている崩れ:

- 部品の形のゆがみ・欠け・重複は、物の種類によらず起きる。色や質感が別の物に乗る取り違えもある [8]。
- 文字は読めない字形になりやすく、新しい模型でも抜けや綴りの誤りが残る [9][10]。刺繍・ワッペン・服の柄・鞄の表に、頼んでいない文字やロゴが出る。
- 頼んでいない形を足したり、その物の「よくある形」に寄せたりする [10]。

このリポジトリで出た例（`docs/knowledge/ai-drawing-notes.md` から要点だけ）:

| 崩れ | 起きたこと |
|---|---|
| 持ち物が2つ・別の物になる | 大スパナを頼むと腰袋の小さなスパナが別に出た。「武器」の言い方に替えると武器が出た。柄の反対の端に2つ目の頭が出て、両口のスパナになった（4枚とも）。剣1本の頼みで剣が2本出た |
| 服の欄の言葉が持ち物を呼ぶ | 服の欄の tool belt が、描かせない袋とぶつかり、4枚とも腰や太ももに袋が出た。服の欄から外すと消えた |
| 範囲の描き直しで物が増える | 宙に浮いた布を消すと、手の横に灰色の箱のような物が新しく描かれた |
| 左右の取り違え | 持ち物の手を左右で頼んでも 2枚とも守られなかった。片手だけ籠手、左右の靴が違う、が外部の生成でも出た |
| 服の指定が守られない | `long navy skirt` は色も長さも守られなかった。持ち物の崩れで戻した絵は 13枚中 2枚 |

検品で見る所:

- 数: 設定の持ち物の欄と、描かれた物を1つずつ照らす。同じ物が2つ、設定に無い物、持ち物の端に2つ目の頭。長い持ち物は物を探す模型で数える仕組みがある（`app/PLAN.md`）
- 左右: 対になる物（靴、靴下、袖口、腰の物入れ、耳）は `tools/gen/measure.py` の pairs で色の差を見る。そろった絵で 0.03〜0.06、左右で違う靴で 0.116 と出ている。形の比は部位分けの左右の取り違えで大きく振れる（腕で 3.8）ので、まだ基準にできない
- ボタン: 前立ての1列が中心を通るか、ダブルの上着で左右の列の数が同じか。数を数える検品はまだ無い（候補）
- 文字・ロゴ: 胸、背中、ワッペン、鞄の表、刺繍。描かせない言葉に `english_text`、`text_focus`、`logo`、`watermark`、`signature`、`artist_name` を入れる。絵の読み手の模型がこれらのタグを出したら戻す候補（まだ検品に無い）
- 柄: チェックやストライプの線が体の丸みと縫い目で曲がりつながっているか。細かい柄が灰色ににじんでいないかは、元の大きさで見る
- 持ち方: 手と物がつながっているか、握る手は設定の側か。言葉だけでは持ち方まで決まらず、下絵が要った（同じ記録）
