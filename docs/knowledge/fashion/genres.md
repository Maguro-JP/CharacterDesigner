# 系統ごとの流行（2024〜2026年、日本の10代〜20代）

最終確認: 2026-10

## この資料の読み方

- 載せたのは、出典で流行が確かめられた系統だけ。[番号] は sources.md の出典。
- 「未確認」は、信頼できる出典で確かめられなかったもの。推測で埋めていない。
- 色の16進コードは、出典にある色名を画面で使うときの目安として付けたもので、出典に書かれた値ではない。
- 「キャラクターに使うときの手がかり」は、系統の名前と出典の説明から引いた設定の候補で、流行の事実ではない。
- 露出の多い品目（へそ出しの短い丈のトップス、浅い股上のパンツ、極端に短いスカートなど）は、出典に挙がっていても載せていない。
- 本文ではブランド名を使わず、一般名詞にしている。
