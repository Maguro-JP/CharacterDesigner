# ファッション誌の誌面レイアウト（設定画・服装図鑑の頁を組むための資料）

最終確認: 2026-10

キャラクターデザインの設定画や、服装の図鑑の頁を「ファッション誌のように」組むための資料。頁の型、組みの決まり、誌面の傾向の違い、このリポジトリで作るときの案を並べる。

- [番号] は末尾の出典。出典で確かめられなかったものは「未確認」と書く。「案」は出典に基づかない、このリポジトリでの使い方の提案。
- 雑誌名・ブランド名・人名は本文に書かない（出典の題の中だけ）。誌面の画像は置かない。
- 出典の多くは雑誌の作り方を一般的に説明したもので、ファッション誌の頁の型ごとの寸法を数字で示した資料は見つからなかった。数字の多くは「未確認」か「案」になっている。

## 1. 頁の型

| 型 | 何を見せる頁か | 人物と物の配置 | 文字の量と置き場 | キャラクター資料での使い方 |
|---|---|---|---|---|
| 表紙 | 1冊の顔。主役の人物1人と、その号で読める中身 | 人物1人を大きく、裁ち落としで全面に置く。題字（誌名）は上に最も大きく、見出し（表紙の売り文句）はそれより小さく人物の左右に散らす [8][9][19]。バーコードは隅に場所を空ける [9] | 題字1、主な見出し1、小さい見出し数本、号数。顔の上に文字を載せない（未確認） | キャラクターの顔見せ。名前を題字の位置に、性格・役割の一言を見出しの位置に置く（案） |
| 目次 | 号の中身の一覧と頁番号 | 小さい写真を数点、頁番号と並べる（未確認） | 特集名・頁番号・短い説明。文字が主 | 設定資料集の目次。三面図・表情差分・服・小物の頁へ番号で飛ぶ（案） |
| 着回し | 少ない服を組み替えて何日分か着る様子。服に物語を付ける形がある [17] | 1日1コマで人物の全身を並べ、各コマに使った品目を小さく添える。中心になる1着を何度も出す（配置の寸法は未確認） | 日付・場面の一言・使った品目名。短い文を各コマに | 1人のキャラクターの私服の幅を見せる。同じ上着で平日・休日・雨の日、など（案） |
| コーディネート一覧（グリッド） | 多くの装いを一度に見比べる | 同じ大きさの全身を格子に並べる。小さい写真を見開きに 40〜70 点並べ、物の情報を効率よく伝える構成がある [6] | 1コマに番号と品目名の短い文。全体の見出しは1つ | 系統の候補を並べて選ぶ頁、学校・組織の全員の私服一覧（案） |
| 品目の切り抜き | 服・靴・鞄・小物を1点ずつ見せる | 背景を外した切り抜き（物撮り）を並べる。見せたい1〜2点を大きく、ほかは主張しすぎない大きさに [5] | 品目名、素材や特徴の短い説明、番号 | 持ち物・小物の設定。`accessories.md` の部品を1点ずつ並べる（案） |
| 街角スナップ | 実際に着た姿を、街の中で見せる | 人物の全身を角版（四角い写真）で、背景ごと置く。人物を中心から少しずらす（未確認） | 人物の短い紹介、着ている品目の一覧、こだわりの一言 | 場面の中の立ち姿。背景担当の背景と合わせた1枚（案） |
| 特集の扉 | 特集の始まり。題と雰囲気だけを見せる | 写真1枚を大きく、見開きにまたがって裁ち落としで置く（未確認） | 特集の題1つと、内容を短く言う袖見出し（デッキ）[2] | 章の扉。「冬の私服」「戦闘服」など設定の区切り（案） |
| 比べ | 前と後、系統どうしの違い | 同じ大きさ・同じ姿勢の人物を左右に並べる。違う所に矢印や丸を付ける（未確認） | 「前」「後」の札、違いの注記を数本 | 衣装の変更前後、季節違い、系統違いを並べる（案） |

各頁に共通する部品は、見出し、袖見出し、本文、写真の説明（キャプション）、撮影者の名前、引用を大きく抜いた文、小見出し、囲み記事、頁番号（フォリオ）[2]。号ごとに変わらない骨組み（格子、余白、頁番号の位置、文字の決まり）と、頁ごとに変わる中身を分けて考える [2][3]。

## 2. 組みの決まり

数字で書けるものを先に置く。

| 項目 | 決まり | 数字 | 出典 |
|---|---|---|---|
| 格子（段数） | 読ませる記事は 2 段、情報の頁は 4 段以上 | 2段 / 4段以上 | [13] |
| 格子（細かく割る） | 段数は 3〜5 で選ぶほか、12 段に割ると左右非対称の組みを自在に作れる | 3〜5段、12段 | [3] |
| 格子（升目） | 横の段と縦の段で升目（フィールド）に割り、写真と文字を升目単位で置く | 8〜32 升 | [1] |
| 余白 | 天・地・ノド（綴じ側）・小口の4辺を決め、頁番号と柱はその余白に置く。余白は頁をまたいで揃える | 寸法は未確認 | [3] |
| ノド | 綴じ代の分だけ広めに取る | 寸法は未確認 | [3] |
| 判型の例 | A4 変形の雑誌の例 | 297 × 225 mm | [11] |
| 裁ち落とし | 頁の端まで出す写真は、断ち切る線の外まで塗り足す。大事な物は安全域（断ち切る線の内側）に置く | 塗り足し 3〜5 mm | [9][10] |
| 写真の大きさの差 | 見せたい 1〜2 点を大きく、ほかは主張させない | 1〜2 点 | [5] |
| 角版と切り抜き | 全部を四角い写真で並べると単調になる。見せたい物は切り抜きにする | 数字なし | [5] |
| 見出しと本文の大きさの比（ジャンプ率） | 比が大きいと賑やか・若い、小さいと落ち着いた・大人の印象。拾い読みには大きい比が向く | 誌面の基準値は未確認 | [12][16] |
| 題字の大きさ | 表紙の題字は号の中で最も大きい文字。表紙の見出しは主な見出しより小さい | 数字なし | [9][19] |
| 視線の動き（横組み） | 左上から右下へ Z の形 | 数字なし | [4] |
| 視線の動き（縦組み） | 右上から左下へ N の形 | 数字なし | [4] |
| 視線の止まる所 | 題と主な写真で読むかどうかが決まる。1 か所だけ最も目立つ所を作る | 1 秒以内（伝聞） | [4] |
| 本文と図の距離 | 本文と、それを補う写真・図はなるべく近くに置く | 数字なし | [4] |
| 揃え | 水平・垂直を揃えると視線が安定する | 数字なし | [5] |
| 格子を外す | 外すときは理由のある1か所だけ。うっかり外さない | 数字なし | 未確認（解説記事の傾向） |

### 縦組みと横組み（日本の誌面）

- 縦組みは右上から読み始め、横組みは左上から読み始める。視線の型も N と Z で逆になる [4]。
- 縦組みの誌面は右に綴じて左へめくり、横組みは左に綴じて右へめくるのが一般的（未確認）。日本のファッション誌がどちらの綴じを多く使うかは未確認。
- 1頁の中で縦組みの見出しと横組みの品目名を混ぜる組み方は見かけるが、その決まりを書いた出典は見つからなかった（未確認）。混ぜるなら、本文の流れ（N か Z）を1つに決め、品目名などの短い札だけを別の向きにする（案）。

### 引き出し線と注記

- 品目の写真と名前・説明をどう結ぶか（線の角度、太さ、番号の振り方）を決めた出典は見つからなかった（未確認）。
- 本文と図を近くに置く決まり [4] と、揃えの決まり [5] から、次を案とする。
  - 注記は物の近くに置き、線は物に重ならない最短の向きで引く。線どうしを交差させない（案）
  - 線は細く1色。端の印（点や丸）は物の上に置き、文字側は揃えた縦の線に並べる（案）
  - 物が多いときは線を引かず、番号を付けて頁の端に一覧にする（案）
  - 顔・手の上に注記や線を載せない（案）

### 色数

- 誌面の色数の基準を数字で書いた出典は見つからなかった（未確認）。
- 案: 地の色1、文字の色1、差し色1 の 3 色に、写真の中の色を足す。差し色は人物の服の主な色から採ると、頁と人物がまとまる（案）。

## 3. 誌面の傾向の違い

- 日本の女性誌と男性誌（男女各3誌、12か月分）を比べた研究では、女性誌は着回しと美容の記事が多く、色の言い表し方が豊か。対象の年齢が高い誌ほど、装い中心から品目中心へ移る [7]。
- 日本の若い女性向けのファッション誌には、見開きに小さい写真を 40〜70 点並べ、商品の情報をカタログのように伝える構成がある [6]。
- 写真を主にして訴えるファッション誌が日本でどう成り立ったかは [14]、女性ファッション誌の文章の年代ごとの傾向は [15] にある（どちらも本文は未確認）。
- 日本の商用の媒体は情報が密になりやすく、高級品や工芸の媒体は余白を活かす、と両方が並ぶという見方がある [18]。これはウェブの話で、雑誌の誌面を数字で比べた資料は見つからなかった。日本の誌面と海外の誌面の違い（余白の量、文字の量）は未確認。

キャラクター資料に当てはめるなら（案）:

- 若い人物・賑やかな作風は、コマが多く、見出しと本文の比が大きい組み（一覧・着回し）
- 大人の人物・落ち着いた作風は、写真を大きく少なく、余白の多い組み（扉・切り抜きを少数）

## 4. このリポジトリで作れる形の案

描いた見本の絵（人物の全身と、小物の切り抜き）を Pillow で1頁に組む道具を作るなら、次の順に作る（案）。

1. 品目の切り抜き: 絵の隣の `.parts.png`（部位分け）を使い回して背景を外し、格子に並べて番号と名前を付ける。部位分けを2度計算しない。1〜2点を大きくする決まり [5] をそのまま数字にできる
2. コーディネート一覧: 同じ大きさの全身を N 列 × M 行に並べる。人物の頭の位置と足の位置を揃えるので、全身の外枠を測る処理がそのまま使える
3. 比べ: 2 枚を同じ倍率・同じ足元の高さで左右に置き、注記を付ける。注記の線の決まり（物に重ならない、交差しない、顔・手に載せない）を最初に入れる
4. 着回し: 一覧と切り抜きの組み合わせ。1日1コマ＋使った品目の小さい切り抜き
5. 表紙・特集の扉: 人物1人の裁ち落とし。安全域と、題字が顔に重ならないことを測る
6. 目次・街角スナップ: 背景の絵がそろってから

どの型でも、組んだ頁の検品として「文字・線が顔と手に重なっていないか」「余白が4辺で揃っているか」「格子から外れた物が理由なく出ていないか」を数字で測れる（案）。描いた絵は 1 枚ずつ元の大きさで見せる決まりがあるので、組んだ頁は絵の見せ方の代わりにはしない。
