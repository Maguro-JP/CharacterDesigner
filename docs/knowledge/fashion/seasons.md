# 季節ごとの装い（2024〜2026年、日本の10代〜20代）

最終確認: 2026-10

- [番号] は sources.md の出典。出典で確かめられなかった欄は「未確認」。
- 季節の定番の品目のうち、昔から変わらない一般的なもの（夏の半袖、冬のコートなど）は流行ではないので、この資料では扱わない。
- 色の16進コードは色名の目安で、出典の値ではない。
- 季節の行事の装い（卒業式の袴、浴衣、成人式の振袖）は、各季節の表の「行事」の行にある。
