## 使わなかったもの（理由）

- 制服の着こなしは 2026年の10代向け雑誌の記事 [34] を使った（2020〜2022 年の調査は使っていない）。
- 浴衣は地方テレビ局の店の取材 [37][38] だけを使い、通販やまとめのサイトの記事は使っていない。
- 古着店のランキング、衣料店の宣伝記事（シティボーイ、セットアップ、アメカジ）は流行の根拠にしていない。
- 男性誌の街角スナップ記事（30代以上が読者の中心）は、対象の年代から外れるため使っていない。
