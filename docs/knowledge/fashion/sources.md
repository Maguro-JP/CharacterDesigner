- 制服の着こなしの調査は 2020〜2022 年のものしか見つからなかったため、2024〜2026 年の流行としては使っていない。
- 浴衣の色の流行は、通販やまとめのサイトの記事しか見つからなかったため、根拠にしていない（seasons.md で未確認と書いた）。
