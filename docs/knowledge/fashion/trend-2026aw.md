# 2026 年秋冬の日本の流行（10 代〜20 代）

最終確認: 2026-11

## この資料の読み方

- [番号] はこの資料の 5. 出典の番号。genres.md・seasons.md の出典（sources.md）を指すときは「既存[番号]」と書く。
- 出典は 2026 年 8〜11 月に出たものを使った。期間の外のものは、出典の表に「期間外」と書き、数に入れていない。
- 1 つの流行は、互いに独立した 2 つ以上の出典で確かめたものだけを「確か」にした。同じ媒体の複数の記事（雑誌の公式ウェブの別の記事、同じ業界紙の別の記事）は 1 出典と数える。1 つの媒体だけのものは「1 出典」と書く。
- 種類は 5 つに分けた。「実売」は店や通販の売れ行き・検索の伸び、「誌面」は雑誌の公式ウェブの提案、「SNS」は SNS で広がったことを調査会社や報道が伝えたもの、「スナップ」は街の観測と撮影、「予測」はコレクション（ランウェイ）や展示会や調査の見立て。予測は街で多いとは限らない。
- 有料の記事は、無料で読める範囲（見出しと公開部分）だけを根拠にした。見出しだけのものは「見出し」と書く。
- 色の 16 進コードは色名の目安で、出典の値ではない。
- 本文ではブランド名・人名・作品名を使わない（店の売れ筋の記事の記事名の中にだけ残る。記事名に人名があるものは人名を省いた）。
- 露出の多い品目、下着風の品目、性的な見せ方は、出典に挙がっていても載せていない。出典がミニ丈を挙げた装いは、描く言葉では膝上丈と黒いタイツにしている。

## 2. 装いの表

- 品目は 1 章で「確か」にしたものだけで組んだ。確かめられなかった欄（色の組み合わせ、靴、鞄、髪の一部）は描くための作例で、「作例」と書いた。
- outfit の句は "wearing ..." に続けて使う。look の句は年齢感・髪・化粧・目で、casts/fashion.json の決まりに合わせて最後に目の色を書く。
- id は前の資料と同じ装いが残るものは同じ id にした（aw26-napoleon-f、aw26-college-f、aw26-bambi-f、aw26-preppy-denim-m、aw26-henley-m、aw26-classic-knit-m）。ほかは新しい id。
- 着方・丈・量感・色の配分まで入れた句は `docs/knowledge/learning/fashion-trend-styling.md` の 4 章にある。

## 4. 海外の流行との違い（短く）

- 海外のコレクション（2026-27 年秋冬）は、体の線を見せる服、透け、ドロップウエスト、シガレットパンツ、オフィスコア、グレーと赤 [19][40][41]。日本の若者の誌面と実売は、ナポレオンジャケット・短い丈の上着・カレッジの品・ドット・カーディガンで、体の線より形と小物で見せる方へ寄っている [3][4][5][12]。色のグレーと赤は日本でも誌面と街で重なった [1][20]。
- 海外のメンズのコレクションは、詩人や学生を思わせるクラシック、タータン、懐かしいニット、赤、細い線 [31]。日本の男子では、クラシックとチェックと赤は男性誌と店と街で重なったが、細い線は店が「まだ限定的」で、売れているのはバレル・ワイドのパンツ [3][30]。
