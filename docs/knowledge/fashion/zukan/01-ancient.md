# 古代（紀元前〜西暦500年ごろ、一部は900年ごろまで）
最終確認: 2026-10
この時代の服の多くは、織機で織った長方形の布をほとんど裁たずに体に巻き、留め具（ピン、ブローチ、帯）で形を作る「巻く・掛ける服」だった（エジプト、ギリシャ、ローマ、インド）。
一方、ユーラシアの草原で馬に乗る人々は、筒袖の上着とズボンという「裁って縫う服」を育て、それがペルシア、中国北方、朝鮮半島を経て古墳時代の日本にまで届いた。
東アジアでは絹を使う上下つながりの長衣（深衣）が礼の服となり、7〜8世紀の日本は唐の制度をまねて位ごとに色を決めた朝服を定めた。
アメリカ大陸では、綿を腰機で織った布が税や贈り物にもなるほど重んじられた。

### アケメネス朝の宮廷衣（Achaemenid court robe）
| 欄 | 中身 |
|---|---|
| 時代 | 前550年ごろ〜前330年 |
| 地域 | ペルシア（現在のイランを中心とする帝国） |
| 着た人 | 王、貴族、宮廷の人々（男性）。同じペルシア人でも、乗馬の場では「騎兵の服」（メディア式）を着た。女性の服は資料が少ない |
| 一言 | 1枚の布を幅の広い帯で締め、極端に広い袖と段になった襞のスカートを作る長衣 |
| 上・下・羽織 | 宮廷衣: 首から足首までの1枚の長衣を幅広の布帯で締め、下は段の襞になる。袖は肩に跳ね上げられる。袖なしの襞のある胴着も。騎兵の服: 体に沿う上着とズボン、空の袖を肩に掛ける長い外套（カンデュス） |
| 素材 | 未確認（布の種類までは出典で確かめていない）。カンデュスには毛皮の縁や毛皮製もあった |
| 色・柄 | 王の長衣はもとは赤か紫で、同心円と蓮の花の模様、縁と襞には青い帯に赤い獅子の行列。ギリシャ人はペルシアのズボンの色の多さを書き残した。目安: 紫 #5B2A6E、赤 #9E2A2B、青 #2E4A8B、金 #C9A227（目安） |
| 髪・頭 | 宮廷衣には鉢巻きか、溝の入った高い帽子。王は胸壁の形の高い冠。騎兵の服では柔らかく尖った帽子 |
| 小物・靴 | 首輪（トルク）、腕輪。短剣（アキナケス）を腰に下げる。王の前では手を袖に入れる作法があった |
| 背景 | 移ってきたイラン系の人々は、寒暖の差が大きく馬に頼る草原の暮らしから「帽子・体に沿う上着とズボン・長袖の外套・長靴」を持ち込み、ペルシア人はそれとは別にメソポタミアの襞のある衣を取り入れて宮廷の服にした。研究者は前者を「騎兵の服」、後者を「宮廷衣」と呼び分けている |
| キャラクターの手がかり | 大帝国の王、太守、宮廷の取り次ぎ役、外交の使者。同じ人物が宮廷では襞の長衣、遠征では乗馬の服、と場面で着替える使い方が考えられる |
| 描く言葉 | achaemenid persian, long robe, wide sleeves, pleated robe, wide sash, tall cylindrical hat, purple robe, gold jewelry, torque |
