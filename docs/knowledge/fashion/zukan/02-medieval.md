# 中世（500年〜1450年ごろ）
最終確認: 2026-10
ユーラシアの東西で、宮廷の服は「誰が何色・何の布を着てよいか」を決める道具として細かく定められた（ビザンツの紫、アッバース朝の黒、宋の位ごとの袍の色、日本の位袍）。絹と金の織物は交易と征服で広がり、モンゴル帝国は職人を移して金襴（ナシージ）を東西に流した。ヨーロッパでは1330年ごろの仕立ての変化（袖を別に付ける）から体に沿う服と男女の服の分かれが進み、日本では平安の重ね着から、下着だった小袖が表に出る流れが室町に始まる。

### ビザンツ帝国の宮廷服（Byzantine court dress: chlamys, loros）

| 着た人 | 男性: 皇帝と文武の高官。女性: 女性でクラミュスを着てよいのは皇后だけ。ロロスは皇帝・皇后と最上位の高官12人、近衛 |

### 西ヨーロッパの宮廷・都市の服: コット、シュルコ、ウープランド、エナン（Cotte, surcote, houppelande, hennin）
| 欄 | 中身 |
|---|---|
| 時代 | 13世紀〜14世紀前半はコットとシュルコ、1400年ごろ〜15世紀前半はウープランド、エナンは15世紀（第3四半期に廃れる） |
| 地域 | フランス、イングランド、ブルゴーニュ公国、フランドル（イタリアではウープランドをチョッパと呼ぶ） |
| 着た人 | 貴族と富裕な町の人の男女。13世紀は男女の形がほぼ同じで男性が少し短い。14世紀半ばから男性は短く体に沿う服、女性は長い衣に分かれる。ウープランドは男女とも着て、男性は若者が短く年長者がふくらはぎ〜足首の丈 |
| 一言 | 13世紀は丸襟で袖の細い毛織の衣（コット）に脇の大きく開いた袖なしの上衣（シュルコ）を重ね、15世紀初めは肩から深い襞が流れ床まで届く広い袖の長衣（ウープランド）になる |
| 上・下・羽織 | 13〜14世紀: 亜麻のシャツ、コット（腰帯でたるませる）、シュルコ、儀式用のマント、男性は頭巾（シャプロン）。14世紀後半〜: 男性は胴着（プールポワン）と脚にぴったりの脚衣（ショース）、女性は体に沿うコット・アルディ。15世紀初め: その上にウープランド（高い立ち襟、毛皮の裏、裾や袖の切り込み飾り） |
| 素材 | 毛織物（13世紀に紡ぎ車の糸で安く丈夫な布が増えた）、イタリア商人が運ぶ色のよい毛織物と紋織の絹、15世紀は絹のビロード、毛皮（リス・テン・オコジョ） |
| 色・柄 | 13世紀に青が流行。襟や縁に刺繍と金の飾り帯（オルフロワ）、15世紀は濃い無地や大柄の紋織と切り込み飾り（ダギング）。目安: 青 #2E4E8F、深紅 #7A1426、深緑 #1E4D3A、オコジョの白 #F2EFE6（目安） |
| 髪・頭 | 13世紀の既婚女性は顎の下を通す白い布（ギャンプ、ウィンプル）や筒形の帽子。15世紀初めは髪を網に入れ詰め物の輪をのせた角のような被り物、のちブルゴーニュで円錐形の枠に布を張り薄いヴェールを流すエナン。男性は尾の付いた頭巾シャプロンを帽子のように巻く |
| 小物・靴 | 金属飾りの帯、刺繍の袋（男女とも）、14世紀後半から先の極端にとがった靴（プーレーヌ） |
| 背景 | 13世紀末から毛皮や絹を制限する奢侈禁止令が出た。1330年ごろ袖を丸く裁って別に付ける仕立てが生まれ、ボタン留めと合わせて体に沿う服が可能になり、男女の服がはっきり分かれた。百年戦争の時代、ブルゴーニュなどの宮廷は高価な布を競い、高い被り物は説教者に非難されるほど目立った |
| キャラクターの手がかり | 男女の服の差が小さい13世紀の若い貴族、宮廷の流行を先取りするエナンの貴婦人、毛皮の裏を見せる商人の家長、の候補（創作の案） |
| 描く言葉 | medieval, long dress, surcoat, sleeveless overdress, wimple, veil, houppelande, hennin, cone hat, wide sleeves, fur trim, dagged sleeves, burgundian |
