# 近世（1450年〜1800年ごろ）の世界の服装
最終確認: 2026-10

ヨーロッパでは、イタリアの絹織物とスペインの黒、のちにフランス宮廷の流行が各国の宮廷に広がり、服で身分を分ける奢侈禁止令がくり返し出されている。
アジアでは、オスマン・サファヴィー・ムガルの宮廷が絹と頭の被り物で忠誠と位を示し、明は位を胸の補子で、清は髪型と袖口で示している。
日本では小袖が男女の表着になり、江戸の後半には町人が流行を作り、禁令の中で茶・鼠・縞の「粋」を楽しんでいる。
西アフリカと南米アンデスでも、輸入された絹や欧州の図柄を取り込みながら、王族の織物が身分の印として続いている。

| 地域 | スペイン（ハプスブルク宮廷）、イングランド（テューダー朝、エリザベス1世の代） |

| 背景 | 新大陸のログウッド（palo de Campeche）で深く光る黒が染められるようになり、高価な黒が富と節度を同時に示した。スペインではブルゴーニュ宮廷の黒と、対抗宗教改革の謙虚さの黒が重なったとされる。英国は奢侈禁止令で身分ごとの布を決め、女性にも1574年から適用、1604年に廃止 |

### 船乗りの服（海賊の時代を含む）（Sailor's slops, petticoat breeches）
| 欄 | 中身 |
|---|---|
| 時代 | 1600〜1800年ごろ（英海軍の水兵に正式の制服ができるのは1857年） |
| 地域 | 英国と欧州の船（商船・海軍） |
| 着た人 | 水夫・水兵などの働く男。士官も18世紀後半には船上でズボンをはくようになる |
| 一言 | 陸の働く男と同じ形の服を、船の売店で既製服として買って着る。動きやすいゆるい下衣が目印 |

| 素材 | 丈夫な麻、帆布、羊毛（帽子や靴下）、木綿はまれ |
| 色・柄 | 下衣は白か薄茶、上着は灰・青・茶。格子や縞のシャツ、縞の半ズボン（1706年の契約にある）。目安: 帆布 #D9CDB0、紺 #2B3A55、灰 #7C7F80、タールの黒 #2A241E |

| 小物・靴 | 首巻きの布、ナイフ。靴は四角いつま先の黒い革靴に留め金で、陸や寒い時だけ靴下と一緒に履く |
| 背景 | 船の売店（slop chest）の既製服の仕組みは1623年に記録があり、陸の仕立て服と違う「既製」が船乗りの特徴だった。ペチコート・ブリーチズは17世紀中ごろの紳士の流行が船乗りに残ったもので、ズボンは身分の低い労働者の印でもあった。現存する16〜17世紀の水夫の服にはロープを引いたタールの跡と継ぎが残る |
