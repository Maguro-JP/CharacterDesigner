# 19世紀の服装（1800年〜1899年）
最終確認: 2026-10

欧米の女性服は、胸の下で切り替えた細い円筒形（1800年ごろ）から、肩の広いロマン主義期、鐘形のクリノリン（1850〜60年代）、後ろに膨らみを寄せたバッスル（1870〜80年代）へと、腰の位置と裾の形が大きく動いた。男性服は逆に色と飾りを減らし、暗い色の上着と長ズボン、シルクハットへまとまっていった。
同じ世紀に、西洋式の服装と軍服が日本・オスマン帝国・インドなどへ広がり、各地で在来の服と組み合わさった。いっぽう清の中国、南米の牧畜地帯などでは在来の服が続いた。後に「スチームパンク」と呼ばれる架空の作風は、主にこの世紀半ば〜後半の欧米の服を元にしている（項目 7 と 8 に書く）。

### 8. 19世紀の軍服の流れ（Military uniform in the 19th century）

|---|---|

| 地域 | ヨーロッパと、その植民地（インドなど） |

| 色・柄 | 世紀の前半は国ごとの目立つ色（未確認: 個別の色）、後半に戦場で目立たない土色へ。目安: カーキ #A8956B、黒革 #1C1A18、紺 #232D4B、赤 #A3272B |
