# 1900年〜1945年 世界の服装（コルセットから配給服まで）
最終確認: 2026-10

コルセットで体を S 字に形づくる 1900 年代から、ポワレやシャネルらがゆるい筒形と動きやすさを広め、1920 年代には膝下丈・低い腰線の服が都市の若い女性の装いになった。1930 年代は腰線が元の位置に戻り、夜の服は体に沿うバイアスカットになった。1940 年代は戦争で布が割り当てられ、簡素な服が求められた。
同じ時期、日本では女学生の袴と銘仙の着物、上海では旗袍、メキシコではテワナの服、インドではカディ（手織りの綿布）が、近代化・民族の誇り・独立運動と結びついて形を変えた。

### ベル・エポックの S 字シルエットとギブソン・ガール（S-bend silhouette / Gibson Girl）

### フラッパー（Flapper / la garçonne）
| 欄 | 中身 |
|---|---|
| 時代 | 1920 年代。筒形は 1918 年ごろから。裾は年ごとに上下し、1925〜27 年ごろが最も短い |

| 背景 | 戦争で女性が働き、多くの国で参政権を得たことが、体を締めない服と短い髪に重なった。ただし膝そのものはほとんど出しておらず（膝丈より上の裾は誤解）、コルセットも長い形で着続けた人がいた。ジャズとダンスの流行が、動ける服を求めた |
| キャラクターの手がかり | 候補として: ダンスホールの常連、新聞社や会社で働く女性、古い家柄に反発する令嬢、慈善ショーを開く地域の名士。描くときは裾を膝下に置き、露出ではなく軽さと動きで時代を出す |
| 描く言葉 | flapper, 1920s, bob cut, cloche hat, drop waist dress, knee-length dress (below knee), beaded dress, fringe, pearl necklace, long necklace, art deco |
