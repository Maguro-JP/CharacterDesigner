# 1946年〜1999年の若者文化と流行
最終確認: 2026-10

戦後の物の不足が終わると、パリのオートクチュール（ディオールのニュールック）が先に形を決め、1950年代からは収入と暇を得た10代が自分たちの服を持つようになった。
1960年代のロンドンとパリで若者向けの既製服と短い丈が広がり、1970年代以降は音楽の集まり（パンク、ヒップホップ、グランジ）が服の型を生んだ。
日本では銀座・原宿・渋谷の街ごとに若者の「族」が現れ、1980年代のデザイナーの服、1990年代の裏原宿へと続く。アフリカのコンゴや韓国にも、独自の若者の装いが育った。
