# 2000年〜2026年の世界の流行
最終確認: 2026-10

2000年代は、雑誌とテレビの有名人と、ブログや写真共有の始まりが流行を運んだ（ロゴ、低い股上、ジャージ素材、日本では渋谷と原宿の系統）[2][3][6][13]。2010年代は SNS と通販で流行が細かく分かれ、ストリートと運動着が高級品の側に入り、普段着そのものが流行になった [27][30][33]。2020年前後からは、短い動画の場で「〜コア」と呼ばれる美学が次々に生まれ、同時に各地域が自分の伝統の服を今の服として着直す動き（漢服、アフリカの布、モデスト・ファッション、チョリータの装い）が目立つ [43][55][58][64][70]。

日本の2024〜2026年の系統（バレエコア、令和版森ガール、地雷系、量産型、韓国系、ゴープコアなど）は `docs/knowledge/fashion/genres.md` にあるので、ここでは重ねない。

この章の読み方:
- [番号] は末尾の出典。出典で確かめられなかったものは「未確認」と書いた。
- 色の16進コードは、出典の色名を画面で使うための目安で、出典に書かれた値ではない（森ガールの4色だけは出典 [17] に値がある）。
- 露出の多い品目（へそ出しの短い丈のトップス、浅い股上を見せる着方、極端に短いスカートなど）は、出典に挙がっていても載せていない。
- 本文と描く言葉ではブランド名を使わず、一般名詞にしている。存命の人の名は書いていない。
