# 今も着られる世界の伝統衣装・民族衣装
最終確認: 2026-10

古い形のまま残った服は少ない。ここに載せた服の多くは、19世紀から20世紀にかけて、植民地支配・国家づくり・独立運動・観光の中で形を整え直された（旗袍、アオザイ、ブーナッド、ディアンドル、フラメンカ衣装、アロハシャツなど）。
いまは日常着として残る服（サロン、カンガ、ディシュダーシャ、サルワール・カミーズ）と、祝日・儀礼・式典の服になった服（韓服、デール、キルト、マオリの外套）に分かれる。
信仰や民族の誇りと結びついた服が多く、外の人が着るときは、着方の決まりと「誰が・いつ着てよいか」を先に確かめる必要がある。

| 欄 | 中身 |

| 時代 | 現代も着用。小袖を表着にする形は室町時代（1338〜1573年）から、幅の広い帯は18世紀から。「着物」という語が広く使われるのは19世紀半ば |
| 地域 | 日本 |
| 着た人 | 男女とも。いまは成人式・結婚式・茶道・夏祭りなど行事で着ることが多い（行事の具体的な割合は未確認）。未婚の若い女性の礼装は振袖、浴衣は男女とも夏の外出着 |

### 旗袍と漢服（qipao / hanfu）
| 欄 | 中身 |
|---|---|
| 時代 | 現代も着用。旗袍は満洲族の衣服をもとに1920年代の上海で今の形になり、1929年に中華民国の礼服の一つに定められた。漢服の復興運動は2003年ごろから |
| 地域 | 中国、香港、台湾、シンガポールなど華人圏 |
| 着た人 | 旗袍は女性。1920年代は女学生と都市の女性、のち社交の場の正装。漢服はいまの主に若い男女（19〜24歳が最も多いとする調査がある） |
| 一言 | 旗袍は立ち襟と脇の切れ込みを持つ一続きの服。漢服は交差した襟と広い袖の長衣 |
| 上・下・羽織 | 旗袍（ワンピース）。漢服は襦・裙・袍など時代ごとに多様（細目は未確認） |
| 素材 | 旗袍は絹・木綿・毛。漢服は絹・化繊 |
| 色・柄 | 旗袍は無地から花柄の錦まで。目安（目安）: 赤 #b3122e、金 #c9a227、黒 #1a1a1a、淡青 #9ec5d8 |
| 髪・頭 | 1920年代の旗袍は短髪と合わせた。漢服は結い上げた髪に簪 |
| 小物・靴 | 旗袍は蛙の形の結びボタン（盤扣）、ハイヒール。漢服は扇、簪 |
| 背景 | 旗袍は、伝統の長衣が男性の服だったことを踏まえ、女性の解放や平等を求める動きの中で都市の女性が着た服として始まり、西洋の流行に合わせて丈が短く体に沿う形になった。襟の合わせは右衽（漢民族の衣服は古来右衽）。漢服の復興は2001年のAPEC首脳会議の装いをきっかけに「伝統の服とは何か」が議論されたことに始まり、祭りや名所で着て写真を撮る楽しみ方が広がっている。運動には民族意識の面があり、研究者の評価は分かれる。外の人が旗袍を着ることは広く見られるが、仮装として誇張しない（具体的な指針は未確認） |

|---|---|
