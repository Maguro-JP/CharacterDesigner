# 人がしわ・線の強弱・左右の目の差を何から決めているか（調べたこと）

前に、しわを乱数の場所に引き、両目を一律にずらし、面と線に雑音を掛けて「人らしさ」とした。理由の無い揺れは雑に見えるだけで、
人の描き手は模型より細かく、理由から位置と形を決めている。ここにはその理由だけを、本文で確かめた出典付きで書く。
本文で確かめられなかったことは「確かめていない」と分けて書く。

## 1. 服のしわ

本文で確かめたこと:

- しわは体の出っ張りの上には出ない。出っ張りに布が引っかかり、余った布が下へ引かれて垂れる所に出る。向きはその流れになる。
  慣れないうちは裸の体を先に描き、服を着せるように描く（CLIP STUDIO 講座 151672）
- 部位ごとの位置と向き（同 151672）

  | 部位 | しわの出方 |
  |---|---|
  | 肩・腕 | 肩の出っ張りには無い。脇から肩筋の終わりへ細かいしわ。袖は中身があるのでしわになりにくく、袖先へ引かれるしわ |
  | 肘 | 曲げた内側に布が寄り、内側から肘の出っ張りへ走る |
  | 胸・腰 | 胸の出っ張りの上には無く、すぐ下に細かいしわ。腰を締める服は三角形の寄りじわ |
  | ズボン | 脚はつっぱってしわになりにくい。留め具の位置から股へ向かうしわ。脚を上げると膝が最も強く引かれる所（159937） |

- しわは服のつなぎ目（縫い目）から描き始める。服は布を縫い合わせて作るので、縫い目に引かれる。やみくもに描かない（149934、159937）
- 強いしわは力点の近くと画面の手前に置く。浅いしわや遠くの人物に強いしわを描くと立体感が無くなる（149934）
- しわは体を包む形に沿わせ、体のふくらみを補う目的で描く（149934）
- 線の形はしわの種類で決める（149934）
  - つっぱりじわ（腕の付け根、膝の上など力のかかる所）: まっすぐな線
  - 溜まりじわ（袖口、裾を入れた所）: 中に空間があるつもりで緩い線
  - 重なりじわ（袖をまくった所）: 力がかからないので直線を避ける
- 素材で密度を変える（151672、149934）
  - 厚手は直線的で大きなしわ。薄手は体の線に沿った細かいしわ
  - 体にぴったりの服に大きなしわを入れると、ゆるく見える
  - 薄いシャツは細かく影が鋭い。マットな生地は強いしわが出にくく、体の線を補う程度。革は細かいしわを描かず、強いハイライト
- ぴったりした服は体の形に沿い、ゆったりした服は引かれる所から下へ垂れるしわが多い。止まっている時は重力で下がり、
  曲げるとくぼみ、ひねりに沿ってしわが出る（159937）
- 影は柔らかい縁と硬い縁を混ぜる。いちばん暗いのは布が押しつぶされて光が遮られる所（159937）
- 省略: 強くデフォルメした絵ではしわを多く描かない。体が描けていれば、しわを忠実に描かなくても決まる。
  体の線を見せたい絵はしわをしっかり描く（151672）。全部を描く必要は無い（159937）

しわの種類（Bridgman の分類、Proko が講座にしている）: 名前は pipe・diaper・half-lock・spiral・zigzag（compression）・drop（flag）・inert の7つ。
本文で原因まで確かめられたのは2つだけ（swintonsart.com の解説）。
- diaper: 2つの支点から布が落ち、その間がたわむ。たわみは真ん中でなく片側に寄せる
- half-lock: 布の下の形が曲がる・平らになる所

確かめていないこと: 残りの種類の原因（Proko の本文は有料の動画の中）、アニメ塗りでしわを線と影のどちらで、何本描くか。

## 2. 線の強弱

本文で確かめたこと:
- 手前と中ほどの物の下側に太い線を足すと、奥行きと影が出る（Proko の講座の説明）
- しわの線は力点の近くと手前を強く（149934。上の1と同じ）
- 革の縁の縫い目は太めに（149934）

確かめていないこと: 外形を太く内側を細くする、光の反対側を太くする、という一般によく言われる決まりは、今回本文で確かめた出典が無い。

## 3. 左右の目の差

本文で確かめたこと（CLIP STUDIO 講座 176083。左右ではなく手前・奥で説明している）:
- 斜めの顔では、奥の目は遠近で横幅が狭くなる。手前を 1 として奥は 0.7 くらい
- 奥の瞳は手前より少し細く縦長に描く
- 目頭の側は正面に近く、目尻の側は側面へ回り込むので、目尻の側はまつ毛の裏が少し見える
- 目と目の間は、中心線から手前の目頭までの距離の半分くらい

つまり差は、わざとずらして付けるものではなく、頭の立体と向きから決まる。正面の顔では大きな差は出ない。

確かめていないこと: 表情（片目をつぶる、片眉を上げる）による差の付け方。
