# 完成の1枚絵（背景つき）

利用者の基準: キャラクターデザインとの一致より、絵として整っていること。矛盾やあり得ない形が無いこと。背景も作り込むこと。
道具は `tools/gen/layers.py`（人物と背景を別々に作り、レイヤーで重ねて PSD と1枚の絵を出す）。

## なじませるとは

境界線をぼかすだけではない。人物と背景が、同じ場所・同じカメラで描かれたようにお互いを合わせる。

| 合わせるもの | やり方 |
|---|---|
| 遠近と大きさ | 背景の地平線を奥行き（Depth Anything V2 Small）から測る（見えている水平線と画面の 3% 以内で合った）。目の高さのカメラでは、立っている人の目は地平線に来る。身長 =（足元 − 地平線）/ 0.93 |
| 視点 | 背景は「目の高さ、地平線が画面の中ほど」で描かせる。指定しないと見下ろしになり、人物が巨人のように浮いた |
| 足元 | 背景から自動で判定する。水: 足首まで沈め、波紋と映り込み。濡れた面: 映り込みと影。花や草: 足が手前の物に隠れるまで奥へ下げる。地面: 光と反対へ伸びる影 |
| 前後 | 人物の足元より手前にある背景の物（ひまわり、岩、しぶき）を、人物の前に重ねる |
| 光 | 背景の明るさの 85〜96% の帯の色を光の色にする（太陽の芯は白く飛んでいて、夕日でも縁の光が白くなった）。背景が暗いほど色寄せを強く、逆光はさらに強く |
| 描き直し | 輪郭の周り・足元・影・映り込みだけを描き直す。全体を描き直すと顔や水着まで変わる |

## AI が描きがちな、あり得ない所（道具で起きないようにし、起きたら落とす）

| 起きること | 起きないようにすること | 検品 |
|---|---|---|
| 人物の周りの白い残り・境界線 | 背景のある絵の人物は、まず無地の上に描き直してから切り抜く（plainify）。背景つきの絵から直接切り抜いた人物は、縁の点を近所の背景の色と人物の内側の色と比べ、背景に近い点を取り除く（clean_remnant） | 取り除いた割合を layers.json に残す。色（白さ）だけで数える方法は、白い水着と見分けられず使えなかった |
| 水が無い所の映り込み | 映り込みを、映り込める面（地平線より下で、空の色に近いか水の色で、きめが細かい所）だけに切り抜く。面が無ければ付けない | 映り込みの 15% 以上が面の外なら落とす |
| 手前の物より前に人物が出る・花の上に立つ | 足元が花や草なら、足の 6 割以上が手前の物に隠れる所まで奥へ下げる | 足元が花や草で、足の半分以上が見えていたら落とす |
| 波紋が足首の輪に見える | 波紋は脚の上に描かない。平たく広い楕円にする | 目で見る |

検品で落ちたら、描き直しの幅を 12px、強さを 0.1 上げて最大2回やり直す。

## 試して分かったこと（2026-10-06）

- 人物と背景を1回で描くと、背景が白く薄くなった。手本の絵（白い背景のデザイン画）にも引っ張られた
- 背景だけを「人を描かない」指定で描くと、雲・海・ひまわり畑・夕日が作り込まれた
- 設定資料の気をつけの立ち姿を貼ると、絵として硬い。前に描いたポーズ付きの人物を使う（利用者の指摘）
- 背景のある絵から髪を切り抜くと、背景の色と髪の色が近いと白い塊やもやが残り、取り除くと髪がぎざぎざになる
- 描き直し（なじませ）は、手前に重ねた物を壊す。葉の後ろに隠した足が葉の上に描き戻され、波紋は足首の輪に描き替えられた。
  前景と波紋は描き直しの後に重ね直し、前景の所は描き直さない
- 検品で落ちたときに描き直しを強く広くしすぎると（強さ 0.7、幅 53px）、頭の周りの空がもやになった。やり直しは強さ 0.6・幅 41px まで
- 道具の検品は、描き直しが足を描き戻したことを正しく見つけた（足の 70% が見えている）。目で見る前に機械で止められた
