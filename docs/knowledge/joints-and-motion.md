# 関節の動かし方と、付いてくる体の動き（可動域）

人の姿勢は、1つの関節だけでは決まらない。腕を上げれば肩甲骨と鎖骨が、片足に体重を載せれば骨盤と肩が、一緒に動く。
関節が可動域の外に出ていないか（逆曲がり、首が真後ろ）と、付いてくるはずの動きが描かれているか（腕を真上に上げたのに肩が動いていない）の
2つを見る。数字は `casts/rom.json`、人形の姿勢の検査は `tools/engine/rom_check.py`。

## 1. 関節の種類と曲がる向き

| 関節 | 種類 | 曲がる向き | 可動域（度、健常な大人の目安） |
|---|---|---|---|
| 肘 | 蝶番（1方向） | 前腕が上腕の前（手のひら側）へ寄る | 屈曲 140〜150、過伸展 0（柔らかい人で 5〜10） |
| 膝 | 蝶番 | すねが太ももの後ろへ寄る | 屈曲 150、過伸展ほぼ 0 |
| 指 | 蝶番 | 手のひらの側へだけ | 付け根 90・中 100・先 80。親指は付け根 50〜60・先 80 |
| 手首 | 2方向 | 掌屈・背屈と、親指側・小指側 | 掌屈 60〜80、背屈 60〜70、橈屈 20、尺屈 30 |
| 足首 | 2方向 | 背屈（つま先を上げる）・底屈（伸ばす） | 背屈 20、底屈 40〜50 |
| 前腕 | ねじれ | 回内（手の甲が上）・回外（手のひらが上） | 各 80。回内では橈骨が尺骨の上を交差する |
| 肩 | 球 | どの向きにも | 屈曲・外転 180、伸展 50〜60、内旋 70〜90、外旋 90 |
| 股 | 球 | どの向きにも | 屈曲 100〜130、伸展 30、外転 40〜45、内転 20、内旋 40、外旋 50 |
| 首 | 背骨の積み重ね | 前後・左右・回旋 | 前屈 45〜60、後屈 75、側屈 45、回旋 60〜80（左右それぞれ） |
| 胴 | 背骨の積み重ね | 前後・左右・回旋 | 前屈 45〜50、後屈 25、側屈 25、回旋 30 |

- 蝶番の関節が逆に曲がる（肘が外へ、膝が前へ）のは、一番分かりやすい崩れ。過伸展は 0〜10 度まで
- 首が肩の線から 80 度を超えて回っている、胴が骨盤から 30 度を超えてねじれている、は人にできない（後ろを見るときは胴と足も回す）
- 指は手のひらの側にしか曲がらない。指先だけ反る、横へ折れる、は崩れ

## 2. 付いてくる動き（連動）

| 動かす所 | 一緒に動くもの | 確かめ方 |
|---|---|---|
| 腕を上げる（肩の屈曲・外転） | 最初の 30 度は肩の関節だけ。そこから先は肩甲骨が上へ回り、腕と肩甲骨がおよそ 2:1 で一緒に動く（肩甲上腕リズム）。鎖骨も持ち上がる | 腕を真上に上げた絵で、肩の線（首の付け根から肩先）が上がっているか。肩先が下がったまま腕だけ真上は不自然 |
| 片足に体重を載せる | 骨盤は体重を載せた足の側が上がり、肩の線は逆に下がる（コントラポスト）。背骨は横に S 字に曲がる。膝の線は骨盤の傾きに沿う | 骨盤の線と肩の線が逆向きに傾いているか。首の付け根からの垂線が体重を載せた足に落ちるか（`sakkan.md` の 2） |
| 頭を回す・見る | 首の回旋は 60〜80 度まで。それより後ろを見るときは、胴、骨盤、足の順に回す | 顔が真横より後ろを向いているのに、肩も腰も正面のままは崩れ |
| 前腕をひねる | 手首から先がひねる向きに回る。上腕は回らない | 手のひらの向きと、肘の曲がる向きが合っているか（肘は手のひらの側へ曲がる） |
| 肘を曲げる | 上腕の前の筋（上腕二頭筋）がふくらみ、後ろ（三頭筋）が伸びる | 曲げた腕で、力こぶの側が肘の内側にあるか |
| 膝を曲げる | 太ももの裏とふくらはぎが押し合ってふくらむ。膝頭は前に出る | 深く曲げた脚で、膝頭が前、ふくらはぎが後ろか |
| 物を持ち上げる・担ぐ | 重さの反対へ体が傾く（重い物を右に持てば体は左へ傾く）。持つ腕の側の肩が下がる | 重い物を持っているのに、体がまっすぐのままは力のかかり方が無い |

- 対になる動き: 上と下、右と左、前と後ろが釣り合う。骨盤と肩、頭と肩が逆に傾くと、体の流れが Z のように通る
- 曲げた関節の内側には、ふくらみとしわ。外側は伸びて平らになる

## 3. 確かめ方

- 人形の姿勢: `tools/engine/rom_check.py`。`pose_prop.py` は姿勢を付けた後に必ず数え、「可動域: 外れなし」か外れた関節を出す
  - 自己試験: `PYTHONPATH=.cache/engine/bpy python3 tools/engine/rom_check.py --self-test`。自然な4つの姿勢で外れなし、
    わざと壊した4つ（肘の逆曲がり 40 度、膝の前曲がり 40 度、首 170 度、手首を甲の側へ 120 度）で全部見つかる
- 絵: 検品担当が `sakkan.md` の 10（人体と重心）で、上の 1 と 2 の表を使う

## 確かめていないこと・限り

- 数字は資料で 5〜15 度違う（年齢・性別・測り方）。年寄り・子供・体の柔らかい人の幅は入れていない
- 鎖骨が腕の挙上でどれだけ上がるかの数字は、今回の検索では取れなかった（肩甲上腕リズムの 2:1 と、最初の 30 度は肩だけ、までは取れた）
- 首の回旋は 60（AAOS 系の表）と 80（WikEM・ほかの表）で割れている。検査は 80 に余裕 10 を足して見ている
- 人形の骨は人の関節と完全には重ならない。検査は骨の向きの角度で測る
