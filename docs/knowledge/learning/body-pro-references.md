# 体の目印・影・姿勢の決まり（一次資料からの抜き出し）

検品でそのまま判定できるよう、「どこに・何が・どう出たら外れ」の形で書く。
光源は左上の1つ、カメラは正面か斜め前を前提にする。出典で確かめられなかった所は「未確認」と書く。

## 0. 影の段の決まり（判定の土台）

明るい順に 光の面 → 中間調 → 境（terminator）→ 最も暗い核の影 → 反射光 → 落ち影 の段がある。

- 核の影（core shadow）は、影の境のすぐ内側に帯として出る。影の中で最も暗いのはここか落ち影で、影の奥（光と反対の縁）ではない
- 反射光は影の内側、光と反対の縁に出る。明るさは「落ち影より明るく、光の面の中間調より暗い」。反射光が光の面と同じかそれ以上に明るければ外れ
- 形の影は境から縁へ向かって少し明るくなる。落ち影は遮った物の形をそのまま写し、境は形の影より硬い
- 落ち影の境の向きは、光の向き（左上→右下）と矛盾しない。右上や左下へ伸びる落ち影は、別の光源が無ければ外れ

## 1. 体の目印が作る形と影（立ち、左上の光）

各行: 目印 ／ 形として見える所 ／ 光源左上での影 ／ 判定

| 目印 | 形 | 影（左上の光） | 外れの判定 |
|---|---|---|---|
| 鎖骨 | 首の付け根から肩先へ、ほぼ水平かやや上がるS字の細い稜。肩幅のほぼ全幅 | 鎖骨の下に細い影（鎖骨下の窪み）。右側の方が濃い | 鎖骨の線が肩幅の半分未満で切れる、左右の高さが肩の傾きと逆 |
| 胸郭の下端 | みぞおちから左右下へ開く逆V。胸骨下端の高さ | 腹の面へ折れる所に弱い境。立ちでは淡い | 逆Vが臍より下に来る |
| 腸骨稜・上前腸骨棘 | 腰骨の前の出っ張り。股関節の少し上、胴の幅の外寄り | 出っ張りの内下に短い影。水着の縁が掛かればその下に落ち影 | 腰骨の左右の高さが、骨盤の傾きと逆 |
| 膝蓋骨 | 太ももと脛の境の楕円。伸ばすと上へ上がり、上に窪み（大腿四頭筋の腱） | 膝蓋骨の下と右脇に影。上の窪みにも小さな影 | 膝の位置が「骨盤の上端〜爪先」の中点から大きく外れる、膝に影が1つも無い |
| 脛骨の稜 | 膝の下から足首の内側へ、前のやや内寄りを通る直線に近い稜 | 稜を境に右側（外側の面）が影。境は稜に沿って縦に走る | 脛の影の境が脚を斜めに横切る |
| くるぶし | 内くるぶしが高く、外くるぶしが低い | くるぶしの下に小さな影 | 内外が同じ高さ、または外の方が高い |
| 三角筋 | 肩先を覆い、上腕の外側の中ほど（三角筋粗面）で細くなる | 下端の付く所に浅い窪みの影。右肩は外側が影 | 肩の膨らみが上腕の中ほどより下まで続く |
| 大胸筋 | 胸骨から肩へ扇形に走り、腋の前の縁を作る | 腋の前の縁の下に影。胸の下の落ち影は anatomy.md のとおり | 腋の前の縁が無く、胴と腕が一枚に繋がる |
| 腹直筋 | 胸郭の下端から恥骨まで中央の縦の帯。左右の縁に浅い溝 | 縁の溝のうち右側が濃い。成人女性の普通の体格では横の区切りは淡いか見えない | 中央の縦の溝が胸の間の線と1本に繋がる |
| 大腿四頭筋 | 太ももの前。膝の上の内側に涙形の膨らみ（内側広筋） | 内側広筋の下と、太ももの外側に縦の境 | 太ももの影の境が直線で斜めに横切る |
| 腓腹筋 | ふくらはぎ。内側の膨らみが外側より低く大きい | 膨らみの下（アキレス腱へ細くなる所）に影 | 内外の膨らみが同じ高さ、膨らみの下に影が無い |

### 姿勢ごとの目印の動き

- 横: 胸郭の背は丸く、腹の前は胸郭より前に出ない。脛骨の稜は脚の前の縁そのものになる。膝蓋骨は膝の前に小さく出る
- 後ろ: 肩甲骨の内縁が背骨の両脇に縦に2本。腸骨稜の後ろは腰の窪み2つ（仙骨の上）。膝の裏は横の皺と、左右の腱の間の窪み
- 歩き: 前の脚は膝蓋骨が上がり脛の前の稜が見える。後ろの脚はふくらはぎが縮んで膨らむ。骨盤は踏み出した側へ回る
- 座り: 太ももの上の面は台の上で平らに広がり、下の面は潰れて台との境に落ち影。膝蓋骨は曲げると膝の前の角に出て、上の窪みは消える
- しゃがみ: 膝蓋骨が膝の最も前の点。太ももとふくらはぎが接する所に、隙間の暗い線と押された膨らみ
- 腕上げ: 鎖骨の外の端が上がり、三角筋が縮んで肩先が高くなる。大胸筋は伸びて腋の前の縁が斜め上へ。胸郭の下端の逆Vがはっきり出る
- 腰に手: 肘が横へ張り、腋の下に三角の隙間（背景が見える）。手を置いた側の腰骨の上に手の落ち影

## 2. 光源1つ（左上）で出来る影・出来ない影

### 出来る所（右下側）

- 形の影: 体の右側の面、首の右、腕・脚の右側。各円柱で境は長さに沿う
- 下を向いた面: 顎の下、胸の下、腹の下の端、膝蓋骨の下、尻の下の折れ目、くるぶしの下
- 落ち影: 顔→首（右下へ）、右腕→胴の右、髪→額と首、胸→腹の上、脚→地面の右下
- 反射光: 地面や反対側の脚から跳ね返り、右の脚の内側・顎の下の縁・胴の右縁に細く出る

### 出来ない所（あれば外れ）

- 体の左上を向いた面（左の肩先、左の頬、左の太ももの前上）に濃い影。遮る物が無い限り出来ない
- 体の向かい合う2面（両脚の内側）が両方とも同じ濃さで暗いのはよいが、片脚の外側だけが全面暗く、もう片脚の外側が明るいのは出来ない（両脚は同じ光を受ける）
- 落ち影が光と逆向き（左上）へ伸びる
- 反射光が光の面より明るい、または反射光の縁が背景の色と無関係な白

出典: https://www.artistsnetwork.com/art-techniques/beginner-artist/beginner-drawing-shadows-and-light-the-basics ／ 写真の一灯（左右 45〜60°、目より上）で影の側が出来る位置: https://thelenslounge.com/rembrandt-lighting-setup/ ／ https://www.photoworkout.com/?p=128237

### アニメの影（1影・2影）で省くもの・省かないもの

セル塗りは、限られた色数（地の色・1影・ハイライト、必要なら2影）で形を示す。現場では原画が色鉛筆で影の範囲を指定し、仕上げがその色で塗る。
1影・2影の厳密な定義を書いた一次資料は今回の検索で見つからなかった（未確認）。以下は塗りの段の役割としての判定。

- 省く: 中間調のぼかし、反射光（多くは省く。入れても細い1本の明るい線）、筋肉の細かい区切り（腹直筋の横の区切り、肋骨1本ずつ）
- 省かない（1影で必ず入れる）: 体の光と反対の側の形の影、顎の下と首、胸の下、腋、膝の裏、尻の下の折れ目、髪→顔と首の落ち影
- 2影を入れる所: 1影の中でさらに奥まる所だけ（顎の真下と首の付け根、腋の奥、太もも同士・腕と胴が接する隙間）。2影が1影の外にはみ出すのは外れ
- 影の境はアニメでも面の曲がりに沿う。セルだから直線でよいのではなく、直線になってよいのは落ち影の境と、硬い物（水着の縁、手すり）が作る影だけ

出典: 影指定の仕組み https://animeanime.jp/release/prtimes/20250919/248955.html ／ 色彩設計・仕上げの役割（文化庁 アニメーション人材育成講座）https://www.bunka.go.jp/animeseminar/course/course06.html ／ セル塗りの成り立ち https://dic.pixiv.net/en/a/Anime%20Coloring ／ 影の単純化と省略（研究）https://zendy.io/title/10.1002/cav.306

## 3. 姿勢ごとに崩れやすい点

### 重心線

- 立ち・歩き・腰に手: 首の付け根（頸窩）から真下へ下ろした線が、体重を載せた足の上（両足立ちなら両足の間）に落ちる。支える面の外に落ちれば倒れる絵
- しゃがみ・腕上げでも同じ。腕を片方へ上げた分、胴か腰が反対へ寄る

### コントラポスト（片脚に体重）

- 体重を載せた脚の側の腰骨が高く、その側の肩が低い。肩の線と骨盤の線は逆に傾く。同じ向きに傾いていれば外れ
- 体重を載せた側の胴は縮み（脇腹に皺か折れ目）、反対側は伸びる
- 体重を載せた脚は、足首が頸窩の真下近くへ斜めに入る。遊脚は膝が少し前に出て、腰骨が下がった側
- コントラポストの立ちは真っ直ぐの立ちより身長が少し低い（目安で頭半分）

出典: https://lifedrawing.academy/drawing-lessons/contrapposto ／ https://lifedrawing.academy/drawing-lessons/how-to-draw-female-body

### ひねり（後ろ・横・歩き）

- 胸郭と骨盤は別の箱。ひねりは腰の背骨で起き、胸郭と骨盤の向きの差は、立ったままで目安 30〜45°程度まで（未確認の目安。これを大きく超えるなら足の向きも変わっているはず）
- 振り返りの後ろ姿で、顔が真横を越えて後ろを向くのは首の可動域を超える
- 歩きで腕と脚は逆に振る（右脚が前なら右腕は後ろ）。同じ側が同時に前なら外れ

### しゃがみ

- 踵を付けたしゃがみは足首を深く曲げる必要がある。踵が浮くのが普通の形で、踵を付けるなら膝が爪先より前へ大きく出て胴が前に傾く
- 膝は爪先と同じ向きを指す。膝が内へ入って爪先が外を向くなら外れ
- 太ももとふくらはぎが接して、膝の裏の線は短い。脛の長さと太ももの長さは、しゃがんでも変わらない（短くなるのは見かけの縮みだけ）
- 尻は踵の上か少し後ろ。踵より大きく後ろなら倒れる

### 座り

- 坐骨で座る。座面との境は平らな接地の線で、太ももは座面の上で横に広がる
- 骨盤が後ろに倒れれば腰が丸まり、胸郭の下端が前へ寄る

### 腕上げ・腰に手

- 腕を肩より上げると肩甲骨が回って肩先全体が上がる。肩の高さが下ろした腕と同じなら外れ
- 腰に手は、手首が反り、指先は前か下を向く。指が背骨側を指すなら肘の向きと合わない

出典: Loomis "Figure Drawing for All It's Worth" https://ia804504.us.archive.org/14/items/livros-andrew-loomis/1943%20-%20Figure%20Drawing%20For%20All%20It%27s%20Worth%20-%20Andrew%20Loomis_text.pdf ／ https://lifedrawing.academy/drawing-lessons/model-drawing ／ ひねり・しゃがみの角度は一次資料で数値を確かめていない（未確認）

## 4. 数字にしやすい項目（検品の候補）

1. 脚の左右の明るさの差: 部位分け（.parts.png）の左脚・右脚の中央値の明るさの差。遮る物が無いのに差が大きければ「片脚だけ暗い」
2. 影の境の直線度と向き: 腕・脚の部位の中で影の境を取り、直線に当てはめた残差と、部位の長軸との角度。長軸と大きく交わる直線は「斜めに横切る影」
3. 肩の線と骨盤の線の傾き: 姿勢推定の肩と腰の点から2本の角度を取り、片脚立ちで同じ向きに傾いていれば外れ
