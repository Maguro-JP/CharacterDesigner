# キャラクターデザインの基本の決まり

目標: 設定画（bible/characters/*.json と描いた絵）を、下の決まりの表で項目ごとに「満たす／満たさない」と判定できる
判定: 決まりの各行を、色見本の値・絵の色の面積・縮小した黒塗りの影で数えるか見る
現在: 決まりを書いた段階。機械の検査（tools/check.py などへの組み込み）はまだ無い。羊娘の設定画で練習していない（確かめていない）
諦める条件: 3体続けて決まりを当てても検品担当の戻しが減らない

## 決まり（判定できる形）

| 項目 | 決まり | 判定のしかた |
|---|---|---|
| シルエット | 黒く塗りつぶして 64 画素の高さに縮めても、役どころと種族が分かる。頭まわりに輪郭から突き出す形を1つ以上持つ（角、耳、髪の房、帽子） | 縮小した影を見る。同じ作品の別の人物の影と並べて取り違えないか |
| 形の言語 | 主な形を1つ決める。丸＝やさしい・幼い、四角＝頑丈・落ち着き、三角＝鋭い・危うい。服・髪・持ち物の大きな形の過半をその形にそろえる | 大きな部位を5〜8個に分け、形の種類を数える |
| 色の数 | 主な色は3色まで（肌と髪を除く服と持ち物）。明度の差で3段に分かれる | 色見本の数、絵の色を k-means で 6 色程度に減らして数える |
| 色の配分 | 主色:副色:アクセント ≒ 6:3:1。アクセントは服の面積の 1 割以下 | 絵の人物の範囲で色ごとの画素の割合 |
| アクセント | アクセントの色は1色、置き場所は顔の近く（胸より上）に1か所以上。見る人の目を最初に向けたい所に置く | 色見本に「アクセント」の役を持たせ、置き場所を注記する |
| 年齢と体型 | 頭身で年齢の帯を決めて数字で書く（例: 子ども 4〜5、10代 6〜6.5、大人 7〜7.5、誇張した大人 8）。大人として描くなら、目の大きさを顔の幅の 1/5 前後に抑え、肩幅を頭の幅の 1.5 倍以上にし、首と脚を短くしない | 全身図で頭の高さと全身の高さ・肩幅を測る |
| 柔らかい要素の釣り合い | 丸い髪・ふわふわの服・大きな瞳を全部重ねると幼く寄る（このリポジトリの羊娘で起きた）。大人の役なら、丸の要素を2つまでにして、直線の要素（襟、プリーツ、ベルト、細い靴）を1つ以上入れる | 丸の要素と直線の要素を数える |
| 種族の特徴 | 種族を示す部位は2つまで（羊なら巻いた角と垂れ耳）で、シルエットに出る位置（頭の横、頭の上）に置く。数と左右の位置を決めて書く（角2本、耳2つ、角より下に耳）。服の柄に同じ動物の意匠を繰り返すのは1か所まで | 四面図のすべてで数が合うか |
| 一貫性 | 上の数字（色、頭身、部位の数）は四面図・ポーズ・表情のすべてで同じ | 絵ごとに数える |
