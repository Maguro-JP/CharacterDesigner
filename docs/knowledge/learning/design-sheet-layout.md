# 設定画集の見せ方

目標: tools/gen/charsheet.py の render が、制作の現場の設定画の並べ方に近い1枚を出す
判定: 下の「足りない点」の各行が直ったか、出した HTML を画像にして見て判定する
現在: charsheet.py sheet で 2・3（上端・半分・足の下の線と足の位置）・4・5・7・8 を直し、羊娘で library/sheets/formats/classic.png（2400x4037）を出した。1（斜め前）と 6（引き出し線）は残り。頭身の目盛りは頭の高さを測る処理が無く、半分の線で代えた
諦める条件: 足りない点を直しても、絵がそろわず（四面図の不一致など）見せ方で補えない

## 決まり

| 項目 | 決まり |
|---|---|
| 並べる順 | 1段目に四面図（正面・斜め前・横・背面、斜め後ろは任意）を同じ高さ・同じ縮尺で横一列。2段目に表情（3x3 か 4x3 の均等なます）とポーズ。3段目に部位の拡大と持ち物。端に色見本と注記 |
| 高さの線 | 四面図には横の補助線を引く（頭の上、目、肩、腰、裾、足の下）。全身の横に頭身の目盛り（頭1つ分ずつ）を置く |
| 姿勢 | 四面図は直立の自然な姿勢（A ポーズに近い）で、向き以外を変えない |
| 縮尺 | 四面図はすべて同じ縮尺。足の位置をそろえる |
| 拡大 | 部位の拡大は、全身図のどこかを引き出し線か番号で示す |
| 色見本 | 色ごとに四角と値（#rrggbb）と役（主・副・アクセント・肌・髪）。影の色を並べて置くと塗りがそろう |
| 注記 | 短い名詞句で、何がどうなっているか（「角: 2本、内巻き、耳より上」）。数・左右・大きさを書く。絵の近くに置く |
| 余白 | 区分の間は区分の中の間隔の2倍以上。絵の周りに文字を詰めない |
| 1枚の比率 | 横長（16:9 か A 判の横、1.41:1）で1枚に収める。画面で見る版は縦に流してもよいが、四面図の段だけは横一列を崩さない |

## 今の charsheet.py との比較（SECTIONS と render、2026-10-19 に読んだ）

今の構成: 基本情報 → 四面図（正面・背面・左・右）→ ポーズ3 → 胸から上（表情8、髪型2）→ 目と髪の詳細 → 服・持ち物 → 色見本 → 補足。絵は auto-fill の格子（最小 220px、表情は 160px）で縦に流れる。

足りない点:
1. 四面図に斜め前（3/4）が無い。現場では最も使われる向き。`view-34` を足す
2. 四面図の並びが 正面・背面・左・右 で、向きの回る順（正面→斜め→横→背面）になっていない
3. 四面図の高さの線と頭身の目盛りが無い。縮尺と足の位置をそろえる処理も無い（格子の幅で縮むだけ）
4. 四面図が格子の折り返しで2段に割れる幅がある。四面図の段は横一列に固定する
5. 表情が auto-fill の格子で、行と列の数が決まっていない。3x3 などの均等なますにし、表情の名前を下に付ける
6. 部位の拡大と全身図の対応（引き出し線、番号）が無い
7. 色見本に役（主・副・アクセント）と面積の比が無い。character-design-basics.md の 6:3:1 を確かめる欄が無い
8. 1枚にまとめる版（印刷・画像の書き出し）が無い。今は縦に長い HTML だけ。横長の1枚（例 1920x1080 か 2400x1700）を別に書き出す

## 版の種類（2026-10-31 に調べた）

分かったこと:
- 設定画は1枚ではなく、目的ごとの組で作られる。構造（頭身と体の区切り）、頭部の向き、全身の向き、色、表情、ポーズの6種に分ける解説が多い。表情は6つ前後、ポーズは4〜5つが目安
- 向きの図は同じ縮尺で、目・顎・肩などの位置を横の線でそろえる。線は本体と違う色（青や赤）で引く
- 部位の拡大（持ち物、素材、飾り）は全身図の外に枠で置き、全身図のどこかを示す。縮尺の目盛りが無いと、別の人が描いたときに大きさがずれる（ゲームで敵が地図より大きく描かれた例）
- 色の版は、色見本の四角と値を、全身を塗った見本の横に並べる。部位ごとにふつう・影・ハイライトの段を並べて指定する形が一般的と書かれていたが、制作の一次資料では確かめていない
- 版面の比率を決めた資料は見つけていない。比率は見せる先（印刷の A 判、画面の 16:9、SNS の 1.91:1）から決めた

この道具での形: 版は `styles/sheet-formats/<名前>.json` に欄の種類と位置（版面に対する割合）で持ち、`charsheet.py sheet <id> <出力.png> --format <名前>` で出す。一覧は `charsheet.py formats`。見本は `library/sheets/formats/<名前>.png`（羊娘）。

残り: 頭身の目盛り（頭の高さを測る処理が無く、全身の 8 等分で代えた）、影とハイライトの色（描いた絵から決めておらず空欄）、斜め前・斜め後ろの向きの絵、持ち物の拡大の絵。
