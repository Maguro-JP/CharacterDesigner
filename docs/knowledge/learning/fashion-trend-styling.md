# 2026 年秋冬の日本の流行の着こなし（学んだこと）

最終確認: 2026-10

品目そのもの（何が流行っているか）は `docs/knowledge/fashion/trend-2026aw.md` にある。この資料は、その品目をどう合わせると 2026 年秋冬の装いに見えるか（丈、量感、色の配分、素材、着方、靴と小物）を、記事と実物の写真から決まりに落としたもの。

読み方:

- [番号] はこの資料の 6. 出典の番号。trend-2026aw.md の出典を指すときは「既存[番号]」と書く。
- 「作例」は出典で確かめていない、描くために選んだ組み合わせ。「未確認」は調べても根拠が見つからなかったもの。
- 本文ではブランド名・人名を使わない。露出の多い服と性的な見せ方は載せない。出典がミニ丈を挙げた装いは、描く言葉では膝上丈と黒いタイツにしている（trend-2026aw.md と同じ扱い）。
- 実物の写真はリポジトリに置かない。5 章は 1 枚 1 行の読み取りと URL だけを残す。

## 1. 学んだと言える条件

この資料を読めば、品目の羅列ではなく、2026 年秋冬の日本の 10 代〜20 代の着こなしとして組める。判定には次の点検表を使う。1 つの装い（outfit の句と look の句）ごとに、はい・いいえで答える。

| 番 | 点検 | はいの条件 |
|---|---|---|
| C1 | 主役が先頭にある | 主役の品が 1 つに決まり、色つきで句の最初に書かれている |
| C2 | 量感が上下の一方だけ | 上下の一方を大きく・長く・広く、もう一方を短く・細く・入れる、と対で分かる（cropped と wide-leg、oversized と above the knee など） |
| C3 | 下の丈が書かれている | ankle、full length、midi、knee-length、above the knee など、丈の語がある |
| C4 | 主な色は 3 色以内 | 小物の差し色 1 色と金・銀の金具を除き、主な色が 3 色以内 |
| C5 | 色がつながっている | 同じ色（または同じ系統の濃淡）が 2 か所以上に出る（上と下、下と靴、靴と鞄など） |
| C6 | 着方が書かれている | tucked in、worn open over、sleeves pushed up、layered over、hem peeking out、half zipped など、着方の語が 1 つ以上ある |
| C7 | 素材の対比がある | 2 つ以上の素材や質感が名前で書かれ、対になっている（スエードとリブ編み、フリースとナイロンなど） |
| C8 | 小物は 2 つまで | 鞄・眼鏡・首飾り・帽子・襟巻きなどの小物が 2 つまで（靴下・タイツ・ベルトは数えない） |
| C9 | 古く見える合わせを避けている | 3 章のその装いの「古く見える・避けたい合わせ」に当たらない |
| C10 | 長さ | outfit の句が英語で 60 語以内 |

採点の結果は 4 章の最後にある。

## 3. 品目ごとの着こなし

各項目の [番号] は根拠。何も付いていない組み合わせは作例。

### aw26-napoleon-f ナポレオンジャケット

- 合わせる物: ゆったりしたデニム、ワイドパンツ、タイトスカート [2][3]。白いボウタイのブラウス [2]（既存[5]）。スカートやワンピースで甘さとの差を出す [3]
- 丈と量感: ジャケットは短い丈 [2][3]。下を長く広く（上は短く下は長い、5 章の S1・S8 と同じ組み方）
- 色の配分: 落ち着いた色で暗い装いにもなじむ [3]。主役の紺に白と淡いデニムの 3 色、靴と鞄は紺か黒でつなぐ（作例、2 章の実物の決まり 1・2）
- 素材: デニムや洗い加工の綿で気負わない [2]。ブラウスの綿とデニムの対比（作例）
- 着方: 前を開けて中をのぞかせる、長袖の Tシャツを裾と袖口からのぞかせる [2]
- 靴と鞄と小物: 記事に具体的な提案は無い [2][3]。作例は紺か黒のローファーと小さい肩掛け
- 髪: 暗めのモカブラウン、透けた前髪、ツヤ [12]
- 今っぽく見せる要点: 軍服らしさ（立ち襟、2 列の金ボタン）は残し、飾りは控えめ [2]。下はカジュアルに崩す [3]
- 古く見える・避けたい合わせ: 全身をクラシックな品でそろえる（ボウタイ、きれいめのスラックス、パンプスまで全部）[3]。装飾の多い上と重ねる [3]

- 色の配分: 紺の地に白 [1]、小物は黒でそろえる [1]。派手な色のニットで変化を付ける例もある [1]
- 素材: 厚い綿のラガーとウールのプリーツ（作例）
- 着方: ゆったりした上の前だけをゆるく入れる、袖をまくる（作例）
- 靴と鞄と小物: ビットローファー、サッチェルバッグ、眼鏡（ブロウ型）[1]
- 髪: 暗い茶、顔まわりのレイヤー、透けた前髪 [12]
- 今っぽく見せる要点: スクールの調子で仕上げ、黒小物で締める [1]
- 古く見える・避けたい合わせ: 制服そのもの（ブレザー、紺の膝下の靴下、校章）に寄せる（作例。子どもっぽく見えるのを避ける [1] の言い方を描く側に移した）。小物の色をばらばらにする [1]
