# HD-2D（箱庭ドット）の戦士の男

目標: 戦士の男の立ち絵を描き、作風の検査（`tools/check.py`、`styles/diorama.json`）を全部通り、
かつ等倍と舞台の図で、顔・剣・盾・胴・脚が1つずつ読める。手打ちの v3（`characters/warrior-v3-hand`）より読みやすく、
v3 より作風（細かい質感、素材ごとの明暗）に近い。

判定:
1. `python3 tools/check.py characters/warrior/sprite.json styles/diorama.json` が 8/8
2. v3 と並べた 8倍の図と舞台の図（`tools/render.py`）を、検品担当（checker）が見て、部品（顔・剣・盾・胴・脚・足）が読めるかを1つずつ判定する。
   読めない部品が1つでもあれば通らない
3. 縮めて白黒にした明暗の図（3段）で、頭・胴・脚・持ち物の塊が分かれて読める

現在（2026-10-12、周6の後で頭打ち）: 1 は 8/8（`characters/warrior-learn`）。2 は通らない。読める部品は 7〜8/8 だが、盾の形と、v3 より作風に近いかで止まっている。判断待ち 6今の戦士は v3 より読めない。顔・剣・盾・脚が細かい点に崩れ、
何がどこにあるか追えない（`docs/progress/2026-10-12-hd2d-learn-0.png`）。3 は測っていない

諦める条件: 3周続けて判定 2 の読める部品の数が増えない。または、実機の立ち絵を見ないと決まりが作れない所で止まる
（参考画像のサイトは 403 で読めない。判断待ちに書いた）

## 周1（2026-10-12）明暗の破片をそろえる

仮説: 質感の点を「明るさは周りと同じで色みだけ違う点」にすれば、ざらつきを残したまま明暗の塊を保てる
やったこと: `tools/value_mass.py fix` で、3段の明暗の 3ドット以下の破片を、周りの段の色のうち色相の近い色へ置き換えた（100ドット）
判定: 検査 8/8。明暗の塊 102→34、破片 21%→4%。孤立ドット 16%、色が変わる割合 0.66 は保った。
検品担当の読める部品（頭・顔・剣・盾・胴・腕・脚・足の8つ）: v3 7/8（盾だけ ×）、今 1/8、周1 1/8。
腕と脚は数えられず、欠損と同じ扱い（`docs/progress/2026-10-12-hd2d-learn-1.png`。左から v3、今、周1）
効いた: 明暗の破片は数字どおり減り、ざらつきの数字は保てた
効かなかった: 部品は読めるようにならなかった。原因は形。立体から縮めたとき、鎧の光った所が白い横線になり、腕と胴の境を消している
次: 形の読める v3 を土台に、明るさを変えず色みだけ変えた点で質感を足し、検査（孤立ドット・色が変わる割合・色数）を通す。頭身は形で直す

## 周2（2026-10-12）形の読める v3 に質感を足す

仮説: 形の読める手打ちの v3 を土台に、明るさを変えず色みだけずらした点を塊の内側に置けば、形を保ったまま検査（孤立ドット・色が変わる割合・色数）を通せる
やったこと: `tools/value_mass.py texture`。置く場所は「上下左右が同じ明るさの段」の画素のうち (x+2y)%5==0 の格子（隣にも斜めにも並ばない）。1色につき暖・寒の2色。
頭身は顔を1行足し、すね当てを1行減らして 3.40 → 3.09
判定: 検査 8/8（孤立ドット 8%、色数 28 はどちらも下限ちょうど）。明暗の塊 64→65。
検品担当の読める部品: 約6/8（頭・剣・胴・脚・足は読める、盾はなんとか、顔は目が無く読めない、盾の側の腕は胴と境目が無い）。欠損・余分なし
（`docs/progress/2026-10-12-hd2d-learn-2.png`。左から v3、周1、周2）
効いた: 形を保ったまま検査を通せた。脚を1行縮めて胴と脚の釣り合いが v3 より良くなった
効かなかった: 顔を伸ばしても目の印が無いので間延びした。彩度の高い赤の面に散らした点は汚れに見えた。銀の面の点はほぼ見えなかった
試さなかったこと（検査の当て方）: 同じ色に限った置き場、ハッシュの並びは、置き場が足りず・斜めに並んで孤立ドットが増えなかった
次: 顔に目の暗い1ドット、彩度の高い色には点を散らさない（布は折り目に沿わせる）、浮いた金の1ドットを手につなぐ、盾の側の腕に影の1列

## 周3（2026-10-12）目・布の点・柄頭

仮説: 周2で戻された所を1つずつ直せば、読める部品が増える
やったこと: 目の暗い点を、輪郭の線の隣（線と一続きに見えて読めなかった）から顔の内側へ移した。彩度 0.6 を超える色（赤い布 0.62〜0.68）には点を置かない
（0.45 にすると髪と肌の影まで外れ、点が足りず検査が 6/8 に落ちた）。点の格子を (x+2y)%5 から %4 に詰めた。柄頭の金の1ドットは持ち方どおりなので残した
判定: 検査 8/8（孤立ドット 8%、色数 28）。検品担当: 目は 8倍で読める・等倍の舞台では弱い、赤い布の汚れは消えた、柄頭は持ち方どおりに読めた。
盾の側の腕が胴と同じ灰色に溶けて数えられない（欠損に近い）、盾は縁しか見えず布とも読める（`docs/progress/2026-10-12-hd2d-learn-3.png`。左から v3、周2、周3）
効いた: 目を輪郭から離す、彩度の高い布に点を置かない
効かなかった: 盾の側の腕には手を入れていないので直らない
次: 盾の側の腕を胴より一段暗くするか輪郭の1列で分ける、盾に縁取りか取っ手の1ドット、目をもう一段暗くするか眉の1ドット

## 周4（2026-10-12）盾の側の腕と眉

## 周5（2026-10-12）盾を描き直す

仮説: 盾を体の前に広げ、縁・光・鋲を付け、腰布の赤を一段暗くすれば、盾と読める
やったこと: 盾を 19〜23列・15〜24行に（暗い赤の縁、左上の光、金の鋲2つ）。盾を持つ腕は盾の後ろに隠す。腰布を一段暗い赤に。
盾を彩度の高い赤で広げたら点を置く場所が減り検査が 6/8 に落ちたので、彩度の高い色にも色みのずれを半分（0.015、彩度を足さない）にした点を置いた
判定: 検査 8/8。検品担当: 8つの部品が全部読める、数の棚卸しも欠損・余分なし。前の周の3つの指摘は全部直った。
戻した理由（厳しめ）: 盾が体の右端の縦長の板で盾らしさがぎりぎり、腰布の暗い赤と盾の赤が接して等倍で一続きに見えかける、目は等倍で点1つが限界（`docs/progress/2026-10-12-hd2d-learn-5.png`）
効いた: 盾を広げて縁と鋲、隠れる腕は盾の後ろ。彩度の高い色には小さなずれ
次: 盾を1列内側へ、腰布と盾の間に灰色の1列、目を縦2ドットに

## 頭打ち（2026-10-12、周4〜6）

読める部品は 7〜8/8 で上がらず、目標の後半（v3 より作風に近い）は「ほぼ同じ」から動かない。
今のやり方の限界:
- 作風に近いかの判定に、実機の立ち絵が無い。手元の数字（`styles/diorama.json`）は通るが、それが作風かを確かめられない
- 1ドットずつの手直しは、直した所の隣で別の弱さが出る（盾を広げると腕が隠れ、寄せると札に見える）。形の設計（盾の構え方、腕の見せ方）を先に決めていない
- 検品の判定が周ごとに揺れる（同じような盾を、周5は読める・周6は読めない寄り）
別のやり方の案:
1. 実機の立ち絵を数枚手元に置き（リポジトリには入れない）、同じ大きさで並べて、素材ごとの明暗の段数と質感の点の置き方を数える
2. 形を立体の人形（`tools/engine/`）で決め、盾を体の前に構えた姿勢を下絵にしてから縮める。ドットは最後の1ドット単位の手直しだけにする
3. 検品の判定を固めるため、部品ごとの「読める」の基準（等倍で何ドットの何があれば読めるか）を、通した v3 の数字から決める

## 周7（2026-10-12）案2: 立体の人形を下絵にして縮める

仮説: 形（剣・盾の構え、腕の向き）を立体の人形で決めてから縮めれば、1ドット単位の手直しで出た「直すと隣が崩れる」が無くなる
やったこと: MPFB の男性に腕の内転 30 度・肘 40 度（可動域の検査は外れなし）、素材ごとの色の帯（髪・肌・鎧・腰布・すね当て・靴）、
右手に剣、左の前腕に盾を付け、左斜め前から正射影で 240x400 に描き、`design.py pixel --preset diorama --mode` で 34 ドットへ縮めた
判定: 検査 3/7（幅 39 は剣と盾込み。孤立ドット 1%、情報量 0.48 で平らすぎる）。8倍で周6と並べると、はっきり悪い（`docs/progress/2026-10-12-hd2d-learn-7.png`、左が周6）
- 剣: 刃が細い棒のまま縮み、鍔と柄が消えて刃だけが手から離れて浮いた（欠損と浮きの両方）
- 頭: 髪の帯が坊主頭の頭頂にしか載らず、髪型が無い。目の点が出ない
- 胴: 鎧の色が肌着のように平らな白で、鎧に読めない
効いたこと: 腕・脚の本数と左右は、立体から起こすと崩れない（4本とも読める）。盾は前腕に付いて体の外に出た
次: 縮める前に、細い持ち物（剣の刃・柄）を等倍で2ドット以上の太さになるよう立体で太らせる。髪は MPFB の髪の部品を付ける。
目と鎧の明暗の段は、縮めた後に1ドット単位で足す（案2の「最後だけ手直し」）

## 周8（2026-10-12）髪の部品・太い剣・縮めた後の手直し

仮説: 周7の弱さ（髪が無い、剣が途切れる、目が無い、鎧が平ら）は、髪の部品を付け、細い物を2ドット以上に太らせ、目と鎧の段を縮めた後に置けば直る

縮めた後、顔に目の点を2つ、胴の明るい面の右2列を中間の灰、最下段を暗い灰にした
判定: 検査 4/7（幅 40 は剣と盾込み、孤立ドット 2%、情報量 0.57）。周6と8倍で並べた（`docs/progress/2026-10-12-hd2d-learn-8.png`、左が周6）
- 効いた: 髪型が読める（前髪と横の髪）。目の点で顔が顔に読める。刃が服と別の色で数えられる
- 効かなかった: 刃は太い棒になり、手から離れて浮いたまま。下絵では剣は手に収まっていたので、縮める前の頭身の変形（`--heads 2.8`）が胴の下を詰め、持ち物と手の位置をずらした。`--heads` を外して同じ下絵を縮めると、刃は手から斜めに伸びてつながった（幅 19、頭身は人形のまま約 7 で、作風の 2.8 頭身にはならない）

次: 頭身は縮める後の変形でなく、立体の人形の側で作る（頭の骨を大きく、脚の骨を短く）。持ち物は手の骨に親子付けして一緒に動かす
