# 言葉からの生成の精度（SDXL 系のアニメ模型）

目標: 羊娘の設定画の残り（ポーズ、表情差分、背面）を、頼んだ通りに描けた割合で測って上げる
判定: 項目ごとに「頼んだ要素が描けた枚数 / 描いた枚数」と、検品担当が通した枚数
現在: 2026-10-19 の記録（ai-drawing-notes.md の羊娘の行）が出発点。持ち物 0/4、頬に手 0/4、ポーズの2回目は 12 枚中 10 枚が服か余分な物で崩れ、表情 11 種は区別がつかない、背面の髪は正面より淡い
諦める条件: 下の5つの手を順に当て、3つ続けて割合が上がらない

## 分かっている決まり

| 項目 | 決まり |
|---|---|
| タグの順序 | Animagine XL 3.1 の手引きの形は「1girl, 人物名, 作品名, その他は任意の順」に品質のタグ（masterpiece, best quality, very aesthetic, absurdres）を添える。このリポジトリの design.py は 75 トークンごとの区切りに分けて読ませるので、区切りをまたいだ言葉どうしは結びつきにくい。人数・種族・頼みたい姿勢は先頭の区切りに入れる |
| 推奨の設定 | CFG 5〜7、Euler a、30 段未満、832x1216 などの決まった解像度 |
| 重み (word:1.x) | 文字の埋め込みを倍にするだけで、模型が知らない形は出ない。1.4 を超えると色が飽和し、ほかの言葉が弱まる。羊娘では種族の言葉を (…:1.4) で先頭に置いて角と耳が 12 枚中ほぼ全部で出た。一方、丈（long skirt）、持ち物、頬に手は重みでも出なかった。学習の画像に少ない組み合わせは重みでは出ない |
| 否定 | 否定の言葉は「その方向から離す」だけで、置き換える形は指定しない。打ち消しに miniskirt を入れても長い丈は出なかった。言葉そのものが呼ぶ物（soccer jersey のマーク）は否定で消えない。否定の言葉を増やすと全体の色と構図も動く |
| 77 トークン | CLIP は 77 トークン（実質 75）まで。超えた分は区切って足す仕組み（design.py の split_tokens）だが、区切りごとの重みは等しく、後ろの区切りの細部ほど効きにくい |
| ControlNet depth | 奥行きは体の厚み・服のふくらみまで縛る。正面の絵を元に姿勢を変える用途では、元の服の形を残そうとして姿勢が変わらない（強さ 0.65 で 6 枚とも立ったまま） |
| ControlNet openpose | 関節の点だけを縛り、服と髪の形は縛らない。姿勢を変えて服を言葉と手本で保つ用途に向く。手と顔の点を含む版なら手の向きも縛れる |
| IP-Adapter | 手本の絵の見た目を写す。scale 1.0 で強く、0.5 で言葉と半々。全層に効かせると構図と姿勢まで手本に寄る。層を選ぶ（InstantStyle: up block_0 だけで色と質感、down block_2 で配置）と、姿勢を変えつつ見た目を保てる。顔には plus-face の版がある |
| 範囲の描き直し | 小さな範囲は画素が足りず変える余地が無い（全身図から切った顔で起きた）。範囲を 1024 画素に引き伸ばしてから描き直し、戻すときは部位の形だけ戻す（手の描き直しで効いた） |
| LoRA | 模型が知らない形（決まった衣装、決まった顔）を足す。1 体分の学習には 15〜30 枚のそろった絵が要るので、四面図と表情がそろってからの手 |

## 次に試す手（優先順）

1. 姿勢は depth を外し openpose で縛る
   変えるもの: bible.py のポーズを、正面の絵の画像から画像（強さ 0.85）ではなく、言葉から描く段に openpose（SDXL 用）を 0.8 前後、服と髪は IP-Adapter（InstantStyle の層指定）で保つ
   判定: 腰に手・籠を提げるなど頼んだ姿勢が出た枚数（いまは depth 強さ 0.65 で 0/6）と、余分な物（リボン、猫の耳、白い袖）で崩れた枚数（いま 12 枚中 10 枚）
2. 表情は胸から上を 1024 画素で描き直す
   変えるもの: 全身図から顔を切るのをやめ、胸から上を新しく描く（IP-Adapter plus-face で顔を保つ）。表情の言葉を先頭の区切りに置き、口の形の言葉（open mouth, clenched teeth, frown）を足す。描き直すなら範囲を 1024 画素にしてから強さ 0.55〜0.7
   判定: 11 種を名前を伏せて並べ、検品担当が表情の名前を当てた数（目標 8/11 以上）。角が写る枚数
3. 持ち物と手の位置は範囲の描き直しで後から足す
   変えるもの: 体を描いたあと、持ち物の置き場所（手の周り）だけ 1024 画素に引き伸ばして basket など物の言葉だけで描き直す。手の形だけを元に戻す既存の処理を使う
   判定: 籠が1つ、手が取っ手を握る形で描けた枚数（いま 0/4）。数の誤り（2つ、浮く）を数える
4. 区切りの組み直しと否定の絞り込み
   変えるもの: 先頭の区切りを「1girl, sheep girl, (curled horns:1.3), sheep ears, 姿勢」にし、服の色と小物は次の区切りへ。否定には実際に出た余分な物だけ（cat ears, red ribbon, boots, white sleeves）を 1.2 程度で入れ、一般の長い否定を短くする
   判定: 同じ種で12枚、余分な物が出た枚数と角2本・耳2つがそろった枚数を、今の組み方と並べる
5. 長い丈は形で縛る
   変えるもの: 言葉は効かなかったので、人形の下絵（depth）にくるぶしまでの円錐のスカートの形を描き足す。背面の髪の塊を描き足して効いたのと同じ手
   判定: 裾が膝より下の枚数（いまは 2 回とも短い丈、0 枚）
