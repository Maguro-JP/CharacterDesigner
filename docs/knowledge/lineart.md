# 線画の作り方を比べた（2026-10-11）

仕上げが汚くなる元は線画だった。塗りの絵（画像生成）から線を取り出していたので、影の境目や髪の陰影まで線に拾い、
線が二重になったり途切れたりした。騎士の絵で、線画の作り方を5つ比べた（`library/samples/lineart-methods.jpg`。左から XDoG、模型で描き直し 0.55、0.88、最初から線画）。

| 作り方 | 結果 |
|---|---|
| XDoG（明暗の差から線を拾う、`imgproc.py lineart`） | 影の境目と髪の陰影も線になり、二重・途切れが出る |
| 色の境目の面の縁 | 塗り分けの継ぎはぎの模様になり、デザインの線にならない |
| 周りより暗い細い線だけ拾う | 線が途切れる |
| 模型で線画に描き直す（強さ 0.55、0.7） | 塗りと陰影が残り、線画にならない |
| 同（0.88） | 黒と赤で塗った別の絵になり、手の位置も変わる |
| 最初から線画として描かせる（`tools/gen/lineart.py draw`） | 線が閉じた、きれいな線画。目・瞳・手まで線で描かれる |

塗りの絵はもともと線画を持たない。取り出すのでなく、人の描き手と同じく最初に線画を描く。

清書（`lineart.py clean`）: 模型の線画は地が灰色で、肌や布に灰色の陰影が乗る。
- 明るさのしきい値で切ると、薄く細い線（目・瞳）が消え、顔の影が黒い塊になった
- 線は細く周りより暗く、影は広く暗いので、細さで見分ける（black top-hat、半径 8）。半径 4 では太い線の中が抜けて二重になった
- 十分に暗い所（地の 0.45 倍）は線に、さらに暗い所（0.25 倍）はベタとして残す

残っている問題: 灰色で塗られた小さな面（ランタンの上の帯）が太い黒い塊になる。線の切れ端の数（骨組みの端点、1000 画素あたり）は
XDoG 44.0、最初から線画 46.9 と 44.3 で差が出ず、閉じ具合の物差しとして使えなかった。目で見るしかない。

外から取った線画抽出の模型（pickle 形式の重み）は、読み込みが外のコードを動かしうるので使っていない。
