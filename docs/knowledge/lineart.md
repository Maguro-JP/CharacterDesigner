# 線画の作り方を比べた（2026-10-11）

仕上げが汚くなる元は線画だった。塗りの絵（画像生成）から線を取り出していたので、影の境目や髪の陰影まで線に拾い、
線が二重になったり途切れたりした。騎士の絵で、線画の作り方を5つ比べた（`library/samples/lineart-methods.jpg`。左から XDoG、模型で描き直し 0.55、0.88、最初から線画）。

| 作り方 | 結果 |
|---|---|
| XDoG（明暗の差から線を拾う、`imgproc.py lineart`） | 影の境目と髪の陰影も線になり、二重・途切れが出る |
| 色の境目の面の縁 | 塗り分けの継ぎはぎの模様になり、デザインの線にならない |
| 周りより暗い細い線だけ拾う | 線が途切れる |
| 模型で線画に描き直す（強さ 0.55、0.7） | 塗りと陰影が残り、線画にならない |
| 同（0.88） | 黒と赤で塗った別の絵になり、手の位置も変わる |
| 最初から線画として描かせる（`tools/gen/lineart.py draw`） | 線が閉じた、きれいな線画。目・瞳・手まで線で描かれる |

塗りの絵はもともと線画を持たないので、取り出すより、最初から線画として描かせた方が線がきれいに出た。

清書（`lineart.py clean`）: 模型の線画は地が灰色で、肌や布に灰色の陰影が乗る。
- 明るさのしきい値で切ると、薄く細い線（目・瞳）が消え、顔の影が黒い塊になった
- 線は細く周りより暗く、影は広く暗いので、細さで見分ける（black top-hat、半径 8）。半径 4 では太い線の中が抜けて二重になった
- 十分に暗い所（地の 0.45 倍）は線に、さらに暗い所（0.25 倍）はベタとして残す

残っている問題: 灰色で塗られた小さな面（ランタンの上の帯）が太い黒い塊になる。線の切れ端の数（骨組みの端点、1000 画素あたり）は
XDoG 44.0、最初から線画 46.9 と 44.3 で差が出ず、閉じ具合の物差しとして使えなかった。目で見るしかない。

外から取った線画抽出の模型（pickle 形式の重み）は、読み込みが外のコードを動かしうるので使っていない。

## 3つの職業で2枚ずつ（2026-10-11、`library/samples/lineart-jobs.jpg`）

魔女・剣士・機械技師を `lineart.py draw` で2枚ずつ描き、清書して、全身と顔・手を拡大して目で見た。

| 絵 | 線 | 崩れ・矛盾 |
|---|---|---|
| 魔女1 | 閉じている | ほうきを持つ手が見えない |
| 魔女2 | 閉じている | 上が枝の杖で下がほうきの穂の、混ざった持ち物 |
| 剣士1 | 閉じている | 無し |
| 剣士2 | 閉じている | 鍔が2か所あり、剣が2本つながったように見える。左目に髪の影が黒い塊でかかる。マントの裾にぼかした黒い塗りが残る |
| 機械技師1・2 | 閉じている | 無し（大きなスパナは作風の誇張として通る） |

- 顔は6枚中5枚で線がきれい。手は見えている所（柄を握る手、手袋）は形が通る。関節の位置から切り出したので、見られていない手もある
- 騎士で黒い塊に見えたランタンの帯は、元の線画でも濃い縁で、清書の誤りではなかった。帯の下に灰色のざらついた点が少し残る
- 描く言葉が長いと 77 語の上限で後ろ（画質の言葉）が切れる警告が出る
- 持ち物の矛盾（剣が2本、杖とほうきが混ざる）は、前に作った途中切れの検品（`pieces.py`）で線画にも使えるか、次に確かめる

## 線画に色を置く（2026-10-11、`library/samples/lineart-color-try.jpg`。左から騎士 0.75、騎士の面塗り、技師 0.75、技師の面塗り）

| 作り方 | 結果 |
|---|---|
| 線画を下絵に色を描かせ、線画を乗算で重ねる（強さ 0.6、0.75） | 線は崩れないが、白い地が勝って色がほとんど乗らない（差し色だけ） |
| 線で閉じた面ごとに、強く描かせた参考（0.9）の真ん中の色を1色塗る（`lineart.flat_fill`） | 線は崩れず、色は面の中に収まる。技師は手袋・帯・道具袋・靴に色が乗った |

面塗りの問題:
- 騎士の顔と肌が髪の茶色になった。参考の絵の顔の位置が線画とずれ、髪の色を拾った
- 全体に白い。参考の絵そのものが白い線画に引っ張られて白くなり、頼んだ橙の作業着も白のまま
次は、色を拾う先を位置でなく部位で合わせる（線画と参考の両方を部位分けし、同じ部位の色を取る）

### 部位で色を合わせる（`lineart.color_by_parts`、`library/samples/lineart-color-parts.jpg`）

参考の絵を線画とは別に色付きで描かせ（頼んだ色が乗る。形は線画と違う）、線画と参考の両方を部位分けして、
線画の面ごとに「参考の同じ部位の、同じあたり」の色を塗った。部位分けは線画でも効いた（顔・髪・上着・ズボン・帯・腕が分かれる）。

- 色がしっかり乗った。騎士の赤い籠手と胸当て、技師の手袋・帯・道具袋は参考どおり。線は崩れず、はみ出さない
- 騎士の顔と首が肌より暗い茶色になった
- 騎士の長いマントが白いまま。線画の部位分けでマントが人物の外とされた
- 技師の作業着が灰色で、参考の橙にならない。左右の靴の色が違う。線画と参考で部位分けの食い違いがあると見ている（確かめていない）

### 部位の食い違いを直した（2026-10-11、`library/samples/lineart-color-parts.jpg` を差し替え）

線画と参考の部位を数えると、同じ物が別の部位に分けられていた。技師の作業着は線画で「ズボン」13.6 万画素、参考で「ワンピース」14.8 万画素。
参考の「ズボン」は 204 画素だけで、その灰色で作業着を塗っていた。参考の靴は右だけ。騎士のマントは線画で「ズボン」、参考で「ワンピース」。

- 500 画素以下の部位は無いと数え、仲間の部位（服どうし・左右の靴・脚・腕）のうち線画で使われていないものと組にした
- 色は赤・緑・青を別々に真ん中を取らず、明るさが真ん中の実際の画素の色を取る（別々だと白と橙が混ざって灰色になった）
- 結果: 技師の作業着の下半分が橙、騎士のマントとスカートが赤と黒になった
- 残り: 作業着の胸当てはシャツと同じ「上着」にされて白いまま。騎士の顔が暗い茶色。騎士の片方の太ももがマントの赤
