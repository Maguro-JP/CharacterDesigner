# AI プリセットと右クリックのメニューの精査

アプリ（chatdraw）の AI プリセットと右クリックのメニューを、項目ごとに押して確かめた結果。
試験は `chatdraw/tests/test_menuaudit.py`。全部の右クリックの項目を本物と同じ経路で押し、プリセットは偽の模型で 1 つずつ描く。

決まり:

- よく使う物を上、消す物は一番下で区切り線の下に置く
- 今の状態で使えない項目は押せなくし、理由をツールチップに出す
- 消す・初期化する項目は、確かめの窓（`chatdraw/confirm.py`）を通す。「次から聞かない」で出さなくでき、「設定」の「確かめの窓をまた出す」で戻せる
- 同じ操作には、どのメニューでも同じ名前を使う

## AI プリセット（`chatdraw/aipanel.py`）

| プリセット | 状態 | 直したこと |
|---|---|---|
| 標準 | 動く | なし |
| キャラデザ | 動く | 「立ち絵（白地）」をまとめ、白地（white background）を足した |
| ラフを清書 | 動く | なし |
| ラフから自由に | 動く | 画風を厚塗りからおまかせにした。説明（ラフを元に AI が整える）に厚塗りの意味が無く、ラフの塗りを変えていた |
| イラスト | 動く | なし |
| アイコン | 動く | 「表情差分」をまとめた。足す言葉から looking at viewer を外した（頼んだ視線を壊す） |
| 背景美術 | 動く | なし（no humans は「人のいない風景」の説明どおり） |
| モノクロ | 動く | 足す言葉から lineart, screentone を外した（白黒の頼みに漫画のトーンまで足していた） |
| 立ち絵（白地） | 消した | キャラデザと中身が同じ。キャラデザへまとめた |
| 表情差分 | 消した | 表情を描き分けず、正方形の顔を 1 枚描くだけで名前と中身が合わなかった。アイコンへまとめた。表情差分は「キャラクターデザイン」のメニューにある |
| レトロアニメ | 消した | 画風「レトロ」と同じ。標準＋画風レトロへまとめた |
| 水彩の挿絵 | 消した | イラストに画風「水彩」を当てたのと同じ。イラスト＋画風水彩へまとめた |

まとめた名前で呼ばれた（声、AI の頼み、`apply_name`）ときは、まとめた先を当てる（`aipanel.MERGED`）。
赤ペンで直すはプリセットに入れない。

## 右クリックのメニュー

| 場所 | 項目 | 状態 | 直したこと |
|---|---|---|---|
| キャンバス | 赤ペンで囲む（T） | 動く | 名前を短くした |
| キャンバス | 囲んだ所を直す | 動く | 処理の途中は押せず、理由をツールチップに出す |
| キャンバス | 赤ペン N の指示を書き直す | 動く | 「印 N」を「赤ペン N」にそろえた |
| キャンバス | 元に戻す・やり直す | 動く | 押せないときの理由をツールチップに出す |
| キャンバス | もう一度描く | 動く | 「この絵を AI で描き直す（もう一度描く）」を短くした。押せない理由を出す |
| キャンバス | 表示する絵を固定 | 動く | 名前を短くした |
| キャンバス | 赤ペン N を消す…・赤ペンの印を全部消す… | 動く | 上の方にあったのを一番下の区切り線の下へ移し、確かめの窓を通す。名前をメニューの帯の「赤ペンの印を全部消す」にそろえた |
| キャンバス | 道具・表示・選択範囲・保存・書き出し・ショートカット | 動く | なし |
| レイヤーの欄 | 新しいレイヤー | 動く | 欄の空きの右クリックの「レイヤーを足す」と名前をそろえた |
| レイヤーの欄 | 1 つ上へ・1 つ下へ・下と結合 | 動く | 一番上・一番下では押せず、理由を出す（前は押しても何も起きなかった） |
| レイヤーの欄 | ロック | 動く | 「ロックを切り替える」と「…」の「ロックする（描けなくする）」を「ロック」の印付きにそろえた |
| レイヤーの欄 | 見えているレイヤーを結合 | 動く | 見えているレイヤーが 1 枚のときは押せず、理由を出す |
| レイヤーの欄 | レイヤーを消す… | 動く | 上にあったのを区切り線の下へ。描いてあるレイヤーだけ確かめの窓を出す（何も描いていないレイヤーは聞かない）。「－」、Delete、メニューの帯の「レイヤーを消す」も同じ道 |
| レイヤーの欄 | 赤ペンの行: 指示を書き直す・赤ペン N を消す…・赤ペンの印を全部消す… | 動く | 消す物を区切り線の下へ、確かめの窓を通す |
| 履歴 | この絵を出して固定・固定を外す | 動く | 固定中は「固定を外す」だけを出す（前は両方出ていた） |
| 履歴 | 囲んで直す | 動く | 「編集する（囲んで直す）」を短くし、ライブラリーとそろえた |
| 履歴 | 頼みを書く欄へ・頼みを描くワードに登録 | 動く | 名前を短くした |
| 履歴 | ディレクトリを開く | 動く | 「保存した場所を開く」をライブラリーの「ディレクトリを開く」にそろえた |
| 履歴 | 消す（ごみ箱へ）… | 動く | 「そのほか」の下に回り込んでいたのを一番下へ。確かめの窓は前から通る |
| 履歴 | 比べる・判定・SNS に送る・3D に進む…ほか | 動く | なし（SNS は選んでいないと押せず、理由を出す） |
| ライブラリー | 評価を外す | 動く | 評価していないときは押せず、理由を出す |
| ライブラリー | 囲んで直す | 動く | 名前を履歴とそろえた |
| ライブラリー | 一覧から外す…・消す（ごみ箱へ）… | 動く | 区切り線の下へ。一覧から外すも確かめの窓を通す |
| 欄の見出し・欄の空き | 置き場所 | 動く | 欄の右クリックにも置き場所を出した（前は見出しの小さなボタンだけ）。別ウィンドウのときは「別ウィンドウにする」を押せず、理由を出す |
| 欄の見出し・欄の空き | 新しく描く | 動く | 「新しく描く（書く欄へ）」を短くした |
| 帯の中身 | 頼んだ言葉: この言葉で描く・書く欄に入れる・描くワードに登録・一覧から消す… | 動く | すぐ描くを上へ。処理の途中は押せない。消すは区切り線の下で確かめの窓を通す。書く欄に入れるを足した |
| 帯の中身 | 登録した言葉: 登録から外す | 動く | 区切り線の下へ |
| 帯の中身 | 禁止ワード: 禁止ワードに足す・この言葉だけにする・登録から外す | 動く | 名前を短くし、外すを区切り線の下へ |
| 帯の中身 | 自分のプリセット: このプリセットにする・今の設定で上書き・消す… | 動く | 前は「消す」だけで、確かめずに消していた。当てる・上書きを足し、消すは確かめの窓を通す |
| 帯の中身 | 単語: 描くワードに足す・訳を直す…・お気に入りから外す | 動く | 外すを区切り線の下へ |
| 帯の中身 | 単語辞書: 描くワードに足す・お気に入りに登録・辞書から消す… | 動く | 確かめずに消していたのを、確かめの窓を通す |
| 帯の中身 | リボン: リボンの並びを変える… | 動く | なし |
| 帯の中身 | 帯の出し入れ・帯とメニューの編集・固定 | 動く | なし |

確かめの窓の種類は `confirm.KINDS` に足した: レイヤーを消す、赤ペンの印を消す、一覧・辞書・プリセットから消す。
