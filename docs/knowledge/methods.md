# 描き方（生成手順）の一覧

スタジオの「手順」で選ぶ。急ぐときは一発、こだわるときは人の描き方の順番を通す。
どの手順でも共通の決まり:

- 仕上げは、模型で描いたと判らない水準を目指す（線が閉じている、光源が1つ、面と影の段が読める、手や小物の形が正しい）
- 矛盾やあり得ないこと（手足の数、切れ、頼んだ物が無い、浮いた物）は、見つけたら文字で残す（仕事の `findings`）
- 特別な注文（「あり得ない形を許す」）が無い限り、あり得ない形は描かない（打ち消しに必ず入れる。`session.IMPOSSIBLE`）

## 今ある手順

| 手順 | 中身 | 時間（CPU） | 向き |
|---|---|---|---|
| 一発（oneshot） | 描く模型で1枚 → 検品 → 落ちたら直して描き直す | 1枚 約3〜4分 | 下書き、数を見たいとき |
| 人の順番で仕上げ直す（handdraw） | 一発の絵から線を閉じ、強弱、下塗り、影、線を重ね、弱く（0.6）描き直して整える | 一発 ＋ 約4分 | 線と面のはっきりしたアニメの絵 |
| ラフから（rough） | 鉛筆のラフ → ラフを下絵に色の手本（0.8）→ ラフの線と手本の色で人の順番 → 弱く描き直して整える | 一発 ＋ 約8分 | 勢いのある構図、こだわるとき |

## 伝統的な描き方（これから手順にするもの）

人の描き手が使ってきた順番。どれも「先に決めたことを、次の段で壊さない」ための段取りになっている。

| 描き方 | 段取り | 何を先に決めるか | 手順にするときの道具 |
|---|---|---|---|
| セル画（アニメの仕上げ） | 原画 → 動画（清書の線）→ 色指定 → 仕上げ（線の中を塗る）→ 撮影（光の効果） | 色指定（キャラクターごとの決まった色と影色） | 下塗りの色を色指定から取る（今は絵から取っている） |
| 漫画の原稿 | ネーム → 下書き → ペン入れ（入り抜き、強弱）→ ベタ → トーン → 仕上げ（ホワイト） | 白と黒の配分（ベタ） | 明暗の塊（`imgproc.py notan`）から先にベタを決める |
| グリザイユ（古典の油彩） | 灰色だけで明暗を描く → 薄い色を何層も重ねる（グレーズ） | 明暗（形と光） | 灰色の段で描いてから色を掛ける |
| 厚塗り（コンセプトアート） | 大きな色の面 → 形を削り出す → 細部 | 色の面と光 | 色の面の塊から描かせる |
| 透明水彩 | 下書き → 明るい色から → 暗い色を重ねる。白は塗り残す | 塗り残す白（一番明るい所） | 紙の白を残す範囲を先に決める |
| 線画の色トレス | 線の色を、隣の面の色の濃い色にする | 線の色 | 暗い面の上の線で一部使っている |

## 段ごとに見ること

- ラフ: 姿勢・構図・比率。手足の数と向きはこの段で直す（後の段では直しにくい）
- 線画: 線が閉じているか、外形と内側で太さが分かれているか、力の掛かる側が太いか
- 下塗り: 1つの領域に色が1つか、白く抜けた所が無いか
- 影: 光源が1つか、影の形が面になっているか
- 仕上げ: 顔・手・小物の形、頼んだ要素が全部あるか
