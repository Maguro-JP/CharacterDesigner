# 映り込みの矛盾の検品

模型は鏡の中と外を別々に描くので、同じ物のはずが別の物（色の違う服、無い腕、反転していない向き）になった。
手・足・顔の検品は枠の中しか見ないため、この食い違いは通っていた。`chatdraw/mirrorcheck.py` が比べ、
`sanity.check` から呼ばれて `qcmanual.flaws` で「矛盾: 鏡の中の〜」の赤ペンの印になる。

## やり方と根拠

1. 映り込みのある絵かは、絵全体のタグ（WD tagger の `mirror`、`reflection`、`reflective water`、`reflective floor`、
   `looking at mirror` など、下限 0.35）で決める。タグが無い絵では何も言わない。water と floor は上下、mirror は左右に反転して映る
2. 元の物と映りの対応は、鏡の対称の見つけ方（Loy と Eklundh 2006。特徴点の記述を反転した絵の記述と突き合わせ、組ごとに軸へ票を入れる）
   に倣う。cv2 が無いので、8 画素の区画の勾配の向きの並び（2x2 x 8 向き）を numpy で作って突き合わせる
3. 外した物: まっすぐな線だけの区画（線は線に沿ってずらすと重なり、どこにでも写しが見つかった）、軸の向きに 3 区画より近い組、
   元の側と映りの側の間が 16 画素（192 画素に縮めた上）より空かない組（正面の顔のような自分の左右対称）
4. 比べ方: 映りは暗く色が寄るので、対応の付いた組から色ごとに「映り = a x 元 + b」を当てはめてから色の差を測る。
   元にあって映りに無い物、映りにだけ有る物（数）、画素の相関が負の区画（形）を数え、近い区画をまとめて枠にする
5. 反転しない写し（平行移動）の方が票が 1.5 倍より多ければ、「向きが違う（反転せずに写っている）」とする
6. タグはあるのに組が見つからない絵は、崩れが無いことにせず「比べていない」と返す（qcmanual.missed）

## 分かっている限界

- 対称な形 1 つ（楕円など）は、自分の半分どうしを組にすることがある。そのときは比べても同じなので崩れは出ないが、「比べていない」とも言わない
- 鏡に背を向けた人（映りが正面、元が背中）は、同じ面が写っていないので組にならない
- 斜めの鏡で大きさや形が変わる映り込みは、平行移動と反転だけを探すので組にならない

## 測った数字

試験の中で組んだ絵（人の形の図と、25% ガラスの色を混ぜた写し）で、正しい映り 0 件、色を変えた写し・腕を消した写し・反転しない写し・
水面の色違いをそれぞれ 1 件ずつ返した（`chatdraw/tests/test_mirrorcheck.py`）。1 枚あたり約 1 秒（192 画素、CPU）。
library/feedback に鏡・水面の映り込みを描いた絵は無かった（「mirror」は加工の名前、「ガラス」はステンドグラスの加工だけ）。
