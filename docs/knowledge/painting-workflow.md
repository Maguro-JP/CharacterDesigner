# デジタルで人が絵を仕上げる工程（調べたこと）

前の手順（`methods.md` の handdraw・rough）は、線を閉じる → 下塗り → 影 → 線 の4段だけで、人の作業のうち
「重ねて、馴染ませて、足して、直す」を繰り返す部分をまるごと省いていた。模型は完成形から逆算して一度に出すので、
この往復の跡（塗りの層の重なり、線の描き足し、ムラ、意図して残した描き込みの粗密）が無い。そこを道具の段に起こす。

## 工程（アニメ塗りのメイキングから。順番どおり）

| 段 | 人がやること | レイヤー | 往復 |
|---|---|---|---|
| ラフ | 構図・パーツの位置と形・シルエット | — | |
| 下描き | ガイドの線。左右対称は半分描いて反転し、ずれを確かめる | — | 全体を見て直す |
| 線画 | 部位ごとにレイヤーを分ける。外側は太く濃く、内側は細く薄く。目は後で別に描く | 部位別 | 縮めて全体を見て、気になる所を直す |
| 下塗り（全体） | キャラクター全体を1色で塗る（はみ出し止め） | 最下層 | |
| 下塗り（部位） | 部位ごとに目立つ色で塗り、塗り残しを探して塗り足す。透明部分をロック | 部位別・クリッピング | 塗り残しを探す |
| 影 | ハッチングや水彩の筆で暗さを重ね、要所を黒で締める。不透明度で濃さを決める | 影のレイヤー | 縮めて全体の雰囲気を見る |
| 目 | 左右をコピーせず差を付けて描く。瞳は上から下へ明るく | 目のレイヤー | 全体の濃淡を見る |
| 加工 | 統合した絵にグラデーションマップ（薄黄→濃紫）を 12% で重ね、さらにスクリーンで重ねる | 通常・スクリーン | |
| 色の差し | オーバーレイで瞳などに色を入れ、範囲で色相を変える | オーバーレイ | |
| 光 | 金属・ハイライトに光を入れる | （加算） | |
| 空気 | スクリーンで遠い所（後頭部など）を明るくして奥行き | スクリーン | |

グリザイユ（灰色の明暗 → 色を重ねる）の場合:
灰色だけで明暗を描き込む（筆ムラやテクスチャでコクが出る）→ オーバーレイ・リニアライト・カラーで色を乗せる（試して選ぶ）
→ オーバーレイを重ねて灰色っぽさを消す → 加算でハイライト、乗算で塗り忘れに色。

## 道具で回す工程

ラフ → 線画 → ベースの色 → 細かく色を塗る → 色を重ねる → 色を馴染ませる → 線を引く・足す・調整する →
影を足す → ハイライト → 汚しやディテール → また調整 → （繰り返す）

## 道具の段に起こすと

1枚の絵を「レイヤーの重なり」として持ち、各段は1枚のレイヤーを足すか直すだけにする。最後に合成する。
段は1回で終わらせず、全体を縮めて見る → 直す、を回す。

| 段 | 道具の中身（作る予定） |
|---|---|
| 下塗り | 部位分け（edit.parts）と閉じた線から、部位ごとのベース色レイヤー |
| 細かい色 | 部位の中の小さな領域（目・口・装飾）に別の色 |
| 色を重ねる | 乗算の影色レイヤー、オーバーレイの色味レイヤー（光源の側と反対側で色温度を変える） |
| 馴染ませる | 影の境目だけをぼかす（アニメ塗りは1段だけ境を残す、厚塗りは広くぼかす） |
| 線の調整 | 外形の線を太く、内側を細く、線の色を隣の面の色に寄せる（色トレス）、切れた所を描き足す |
| ハイライト | 加算で光源側の縁と金属・髪・瞳に |
| 汚しとディテール | 紙や筆のテクスチャを薄く、布のしわ・傷・刺繍などの描き込み（img2img で範囲だけ） |
| 加工 | グラデーションマップを薄く、スクリーンで遠い所に空気 |
| 調整（繰り返し） | 縮めた絵で明暗の塊（notan）と見せ場を測り、弱い所の段に戻る |

## 模型の絵が見分けられる所（調べたこと。確かな判定ではない）

- 手指の数や関節、髪の束が溶け合う、左右で揃うべき装飾がずれる
- 消えるように途切れる線、真っすぐなはずの線の歪み
- 描き込みの粗密が意図と関係ない（髪は単純なのに別の所だけ細かい）、背景や服がにじむ
- 表情が乏しい
- うまく描けた模型の絵は目では見分けられないという声もある

## まだやっていないこと

  見るだけにして、気づいたことを数字と言葉でここに足す）

## 人の絵と模型の絵を並べて見た（2026-10-11）

人の絵は CLIP STUDIO のアニメ塗りの講座の工程の絵（ラフ・線画・目・完成）を取って見た（scratchpad にだけ置き、リポジトリには入れない）。
模型の絵はこの道具で描いた騎士（`.cache/app/jobs/ade502136568/try-0.png`）。顔の周りを同じ大きさに切って並べた。

| 見た所 | 人の絵 | 模型の絵 |
|---|---|---|
| 線 | 1本ずつの筆跡。端が細く抜ける。髪は細い線を何本も重ね、毛先が交差してはみ出す | 太さがほぼ一定で、端が丸く柔らかい。髪は大きな帯の形 |
| 塗りの面 | 筆ムラと紙の目、ハッチングの筋が見える | 面の中がつるつるのグラデーション（エアブラシのよう） |
| 左右 | 両目をコピーせず、わざと差がある | 両目がほぼ同じ形 |
| 描き込みの粗密 | 装飾は輪郭がはっきりして中まで模様を描く | 髪や鎧のつやは丁寧で、境目はぼやける |

数えた: なだらかな面（明るさの傾きが小さい所）の中の、ぼかした絵との差の平均（細かいざらつき）。
人の完成絵 6.65、模型の絵 1.54 と 1.80。人の絵は約4倍ざらつく。人の絵は1枚しか測っていないので、数を増やして確かめる。

ここから足すもの:
- 線を筆跡としてブラシで引き直す（`tools/gen/brushes.py`、`casts/brushes.json`）。丸ペン・Gペン・かぶらペン・筆・鉛筆・マーカー。
  雰囲気で丸（柔らかい・かわいい）と鋭い（入り抜き、格好いい）を使い分け、デフォルメ（chibi）は線を 1.6 倍に太くする
- 塗りの面に紙の目や筆ムラを薄く足す（まだ）
- 左右対称の部位に小さな差を付ける（まだ）

### 2回目（2026-10-11）: 人の絵 3 枚と模型の絵 5 枚で、面のざらつきを測った

| 絵 | 面のざらつき |
|---|---|
| 人: 水彩毛筆で塗ったアニメ塗りの完成絵（講座 153260） | 6.11 |
| 人: 講座の扉の1枚（158695、本の表紙で文字入り。参考の外） | 6.36 |
| 人: すっきりしたアニメ塗りの2人の絵（講座 165870） | 2.75 |
| 模型: 騎士・剣士・機械技師など 5 枚 | 0.79〜2.48 |

- 人の絵の中でも作風で大きく違う。筆の跡を残す塗りは 6 前後、すっきりしたアニメ塗りは 2.75 で、模型の絵の上の方（2.48）とほぼ重なる
- つまりざらつきだけでは見分けられない。すっきりしたアニメ塗りでは、線（1本ずつの筆跡、入り抜き）と左右の差、描き込みの粗密の方が手がかりになる
- 足すざらつきの量は塗り（paint）ごとに決める: アニメ塗りは 2〜3、水彩・厚塗りは 6 前後（今の handdraw は一律 6）
- 講座の絵はリポジトリに置かず、見て測っただけ

## 人の順番の仕上げを段ごとに元の絵と比べた（2026-10-11）

魔女2枚と騎士で、handdraw の段ごとの出力を元の絵と比べた。人物の中の平均で、細かい明暗（ぼかした絵との差）、色の差、大きな明暗の差（8 画素でぼかした明るさの差）を数えた。

| 段 | 細かい明暗（元 10.0〜12.7） | 色の差 | 大きな明暗の差 |
|---|---|---|---|
| 下塗り（3-flats） | 7.9〜10.5 | 20〜28 | 19〜26 |
| 影（4-shade）・光（4-light） | ほぼ同じ | ほぼ同じ | 1〜2 戻るだけ |
| しわを戻す（4-folds） | 範囲の中だけ戻る | 同じ | 同じ |
| 線を重ねる（5-final） | 11.3〜15.0（元より多い） | 26〜34 | 15〜20 |

目で見たこと（騎士）:
- 下塗りで、鎧とマントが同じ灰色の1つの塊になり、胸当てや肩当ての形が消えた。部位分けは鎧とスカートを1つの「ワンピース」にし、線だけでは閉じない所があるため
- 影は、絵とは別に作った明暗の計算（imgproc.shade）から置くので、形と合わない大きな面になる。元の絵の光の当たり方は下塗りで消えたまま戻らない
- 線を重ねると、元の絵の線とずれた所に二重に引かれ、顔の周りが汚れる

人の描き手は、下描きで決めた形と光を、下塗り・影の各段で保ったまま描き進める。今の作りは、元の絵が持っている形と光を下塗りで捨て、
あとの段で別の計算から作り直しているので、段を重ねるほど元の絵から離れる。
