# デジタルで人が絵を仕上げる工程（調べたこと）

前の手順（`methods.md` の handdraw・rough）は、線を閉じる → 下塗り → 影 → 線 の4段だけで、人の作業のうち
「重ねて、馴染ませて、足して、直す」を繰り返す部分をまるごと省いていた。模型は完成形から逆算して一度に出すので、
この往復の跡（塗りの層の重なり、線の描き足し、ムラ、意図して残した描き込みの粗密）が無い。そこを道具の段に起こす。

## 工程（アニメ塗りのメイキングから。順番どおり）

| 段 | 人がやること | レイヤー | 往復 |
|---|---|---|---|
| ラフ | 構図・パーツの位置と形・シルエット | — | |
| 下描き | ガイドの線。左右対称は半分描いて反転し、ずれを確かめる | — | 全体を見て直す |
| 線画 | 部位ごとにレイヤーを分ける。外側は太く濃く、内側は細く薄く。目は後で別に描く | 部位別 | 縮めて全体を見て、気になる所を直す |
| 下塗り（全体） | キャラクター全体を1色で塗る（はみ出し止め） | 最下層 | |
| 下塗り（部位） | 部位ごとに目立つ色で塗り、塗り残しを探して塗り足す。透明部分をロック | 部位別・クリッピング | 塗り残しを探す |
| 影 | ハッチングや水彩の筆で暗さを重ね、要所を黒で締める。不透明度で濃さを決める | 影のレイヤー | 縮めて全体の雰囲気を見る |
| 目 | 左右をコピーせず差を付けて描く。瞳は上から下へ明るく | 目のレイヤー | 全体の濃淡を見る |
| 加工 | 統合した絵にグラデーションマップ（薄黄→濃紫）を 12% で重ね、さらにスクリーンで重ねる | 通常・スクリーン | |
| 色の差し | オーバーレイで瞳などに色を入れ、範囲で色相を変える | オーバーレイ | |
| 光 | 金属・ハイライトに光を入れる | （加算） | |
| 空気 | スクリーンで遠い所（後頭部など）を明るくして奥行き | スクリーン | |

グリザイユ（灰色の明暗 → 色を重ねる）の場合:
灰色だけで明暗を描き込む（筆ムラやテクスチャでコクが出る）→ オーバーレイ・リニアライト・カラーで色を乗せる（試して選ぶ）
→ オーバーレイを重ねて灰色っぽさを消す → 加算でハイライト、乗算で塗り忘れに色。

## 利用者が挙げた工程（そのまま）

ラフ → 線画 → ベースの色 → 細かく色を塗る → 色を重ねる → 色を馴染ませる → 線を引く・足す・調整する →
影を足す → ハイライト → 汚しやディテール → また調整 → （繰り返す）

## 道具の段に起こすと

1枚の絵を「レイヤーの重なり」として持ち、各段は1枚のレイヤーを足すか直すだけにする。最後に合成する。
段は1回で終わらせず、全体を縮めて見る → 直す、を回す。

| 段 | 道具の中身（作る予定） |
|---|---|
| 下塗り | 部位分け（edit.parts）と閉じた線から、部位ごとのベース色レイヤー |
| 細かい色 | 部位の中の小さな領域（目・口・装飾）に別の色 |
| 色を重ねる | 乗算の影色レイヤー、オーバーレイの色味レイヤー（光源の側と反対側で色温度を変える） |
| 馴染ませる | 影の境目だけをぼかす（アニメ塗りは1段だけ境を残す、厚塗りは広くぼかす） |
| 線の調整 | 外形の線を太く、内側を細く、線の色を隣の面の色に寄せる（色トレス）、切れた所を描き足す |
| ハイライト | 加算で光源側の縁と金属・髪・瞳に |
| 汚しとディテール | 紙や筆のテクスチャを薄く、布のしわ・傷・刺繍などの描き込み（img2img で範囲だけ） |
| 加工 | グラデーションマップを薄く、スクリーンで遠い所に空気 |
| 調整（繰り返し） | 縮めた絵で明暗の塊（notan）と見せ場を測り、弱い所の段に戻る |

## 模型の絵が見分けられる所（調べたこと。確かな判定ではない）

- 手指の数や関節、髪の束が溶け合う、左右で揃うべき装飾がずれる
- 消えるように途切れる線、真っすぐなはずの線の歪み
- 描き込みの粗密が意図と関係ない（髪は単純なのに別の所だけ細かい）、背景や服がにじむ
- 表情が乏しい
- うまく描けた模型の絵は目では見分けられないという声もある

## まだやっていないこと

- 人の描いた絵と模型の絵を、実際に並べて目で見比べることはまだしていない（参考作品の画像はリポジトリに置かない決まり。
  見るだけにして、気づいたことを数字と言葉でここに足す）
