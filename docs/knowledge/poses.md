# ポーズの描き分け（2026-10-04、理想のベースの体で12種）

ポーズの型は `casts/poses.json`、描く道具は `tools/gen/poses.py`、見本は `library/samples/people/poses-ideal-female.png`。
体のベースの構図の言葉（standing, arms at sides）だけをポーズの言葉に差し替え、体・服・打ち消しはベースのまま描く。

## 結果

| ポーズ | 出来 | 効いた言葉・直したこと |
|---|---|---|
| 片足重心の立ち | 良い | 「weight on one leg」は片足立ちになった。「both feet on ground, hip tilt」に替えた |
| 腕組み | 良い | |
| 振り返り | 良い | from behind, looking back |
| 歩き | 弱い | 3回とも歩きにならなかった（片足立ちで腕を広げる → 同じ → 片足を跳ね上げた小走り）。今は小走りに近い絵を残している |
| 走り | 良い | seed 31 では2回とも腕を広げた。seed 57 と打ち消し（outstretched arms, ballet）で横向きの走りになった |
| 跳躍 | 普通 | 腕を広げて浮いている。足の下の地面との隙間は出ていない |
| 伸び | 良い | |
| 椅子に座る | 普通 | 座れているが、脚は組んでいない。1回目は画面の端で切れた |
| しゃがみ | 良い | |
| 片膝立ち | 普通 | 1回目は両膝を着いて胸を腕で隠す姿勢。「kneeling on one knee, one knee up, back straight」で片膝は立った |
| 構え（格闘） | 良い | |
| 構え（剣） | 弱い | 剣の形が曲がった刃になり、両手の持ち方が曖昧 |

## わかったこと

- ポーズの言葉は、体のベースの seed（31）の癖に引っ張られる。この seed は、動きの言葉に対して両腕を広げやすい
- 直らないときは、seed を替えて打ち消しで癖を止める（`poses.json` の seeds と negative）
- 同じ原因で3回ずれたら、言葉で直すのは止める。次は手本の絵（IP-Adapter）か、3D の人体で姿勢を作って下絵にする方法を試す
