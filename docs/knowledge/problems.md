# 問題

## 2026-09-29 描画器の初版で剣が消えた

- 起きたこと: 2ドット幅の剣身が、縮小後に輪郭色だけになり、暗い背景で見えなくなった
- 原因: 透明に接するドットを輪郭色に塗り替えていた。幅2の部品は全部が外周になる
- 解決: 輪郭を形の外側に1ドット足す方式に変えた
- 再発防止: `tests/test_build.py` の `test_thin_part_keeps_its_inside`

## 2026-09-29 膝を曲げたコマで1ドットの穴

- 起きたこと: 剣士の歩き4コマ目で、両脚の間の膝の高さに背景が1ドットだけ覗いた
- 原因: 3点の筒を曲げると、2本の脚の間に縮小の閾値すれすれの隙間ができる
- 解決: 上下左右が塞がれた透明の1ドットを、周りで最も暗い色で埋める `fill_pinholes`
- 再発防止: `test_pinhole_is_filled_with_darkest_neighbor`

## 2026-09-29 前掛けが見えない

- 起きたこと: 薬師の前掛けが細い帯にしか見えなかった。形を広げても脚の上に白い線が出ただけだった
- 原因: 重ね順。前掛けを上着の裾の後ろに足したので、その後に描かれる脚に隠れていた
- 次から: 部品が読めないときは、形の前に重ね順（`after` `before`）を疑う。`--preview` の高解像度の絵で隠れ方を見る
