# 赤ペンの直しで模型に渡す言葉と強さ

## 渡す言葉

- 直しの言葉 = 指示の訳（前）＋ 元の絵の言葉（後ろ）＋ 画風。元の絵の言葉は、その絵を描いたときの記録の prompt。記録が無い絵は wd-vit-tagger-v3 で絵から読んだタグ（確からしさの高い順に 30 件）
- 指示とぶつかる元の語は外す（髪を赤くするなら元の髪の色、ドレスを替えるなら元の服、右手に持たせるなら元の右手の物）。両方を渡すと、模型は元の語の方を描いた
- 前の形は指示の訳だけを渡していた。言葉の模型が無いと、描く頼みの表では直しの指示がほとんど読めなかった

| 指示 | 前に渡った言葉 | 今渡る言葉（指示の訳の部分） |
|---|---|---|
| 目を大きくして | （空） | large eyes, big eyes |
| 指を5本にして | book | five fingers |
| 髪を赤くして | （空） | red hair |
| もう少し細く | （空） | slender, slim |

## 強さ

fix-verify（Actions の実行 43563743120）で、雪女の絵（library/daily/2026-10-13/05-yukionna.png）の頭の囲み（170,0,350,200）に強さ 0.75 で 3 つの指示を出した。

- 髪を赤くして: 前髪の根元がわずかに桃色になっただけで、髪は白いまま
- 髪を黒くして: 髪は白いまま
- 目を閉じて: 目は開いたまま（このときは「閉じ」が訳せず、指示の語が渡っていなかった）

言葉は渡っていても、0.75 では元の色と形が残った。描き直しの強さが低いと元の絵の色を土台に描くためで、色と形を変える指示は 0.95 より下げないことにした（engine.fix_strength）。崩れを直す指示は、形を保つ方が良いので利用者の強さのままにする。

同じ絵・同じ囲み・同じ 3 つの指示を強さ 0.95 で出し直した（実行 43571728650、1 か所 800〜870 秒、CPU）。

- 髪を黒くして: 囲みの中の髪が黒になった。囲みの外の長い髪は白いままなので、頭の上だけ黒い絵になる（囲みの外は変えない決まりのため）
- 目を閉じて: 目が閉じた
- 髪を赤くして: 髪は白いまま（わずかに紫がかった）で、赤い花が髪に足された。red が髪ではなく飾りに付いた

3 つのうち 2 つが指示どおりに変わり、0.75 では 0 だった。赤い髪は、元の絵の言葉の白い物（snowflakes、white kimono など）が強く、まだ伝わらない。
