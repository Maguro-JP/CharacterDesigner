# リボンの道具の系統

リボンの「描く」の頁は、道具を 1 つずつ並べると似た物が横に並び、どれが同じ働きの仲間か見えなかった。
普通の絵のアプリに合わせ、同じ系統を 1 つのボタンにまとめた（`chatdraw/ribbon.py` の `Family`、`FamilyButton`）。

## 合わせた並べ方

- Photoshop の道具の欄は、関係する道具を 1 つの場所にまとめ、右下の三角で隠れた道具があると示す。押し続けるか右クリックで中を出し、場所には最後に選んだ道具が出る
- CLIP STUDIO PAINT は、道具（ペン、消しゴム、色混ぜ、塗りつぶし、グラデーション、図形、定規、選択範囲など）の下にサブツールを持つ

## このアプリの系統

| 帯 | ボタン | 中の道具 |
|---|---|---|
| 選択 | 移動 | 移動 |
| 選択 | 選択 | 四角・投げなわ・多角形 |
| 描く | ペン | ペン・スプレー |
| 描く | 消しゴム | 消しゴム |
| 描く | 色を混ぜる | ぼかし・指先 |
| 塗り | 塗り | 塗りつぶし・グラデーション |
| 図形・文字 | 図形 | 直線・四角・楕円・多角形・正多角形 |
| 図形・文字 | 文字 | 文字 |
| 定規・対称 | 定規・対称 | 定規の種類、対称の種類（押すと選ぶ物が出る） |
| 色 | スポイト・入れ替え | |
| 表示の道具 | 手のひら・拡大 | 手のひら・拡大 |
| AI | 赤ペン | 赤ペン |

「表示」の頁では、拡大率（全体・100%・倍率）と回転（左・右・角度）を 1 つずつにまとめた。

## 動き

- ボタンを押すと今の道具を使う。▼か、押し続ける（450 ミリ秒）と中の道具が出る
- キーで道具を変えても、その系統のボタンの顔がその道具になる
- 説明はツールチップに、今の道具の説明と系統の中身を出す
- 1280 の窓で、どの頁も横に流れない（`chatdraw/tests/test_ribbonfamily.py`）

出典は `docs/references.md` の「リボンの道具の系統」。
