# 設定画の構成

アニメ・ゲーム・漫画の設定資料（キャラクター表、model sheet）は、描く人が変わっても同じ人物に描けるよう、
次の欄を 1 枚にまとめるのが共通している。道具（`tools/gen/settei.py`）はこの構成で 1 枚の PNG（A3 横、3508×2480）に組む。
欄の並びと大きさは `styles/settei.json`。

| 欄 | 中身 | 道具がすること |
|---|---|---|
| 三面図 | 正面・横・背面の全身を同じ縮尺で並べる | 部位分けで人物の外接枠を取り、高さをそろえて並べる |
| 頭身の目盛り | 頭の高さごとの横線（頭頂・あご・…・足裏） | 正面の絵の頭身（`qc.heads_tall`）から線を引き、頭身を見出しに出す |
| 表情 | ふだん・笑い・怒り・驚き など 4 つ以上 | `bible.py expressions` の顔だけを描き直した絵から顔を切り出して並べる |
| 部位の拡大 | 目・髪の後ろの流れ・服の留め具・靴 など 3 つ以上 | `closeup.py` の拡大を並べる |
| 色指定 | 部位ごとの基本色・影色・明るい色（色の指定表） | 正面の絵の部位分けから、明るさの順の帯（影 15〜30%、基本 40〜70%、明 95〜99%）の色を取る |
| 持ち物・装飾 | 名前・説明・大きさ | 設定資料集（`bible/characters/<id>.json`）の items |
| 注記 | 性格に合わせた描き方の決まり（目の形、ハイライトの数など） | 設定資料集の notes と eyes.notes |
| 線画 | 塗る前の線 | 設定資料集の lineart |
| 足りない欄 | 設定画として使うのに欠けている欄 | 見出し付きで赤字で出す（欠けたまま「出来た」と見せない） |

## 道具が守ること

- 三面図は同じ縮尺にする。向きごとに大きさが違うと、背の高さや部位の長さを読み取れない
- 色指定は描いた絵から取る。設定の言葉の色と違えば、それも崩れとして目で見て分かる
- 欄が欠けていても 1 枚に組み、欠けた欄を名指しする。三面図・表情 4・部位の拡大 3 がそろって設定画として使える

## 確かめたこと

- 2026-10-18: 剣士（swordswoman）の手本の絵 1 枚から組み、正面・頭身 6.19・色指定 7 部位が出た。色指定の表で、左右の靴の色の違い（灰と白）が目で分かった
- 部位分けが帽子の無い絵で帽子を 1,500 画素未満読むことがあるので、1,500 画素未満の部位は表に載せない

- 2026-10-18: 剣士の三面図（各 1 枚、約 29 分）・表情 9（約 39 分）・部位の拡大 4（約 7 分）を描かせて組むと、欄はすべて埋まった（組むのは 40 秒）。描いた絵は設定の服と違い、手が欠けた。型は使えるが、中身の絵の一致を確かめる検品が要る
- 表情のフォルダに部位分けの控え（.parts.png）が混ざり、黒い四角が表情として並んだ。settei は .parts. を読まない

- アニメ制作の設定資料（キャラクター設定・色指定表）の一般的な構成
