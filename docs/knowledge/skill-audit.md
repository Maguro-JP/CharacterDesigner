# 技能（右クリックの加工・仕上げ・組み合わせ）を押して効くかの棚卸し

右クリックのメニューに出る技能（chatdraw/shortcuts.py の builtins）を、本物の Window に絵（96×144）を開き、
試験用の小さな本物の模型（hf-internal-testing/tiny-stable-diffusion-xl-pipe を chatdraw.engine.Painter で読む）を絵の模型にして、
1 つずつ押して最後まで流した。押せるか、終わるか、新しいレイヤーが付くか（または絵が変わるか）、出た知らせを見た。
画素が変わるかは chatdraw/tests/test_shortcuts.py が項目ごとに確かめている（ここでは押して終わるところまでを見た）。

| 技能 | 押して | 時間 | 結果 |
|---|---|---|---|
| 線と塗りを整える（fin:retouch） | 効く | 28.5 秒（初めは部位分けの模型を読む） | 新しいレイヤー |
| 塗りのむらを均す・ジャギーも取る・整える | 効く | 0.4〜0.5 秒 | 新しいレイヤー |
| 指定した箇所の周辺を整える | 囲みが無いと理由を出す | 0.1 秒 | 「選択範囲か赤ペンで囲んでから」 |
| まとめて綺麗にする・まとめて整える（combo:tidy、combo:tidy_color） | 効く | 0.7 秒（部位分けを読んだあと）。1 項目だけの試験で 29.9 秒 | 新しいレイヤー |
| ディテール追加 | 効く | 9.8 秒 | 新しいレイヤー |
| 軽く描き直して仕上げる（fin:refine） | 効く | 33.9 秒 | 新しいレイヤー |
| 1 枚にして 2 倍に拡大（アニメ向け） | 効く | 2.2 秒 | 192×288 になる |
| 画風 5 つ（アニメの塗り・厚塗り・水彩・線画・セル画） | この手元では効かない | 0.1 秒 | 「模型のファイルが足りません」。線を守る ControlNet（xinsir/controlnet-union-sdxl-1.0、約 2.5GB）を押したときに取る作りで、この手元はネットに出られず取れなかった。取れる手元で押して確かめていない |
| 金属・宝石・透明感・神々しい光・木漏れ日・霞と遠近・ラフを清書する | 効く | 0.1〜0.4 秒 | 新しいレイヤー |
| レイヤーのまま 2 倍に拡大 | 確かめの窓が出る | — | 窓（confirm.ask）で「拡大」を選ぶ作り。窓を自動で答える形にできず、ここでは最後まで流していない（test_shortcuts は偽の重みで流して通る） |
| 線画にする・ドット絵にする・背景を消す | 効く | 0.1 秒 | 新しいレイヤーか、背景を消した絵 |
| 透過（人物を切り抜く） | 効く | 19.9 秒 | 新しいレイヤー |
| ちびキャラにする | 効く | 16.0 秒 | 新しいレイヤー |
| 左右・上下・四方に広げる | 効く | 48〜145 秒 | 352×144、96×400、352×400 になる |

## 直したこと

- まとめて綺麗にするの 2 つ（combo:tidy、combo:tidy_color）は、元の版で test_shortcuts の待ち 60 秒を超えて落ちていた。
  原因は組み合わせの工程ごとに部位分け（CPU で 1 回 30〜40 秒）を測り直していたこと。claude/FIX-finish2-20261108 の
  直し（finishers._reuse_parts）を取り込んだあとは、同じ試験が 29.9 秒で通った。2 つ目の落ち（工程の名前が違う）は、
  1 つ目がまだ動いている間に押して「描いている途中」で断られていたためで、1 つ目が通ると消えた
- 画風 5 つは、取れない手元でも押せる形のまま残している。取れる手元では押したときに取る作りなので、隠すと取れる手元でも使えなくなる。
  ネットに出られる手元で押して確かめるのが残っている
