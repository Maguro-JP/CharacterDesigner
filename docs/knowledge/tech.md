# 技術

## 描画器 tools/build.py（2026-09-29）

- 流れ: 部品を SS=8 倍で塗る → 部品ごとに光を当てる → 奥から重ねる → 落ち影 → 8x8 の塊ごとに1ドットへ →
  素材の色段に減色 → 輪郭を外に足す → 孤立ドットの掃除 → touchups
- 厚み: マスクを部品の太さ×0.35 でぼかした膨らみを高さとみなし、勾配から法線を取る。
  膨らみの高さを太さに比例させないと、太い胴がほぼ平ら（法線がほぼ正面）になり明暗が出ない
- 輪郭は外側に足す。内側の外周を塗り替えると、2ドット幅の剣が輪郭だけになり中身が消えた
- 頭の高さと体の枠は描き上がりから数える（`head: true`、`prop: true`）。輪郭のドットは接する部品すべてのものとして数える
- 依存は Pillow だけ。28x39、部品22個で 0.5 秒前後
- Pillow 12 で `getdata` が非推奨。`get_flattened_data` があればそちらを使う（`_data`）
- `strands`: 部品の明るさに sin の縞を足す。`angle` は縞が変わる向き（度）、`period` はドット単位の周期、`amp` は振れ幅。
  部品の明るさが段の境から遠いと縞が段を越えないので、振れ幅はその部品の明るさの位置で決める
- 色数が上限に当たったら、素材どうしで段を共有する（金の暗い段 = 革の明るい段）。使用数の少ない色から探す
- `base` と差し替え（`remove` `override` `add` `materials`）: 職業ごとに頭や体格を書き直さないため。`load_spec` が読む。
  `add` の部品は `after` か `before` で重ね順を決める
- `pixline`: 仕上がりの格子で Bresenham の線を引き、そのドットを丸ごと塗る。細い斜めの剣や槍に使う。
  傾きは 1:5 前後が段がそろってきれい。1:3 だと段が不ぞろいに見えた
- 継承は2段以上でもよい（神官 → 剣士 → 戦士）。ただし `touchups` は顔の形ごとに違うので、顔を変えたら差し替える
- 長い髪は `head: false` にする。頭身の頭は前髪の上端から顎まで
- `tools/fmt.py`: parts.json を幅 110 で整える。indent=1 の json.dumps だと座標まで1要素1行になり、3人で 1984 行あった。整えて 479 行
