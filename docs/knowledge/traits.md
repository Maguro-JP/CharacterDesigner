# 人の描き分けの部品の効き目（描いて確かめた結果）

部品は `tools/gen/traits.json`。設定集の人物に `"traits": ["分類:種類", ...]` と書く。
同じ人物（白いシャツの冒険者の男性）で、部品を1つずつ変えて描いて比べた（2026-10-03）。
効かない部品は、効く書き方が見つかるまで使わず、効いた部品の組み合わせで作る。

## 判定の決まり

「できた」と言えるのは、指定した変化が出て、かつ指定していないところ（服、ポーズ、髪、顔、ほかの部位）が変わっていないときだけ。
指定外の変化が出たら「出たが、余計な変化あり」と書き、何が変わったかを添える（利用者の指摘: 余計な変更がされた絵でできたと言わない）。

いまの道具の限界: 部品ごとに絵を一から描くので、同じ seed でも服・ポーズ・髪が入れ替わる。
「ほかは同じまま1か所だけ変える」には、基準の絵から部分を描き直す仕組み（基準の絵を下に敷いて、変える場所だけ描く）が要る。未着手。

## 1回目: アニメ風（SD1.5 系）、全身

下の「出た」は指定の変化が見えたもの。どれも服・ポーズ・髪の一部が基準と変わった（余計な変化あり）。完全に「できた」ものは無い。

| 分類 | 出た（余計な変化あり） | 出なかった（何が起きたか） |
|---|---|---|
| 体型 | — | stocky、giant（基準と同じ。巨体は1人だけの絵では大きさが比べられない） |
| 筋肉量 | high | low（基準と同じ） |
| 脂肪量 | high | — |
| 比率（頭身） | heroic（少し） | chibi（頭身が変わらない） |
| 骨格 | — | broad、hunched（基準とほぼ同じ） |
| 肌の色 | dark | blue（肌でなく服が青くなった） |
| 皮膚の質感 | — | scales（体の後ろに海蛇が出た）、stone、scars（見えない） |
| 刺青・紋様 | — | tribal（見えない）、runes（体でなく周りに魔法の渦が出た） |
| 耳 | cat（指定していない尾も生えた） | elf、rabbit（全身では小さく見分けられない） |
| 輪郭・鼻 | — | round、square、aquiline（全身では顔が小さく見分けられない） |
| 目 | — | hetero（服が変わった）、third（出ない） |
| 角 | ram、antlers | unicorn（出ない） |
| その他 | wings_bat、tail_dragon、mech_arm | — |
| 亜人間 | dwarf、orc（服が緑に変わった。牙と緑の肌は弱い）、beast_wolf、dragonkin | lizard（頭は人のまま、隣に蛇が出た） |

わかったこと:

- SD1.5 系は、色や質感の言葉を肌ではなく服や背景に移す（青い肌 → 青い服、鱗 → 海蛇）
- 顔の部品は、全身の絵（512x768）では顔が小さすぎて描かれない。胸から上（`"framing": "portrait"`）で描く
- 体の外に足す部品（角、翼、尾、機械の腕）はよく効く。体そのものを変える部品（頭身、骨格、細さ）は効きにくい

## 2回目: SDXL 系（全身）と、アニメ風の胸から上（顔の部品）

SDXL 系は、部品を変えても服・ポーズ・構図が基準とほぼ同じまま残った（余計な変化が少ない）。ただし指定した変化もほとんど出なかった。

| 部品 | 結果 |
|---|---|
| proportion:chibi | 出た。余計な変化あり（髪が茶色、鞄が増えた） |
| race:lizard | 出た。余計な変化あり（尾が体と別の蛇のよう、手袋が増えた） |
| skeleton:hunched | 弱い（少し前かがみ） |
| muscle:low、body:stocky、skin:blue、texture:scars、race:elf | 出なかった（基準と同じ） |
| texture:scales、texture:stone | 出なかった（体の隣に別の生き物、岩が出た） |
| marking:tribal、marking:runes | 出なかった（背景に渦や光の筋が出た） |
| 顔 ears:elf（胸から上） | 出た |
| 顔 ears:rabbit | 出た。余計な変化あり（服がフード付きに変わった） |
| 顔 horns:unicorn | 出た。余計な変化あり（額でなく頭の横に出た） |
| 顔 eyes:hetero、eyes:third、face:round / square、nose:aquiline | 出なかった（胸から上の基準を描いていないので、厳密な比較はしていない） |

わかったこと: 言葉だけでは、体の質感・肌の色・紋様は変わらない。言葉は体の外のもの（隣の岩、背景の渦）として描かれる。

## 3回目: 基準の絵を下に敷いて全体を弱く描き直す（SDXL 系 img2img、強さ 0.5 と 0.65）

8部品（skin:blue、marking:tribal、texture:scales、muscle:high、fat:high、horns:unicorn、ears:elf、race:orc）×2 の 16 枚すべて、
基準の絵とほぼ同じだった。指定の変化は1つも出なかった（失敗）。全体を弱く描き直す方式では、この強さでは何も変わらない。

次: 変えたい場所だけを描き直す（頭まわりは頭だけ塗り直す、肌の上は肌の部分だけ塗り直す、肌の色は肌の画素の色を置き換える）。

## 4回目: 変えたい場所だけを描き直す（SDXL 系 inpaint、強さ 0.95、8 段、guidance 2.0）と、肌の色の置き換え

| 部品 | 方式 | 結果 |
|---|---|---|
| ears:elf | 頭の範囲だけ塗り直す | 出た。余計な変化わずか（表情が少し変わった）。いちばん近い |
| skin:blue | 肌の画素の色相を置き換える（生成なし） | 顔と手は青くなった。余計な変化あり（カーキのズボンと靴の一部も肌と判定されて青い斑点） |
| horns:unicorn、horns:ram | 頭の範囲（上へ 60px 広げる）だけ塗り直す | 出なかった（顔つきが少し変わっただけ） |
| marking:tribal、texture:scales | 肌の範囲だけ塗り直す | 出なかった（顔の肌の色が少し変わっただけ） |

次に確かめること:
- 肌の判定を絞る（彩度と明るさの範囲を狭め、服の色を除く）
- 角・刺青・鱗が出ないのが、段数（8）と guidance（2.0）の低さのせいかどうか（段数と強さを上げて比べる）

## 5回目: 4回目の段数と強さを上げる（12 段、guidance 3.5、強さ 1.0）、肌の判定を絞る

- skin:blue: ズボンにはほぼ色が付かなくなったが、肌の拾い漏れで顔の半分と手だけが青い（靴にも少し点）。出たが不完全
- horns、marking、texture: 出なかった。ears:elf も今回は出なかった
- わかったこと: 少ない段数で全体を描く版のモデル（DreamShaper XL Lightning）は、部分を描き直しても新しい形（角、刺青、鱗）をほとんど描き足さない。
  部分の描き直し専用のモデル（SDXL inpainting）で確かめる

## 6回目: 部分の描き直し専用のモデル（SDXL inpainting 0.1 の本体、20 段、guidance 7.0）

| 部品 | 結果 |
|---|---|
| horns:unicorn、horns:ram、ears:elf | 出なかった（顔つき・髪型が少し変わっただけ） |
| marking:tribal | 前腕に黒い帯が出たが刺青の形ではない。余計な変化あり（シャツに灰色のしみ） |
| texture:scales | 出なかった。余計な変化あり（シャツに灰色のしみ） |

- 本体を2つ持つとメモリ 15GB を超えて強制終了された。今の本体を捨ててから専用の本体を読む
- 塗り直す方式は3通り（全体を弱く、範囲だけ、専用のモデルで範囲だけ）とも効かなかった

## 7回目: 基準の絵を手本（IP-Adapter、強さ 0.5）にして、部品の言葉を足して一から描く

顔・服・ポーズは基準とほぼ同じに保てた。指定した部品は horns:ram / unicorn、ears:elf、marking:tribal、texture:scales、skin:blue が出なかった。
muscle:high は腕がわずかに太くなった程度。背景の明るさが少し変わった。

## まとめ（7回、2026-10-03）

- 「ほかは同じまま1か所だけ変える」は、いまの道具（CPU、SD1.5 系と SDXL 系）では、どの方式でもできなかった
  （全体を弱く描き直す、範囲だけ描き直す、専用のモデルで範囲だけ描き直す、手本を読ませて描く）
- 一から描くなら、体の外に足す部品（角、翼、尾、機械の腕、獣の耳と尾）と、太さ（筋肉が多い、脂肪が多い）、濃い肌、亜人間（ドワーフ、竜人、獣人）は出る。
  ただし服・ポーズ・髪も入れ替わる
- 使い方: 部品は「後から足す」のではなく、デザインの最初から指示文に入れて描き、候補を何枚か出して選ぶ
- 出ないもの（青など普通でない肌の色、鱗・石の肌、刺青・紋様、輪郭・鼻の違い、第三の目）は、いまの道具では作れない。
  作るには、人の手で描いた下絵か、別の仕組み（線画で形を固める ControlNet、作品専用の追加学習）が要る（どちらも未着手）

## 8回目: 素体（簡素な無地の肌着、`"framing": "body"`）で男女 16 部品ずつ（アニメ風 SD1.5 系）

服を着た姿では肌の言葉が服や背景に移ったので、体の線が見える無地の肌着で描いた。指定外の変化が全く無いものは無い。

| 部品 | 男 | 女 |
|---|---|---|
| skin:dark | 出た（背景に灰色の影） | 出た（シャツが黒） |
| muscle:high | 出た（シャツが短い） | 出た（肩当て） |
| muscle:low | 弱く出た | 出なかった |
| fat:high | 出た（シャツが灰色の半袖） | 出た（シャツが灰色） |
| body:stocky | 弱く出た（ズボンが長い） | 出なかった |
| horns:ram | 出た（髪が少し） | 出た（長いツインテール） |
| ears:elf | 見分けられない | 出た（シャツが少し） |
| marking:tribal | 腕に出た（シャツが短い） | 出なかった（長い三つ編み） |
| race:orc | 出た（上の肌着が無い） | 出た（服） |
| race:lizard | 出た（上の肌着が無い） | 出なかった（背後に竜） |
| skin:blue、texture:scales / stone、marking:runes、proportion:chibi | 出なかった（背景や服に移った） | 出なかった |

- 素体にすると、太さ・濃い肌・角・耳・オークは体に出るようになった。普通でない肌の色と肌の質感は、素体でも背景や服に移る
- 出たものは `library/patterns.json` に、男女の見本の絵と「余計な変化」を添えて保存した

## 9回目: 部位を指定して直す（tools/gen/edit.py。部位分けのモデルで範囲を決め、範囲の外は貼り戻す）

範囲の外で変わった画素は、試した 13 枚すべて 0（数字で確かめた）。

| 部品 | 方式 | 結果 |
|---|---|---|
| 肌の色（青、緑、灰、赤）×男女 | 肌の部位の色だけ置き換え（生成なし） | できた。陰影は残り、目の線と白目はそのまま |
| 刺青（腕） | 腕だけ描き直し（強さ 0.99） | 右腕に出た。左腕は袖のような形になり手の形が変わった。腕の周りに明るい縁取り |
| 鱗（腕） | 同上 | 右腕が緑の鱗になったが腕の形が筒のように変わった |
| 巻いた角、エルフの耳 | 頭の上だけ描き直し | 出なかった。髪型が変わり、背景に四角い継ぎ目 |
| 着せ替え | 服の部位だけ描き直し | 服だけ変わり体はそのまま。ただし頼んだ服（革の上着、黒いズボン）ではなかった |

直したこと: 描き直しは広げた範囲で行い、貼り戻すのは元の部位の範囲だけ（縁取りが出たため）。模様（刺青、鱗）は強さを下げて形を保つ。

## 10回目: 部位の描き直しを2倍に拡大して描き、強さを比べる（男の素体の両腕）

範囲の外で変わった画素は 4 枚とも 0。
- 刺青: 強さ 0.85 で両腕に部族の刺青が入り、腕の形も保てた（できた）。0.95 も入るが、腕の輪郭が少し崩れる。0.7 以下では薄く出ない
- 鱗: 0.7 / 0.85 / 0.95 とも出なかった（肌が少し明るくなるか、半透明の影になる）。鱗は未解決
- 刺青はパターン集に `tattoo-tribal-arms` として、肌の4色（青、緑、灰、赤）は `skin-blue` ほかとして、コマンドと見本の絵つきで保存した

## 11回目: 服の部位だけ描き直す（男女、範囲の外は 4 枚とも 0）

- 柄と色は頼んだものになった（赤いチェック、赤い革、ジーンズの生地、水色のパーカー）
- 服の形は元の服の輪郭から出られなかった（ジーンズは短パンの丈、スカートは短パンの形、上着は袖なし）
- 直したこと: 部位を + でつないで範囲を合わせられるようにした。長袖は `upper+arms`、長い丈は `lower+legs`

## 12回目: 服＋腕、服＋脚の範囲で描き直す（範囲の外は 4 枚とも 0）

| 頼んだ服 | 範囲 | 結果 |
|---|---|---|
| 男・赤い革の上着（長袖） | upper+arms | できた。袖まで革になった。片方の肩に白い当て布が出た（範囲の中の余計な変化） |
| 男・黒いジーンズ（長い丈） | lower+legs | 足首までのジーンズになった。片足の先が白くかすれた（範囲の中の崩れ） |
| 女・白いパーカー（長袖） | upper+arms | できた。白い長袖、青い紐と裾 |
| 女・赤いチェックのスカート | lower+legs | できた。膝丈のプリーツスカート。頼んでいない赤い靴が出た（脚の範囲に足先が入っているため） |

次: 脚の範囲から足先を外す（靴を足さないとき）。崩れた足先は、足の範囲だけ元の絵から貼り戻す。

## 13回目: 足先を範囲から外す（`lower+legs-feet`）、上着を種を変えて描き直す

- ジーンズ: 足首までの丈のまま、足先のかすれが消えた（範囲の外 0）
- スカート: 頼んでいない靴が消え、素足のまま（範囲の外 0）
- 革の上着（種 8）: 半分が青い別の上着になった。種 7 の案（肩に白い当て布）のままにする。肩の当て布は未解決
