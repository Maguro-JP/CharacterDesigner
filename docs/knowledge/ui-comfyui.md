# ComfyUI の画面から取り入れた物と、取り入れなかった物

ComfyUI（画像生成の工程をノードでつなぐ道具）の画面のうち、このアプリに合う所だけを取り入れた。
今の画面の形（欄・帯・タブ・指示のタブの並び）は変えず、足した物はメニューとキーから呼ぶ。

## 調べた所（公式の資料で確かめた物）

- 待ち行列と履歴: 実行中の仕事の表示を押すと待ち行列が開き、履歴を左の欄に出せる（docs.comfy.org の Interface overview）。v1.2.0 で Queue/History の欄が入った（Comfy-Org/ComfyUI_frontend の README）
- 出来た絵の欄（Assets）: 描いた絵と取り込んだ絵を見る・使い直す・書き出す・消す（docs.comfy.org）
- 名前付きの保存: Workflows の欄に保存した流れと最近のファイル、Templates に組み込みの見本（docs.comfy.org）
- 探して呼ぶ: Node Library の欄に検索、ダブルクリックでノードの素早い検索の窓（comfyanonymous/ComfyUI の README のキーの表）
- キー: Ctrl+Enter で待ち行列に入れる、Ctrl+S で保存。キーは v1.3.7 から変えられる（ComfyUI_frontend の README）
- 変わった所だけを動かし直す（comfyanonymous/ComfyUI の README）

ノードの工程ごとの秒の表示と色の数は、上の資料では確かめられなかった。下で取り入れた「工程ごとの秒」は、ComfyUI の「どこが動いているかが見える」考え方を参考にした自前の形。

## 取り入れた物

| 物 | 入口 | 理由 |
|---|---|---|
| 工程ごとの秒と止まった所 | 進みの欄の帯の下の 1 行 | 描く・検品・直しのどこで時間を使い、どこで止まったかが見えないと、待つか止めるかを決められない。engine の状態の言葉（on_status）から区切るので、描く所に手を入れない |
| 描いた絵を並べて比べる | 表示のメニュー、履歴の右クリック、Ctrl+Shift+K | 履歴は小さな絵が縦に並ぶだけで、2 枚の違いが見にくかった。ComfyUI の Assets のように、出来た絵を並べて選んで使い直す |
| 操作を探す窓 | ヘルプのメニュー、Ctrl+K | メニューの奥の操作を名前の一部で呼べる。ComfyUI のノードの検索の窓と同じ考え。メニューの QAction をそのまま呼ぶので、同じ名前で違う動きにならない |

## 取り入れなかった物

- ノードをつなぐ画面: 利用者は頼みの言葉と赤ペンで描かせる。工程を組む画面は手数が増え、初めの画面が難しくなる
- 待ち行列の窓: 候補を大量に描かせて選ぶやり方をしない決まりなので、待ち行列を見せる窓は今は要らない。続けて描く頼み（チャットの手順）は今の進みの欄に出る
- 名前付きの設定の保存: 描くワードの登録・禁止ワードの登録と履歴の「この設定で描き直す」が、すでに同じ役をしている
- 暗い色の画面: テーマの選択がすでにある。色の決まりは資料で確かめられなかったので変えない
