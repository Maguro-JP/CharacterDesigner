# chatdraw の残り（2026-10-26 JST、0.4.3 の時点）

「直す」は AI が直す物、「利用者」は利用者が見て決める物です。

## 確かめ方

| 確かめ方 | 中身 | いつ流れるか |
|---|---|---|
| 手元の試験（`bash .claude/hooks/test.sh </dev/null`） | 画面・設定・キー・進み・検品の回し方など。模型は使わない | マージの前に毎回 |
| Windows の通し試験（chatdraw-e2e） | Setup.exe を入れる、起動、部品を取る、試験用の小さな模型で描く、アンインストールして残りが無いか | chatdraw を変えて push するたび |
| Windows で本物の模型で描く（chatdraw-windraw） | Setup.exe を入れたアプリの Python で、日本語の頼みを描く言葉に直し（何が模型に渡ったかを残す）、Animagine XL 4.0 で描き、手と頼んだ物を検品する | 手で流す。描く所を変えたら流す |
| 2 段で描く（draw-one） | 構図（FLUX.2 klein）と仕上げ（Animagine）。遅い機械なら出し直し、検品を通らなければ種を変えて描き直す | 頼みを変えて push するか、手で流す |
