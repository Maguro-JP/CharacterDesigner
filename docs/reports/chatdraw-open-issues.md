# chatdraw の残り（2026-10-24 JST、0.2.8 の時点）

「直す」は AI が直す物、「利用者」は利用者が見て決める物です。

## 確かめ方

| 確かめ方 | 中身 | いつ流れるか |
|---|---|---|
| 手元の試験（`bash .claude/hooks/test.sh </dev/null`） | 画面・設定・キー・進み・手で置く模型・ヘルプなど | マージの前に毎回 |
| Windows の通し試験（Actions の chatdraw-e2e） | Setup.exe を入れる、起動、描く部品と模型を取る、1 枚描く、アンインストールして残りが無いか | chatdraw を変えて push するたび |
| 模型の出来（Actions の model-verify と毎週の見直し） | 模型ごとに絵を描かせ、出来を見て点を付ける | 毎週土曜 9 時 47 分（日本時間）に見直す |
