# 整理整頓（2026-10-31）

開発はすべてデスクトップアプリ chatdraw（`chatdraw/`、配布は `packaging/chatdraw/` と `.github/workflows/chatdraw-*.yml`）で行う。
その前のアプリと、それだけが使っていた物を外した。まだ役に立つ道具は残し、試験で動くことを確かめている。アプリに入れるかは利用者が決める（[pending.md](pending.md) の 14）。

分け方: A はアプリが読む・同梱する物、B はアプリは使わないが役に立つ物、C は外した物。迷った物は B にした。

## A アプリが使う（残す）

| 場所 | 大きさ | 使い方 |
|---|---|---|
| `chatdraw/` | 約 1.0MB | アプリ本体と試験 |
| `packaging/chatdraw/` | 約 20KB | Setup.exe を組む（build.sh、installer.nsi） |
| `.github/workflows/chatdraw-setup.yml` `chatdraw-e2e.yml` `chatdraw-windraw.yml` | | Setup.exe を組み、起動と描く流れを確かめる |
| `.github/workflows/draw-one.yml` | | `python -m chatdraw.draw_one` で 1 枚描いて確かめる |
| `tools/gen/hands.py` `tagger.py` `cdhome.py` | | build.sh がアプリに同梱する |
| `tools/gen/feet.py` `facecheck.py` | | chatdraw/handcheck.py が読む（足の指・顔の検品） |
| `VERSION` `LICENSE` | | build.sh が同梱する |

## C 外した物

戻すときは、この整理のコミットの 1 つ前から取り出す（`git checkout <この整理のコミット>~1 -- <場所>`）。

| 場所 | 大きさ | 外した理由 |
|---|---|---|
| `app/`（画面 web/、窓口 server/、MCP mcp/、launch.py、start.sh） | 約 532KB | 前のアプリ。製品は chatdraw に作り直した。アプリから読まれていない |
| `packaging/windows/` | 約 16KB | 前のアプリの Setup.exe の組み方。配っているのは `packaging/chatdraw/` |
| `.github/workflows/bundle.yml` | | 前のアプリの Setup.exe を毎月組んでいた |
| `tests/test_launch_window.py` `tests/test_launch_choices.py` | | 前のアプリの起動役（app/launch.py）の試験 |

外したことに合わせて、`tests/test_cdhome.py` と `tests/test_version.py` から前のアプリの道を外し、`.claude/hooks/test.sh` から前のアプリの試験を流す行を外した。
