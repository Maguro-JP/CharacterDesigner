- 何を決めてほしいか: この環境のネットワーク設定で、次のドメインへの接続を許可するか

  - `www.cgworld.jp`（開発者の記事。サイズや作り方の出典）

  記事の数字（18x32 など）と記憶で `styles/diorama.json` を書いている
- 選択肢: A 許可する / B 許可しない（今のまま数字だけで進める）
- 推す案: A。見た目の判定を「本物と並べて」行えるようになる。画像はリポジトリに置かず、
  見て数字に落とすだけにする（CLAUDE.md の方針どおり）

- 状態: 解決（2026-09-30）。ネットワーク設定を Full に変更。資料サイトへの接続が通ることを確かめた（HTTP 200）

## 2. マージ済みの作業ブランチをリモートから消せない（2026-09-29）

- 何を決めてほしいか: 残っているブランチを消すか、この環境から消せるようにするか

- 起きたこと: `git push origin --delete <branch>` が `fatal: the remote end hung up unexpectedly` で失敗する。

- 選択肢: A GitHub の画面で消す（リポジトリの Settings で「マージ後にブランチを自動で消す」を有効にすれば以後は不要）/ B 残す

- 答え: 削除（2026-09-30）。この環境の git からは消せない（`git push --delete` がプロキシで切られる）ので、利用者が GitHub の画面で消し、「マージ後にブランチを自動で消す」を有効にする。残りは main 以外 30 本
