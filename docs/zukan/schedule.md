# 動物の描く予定

1日1種の動物を、0時から23時（JST）まで毎時1つの画風で描く（24画風、簡単なものから本格的なものへ）。1つの画風を3枚（1枚 約5分）。
動物は日ごとに替え、`tools/gen/animal_cycle.py` の ANIMALS に足せば増やせる。
