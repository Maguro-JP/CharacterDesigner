# 動物の描く予定

1日1種の動物を、12時から23時（JST）まで毎時1つの画風で描く。1つの画風を3枚（1枚 約5分）。
画風は12個で決まっている。動物は日ごとに替え、`tools/gen/animal_cycle.py` の ANIMALS に足せば増やせる。

## 毎日の時間割（JST）

| 時刻 | 画風 |
|---|---|
| 12:00 | 01-yurukyara（yuru-chara mascot, super simple round shapes, thick outline, flat colors, cute） |
| 13:00 | 02-chibi（chibi deformed sticker, big head, flat 2d, white outline） |
| 14:00 | 03-character（anime character design sheet style, cel shading, clean lineart） |
| 15:00 | 04-anime（1990s anime cel animation still） |
| 16:00 | 05-manga（black and white manga ink drawing, screentone, monochrome） |
| 17:00 | 06-illust（digital illustration, soft lighting, detailed） |
| 18:00 | 07-kirie（paper cut-out art, layered colored paper, flat shapes） |
| 19:00 | 08-nihonga（nihonga japanese painting, mineral pigments, gold leaf background） |
| 20:00 | 09-ukiyoe（ukiyo-e woodblock print, bold outlines, flat colors） |
| 21:00 | 10-oil（classical oil painting, visible brush strokes） |
| 22:00 | 11-watercolor（loose watercolor painting, paper texture） |
| 23:00 | 12-real（wildlife photograph, realistic, natural habitat, sharp focus） |
