# 襟巻きの剣士の 3D、2 回目（形は TripoSR、色と顔は描いた絵）

入力は `../swordswoman/swordswoman-input-s0.jpg`（三面図）。種は使わない（s0）。
- mix: `chara3d.py 入力 out --mesh mesh.obj`。形は TripoSR（コミット 107cefdc、重み 5b521936、Actions の実行 43727450848 の mesh.obj）。向きは自動で yaw 270・鏡写し（型の重なり 0.57、色の差 0.221）。点 17,776、三角形 24,984、.vrm 2.40MB、作る 8.9 秒・撮る 12.1 秒
- plate: 膨らませた板の形をならした物。点 12,535、三角形 20,014、.vrm 2.05MB、作る 9.5 秒・撮る 11.2 秒

腕を上げたとき、腰より下の点（mix 4,990 点、plate 5,258 点）のうち 1cm 以上動いた点はどちらも 0（スカートは持ち上がらない）。
