# フィードバックの成果物

フィードバックの題目ごとに、利用者に見せた成果物（通った絵・途中の絵・設定画）を資産として残す置き場。
作業場所（scratchpad）に置いたままにすると、セッションが終わると消え、あとから見比べられなかった。

置き方: `library/feedback/<題目>/<日付>/<組>/<組>-<姿勢か番号>-s<種>.jpg`（1 枚ずつ。一覧図にまとめない）と、組のフォルダの `README.md`（1 枚 1 行で、判定・描かせた言葉・種・残っている崩れ）。日付のフォルダの `README.md` は組の一覧。設定画は頁ごとに種が違うので `-s<種>` を付けない。
判定は「通す」「途中」「戻す」のどれか。目録は `library/INDEX.md`（`python3 tools/library_check.py` が書く）。

| 題目 | 中身 |
|---|---|
| `settei/` | 設定画（三面図・表情・部位の拡大・色指定）の型を当てはめた絵 |
| `check/` | 描画確認（段階ごと・回ごと）の絵 |
| `baseline/` | 描く前の最低限の決まり（腕 2 本、種族の部位、持ち物 1 つ など）を掛けて描かせた絵 |
