CharacterDesigner

日本語で頼むと、手元の PC がキャラクターを描いて確かめる

「赤い襟巻きの騎士の少女、ランタンを持って」と書くだけで、描く言葉に直し、描き、頼んだ物が描けたか・手足や持ち物に矛盾が無いかを検品し、落ちた絵は理由に合わせて描き直します。外のサービスも API キーも要りません。

GPU 不要（CPU で 1 枚 約3分） 言葉の模型も手元 Claude から呼べる（MCP）

What it does

できること

1

頼みごとを、7つの役割で描いて検品する

安全・読み手・演出・描き手・検品・意地の悪い目・整理の7つの役割が順に回します。落ちた絵は、落ちた理由（描かれていない物、腕が無い、物が2つに分かれている）に合わせて描き方を変えて描き直します。

  • 描く言葉に直す模型は、画面から入れ替えられる（同梱、Ollama などの窓口）
  • 通った描く言葉は覚え、似た頼みごとのときに手本として使う
  • あり得ない形（余分な手足、浮いた物）は、特別に頼まない限り描かない
2

線画から描く

人の描き手と同じく、線画を先に描きます。塗りの絵から線を取り出すと、影の境目まで線になって二重や途切れが出たため、描く段階から線画として描かせ、灰色の陰影だけを除いて清書します。

python3 tools/gen/lineart.py draw "1girl, witch, ..." out/

3

種族・年齢・服を描き分ける

エルフ、ドワーフ、獣の耳や尾を持つ種、子供から老人、服の差し替えまで、同じ作風のまま描き分けます。亜人は耳・尾・翼・角の付いた設定資料（4方向）を描きます。

4

箱庭ドットのドット絵と設定資料

部品（楕円、多角形、太さのある線）と素材で人物を組み、光を当てて高い解像度で描いてから、縮小・減色・輪郭付けでドット絵に落とします。待機と歩きのコマ、右向き、色指定の設定資料まで出します。

python3 tools/build.py characters/warrior/parts.json --preview out/

5

絵の一部を直す

範囲だけ描き直す、絵の外を描き足す、背景を抜く、顔だけ拡大して描き直す。描き直した所と元の絵の継ぎ目が出ないように、縁の色を合わせます。

python3 tools/gen/imgproc.py inpaint / outpaint / facefix

6

描けたかを数えて確かめる

目で見る前に、機械で数えられることは数えます。

  • 頼んだ物が描かれたか（絵からタグを読んで突き合わせる）
  • 腕や脚が無い、体が画面の端で切れている
  • ほうきや杖が柄と先で別々に描かれている（物を探す模型で塊を数える）
  • 関節の位置（肩・肘・腰・膝）と顔の向き
How to use

使い方

1 / 起動する

アプリを立ち上げる

リポジトリの場所で1行流します。初回は部品の取得に数分、2回目からは数秒で起動します。

sh app/start.sh

必要なもの: Python 3.10 以上、Node.js 20.19 以上、curl、ディスク約 9GB。GPU は無くても動きます。

2 / 開く

画面を開いて頼む

表示された住所を開き、「自由に描く」の欄に日本語で頼みます。「描く言葉に直す」で英語のタグにし、見て直してから「描く」。

http://127.0.0.1:4173/

例: 赤いマフラーの騎士の少年、雪の城の前

3 / 見る

結果を見て選ぶ

最初の1件はモデルの取得と読み込みで 10〜20 分、そのあとは1枚 約3分です。落ちた絵は「回ごとの結果」で理由を見られます。良ければ「良い」を押すと、次から手本になります。

描き方は「一発で描く（速い）」「描いてから人の順番で仕上げ直す」「ラフから描く」から選べます。

Claude から頼む

アプリを起動したまま、MCP サーバーを登録すると、Claude に「白い狐の巫女を描いて」と頼めます。

claude mcp add characterdesigner -e PYTHONPATH=.cache/app/lib -- python3 -m app.mcp.server
